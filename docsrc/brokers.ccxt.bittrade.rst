What is BitTrade?
-----------------

BitTrade is a registered crypto exchange run by BitTrade Co., Ltd., with prices in Japanese yen. It offers an order-book exchange, a simple buy and sell desk, and leverage trading; its API supports the exchange and the desk but not leverage trading yet.

Sign up for BitTrade
--------------------

#. Open the account form on the BitTrade site or app, enter your email and a password, and confirm the code BitTrade emails you.
#. Finish identity verification (本人確認) and wait for BitTrade to approve your account.
#. Turn on two-factor authentication (SMS or Google Authenticator) under Security. BitTrade has no testnet, so plan to test with a very small amount.

`Open a BitTrade account <https://www.bittrade.co.jp/>`_

Create a BitTrade API key
-------------------------

#. Log in on a computer browser. BitTrade's API page cannot be opened from the phone app.
#. Go to My Page, then API, then Create API key (https://www.bittrade.co.jp/ja-jp/user/api/).
#. Type a note (備考) so you can tell your keys apart.
#. Add the IP address of the machine that runs your bot (up to 20). A key with no IP address set expires after 90 days.
#. Tick the permissions (see below), then press 秘密鍵を作成 (Create secret key).
#. Save the Access Key and Secret Key right away. BitTrade shows the Secret Key only once.

**Which permissions to turn on:** BitTrade has three permissions: 読取 (Read), 取引 (Trade) and 出金 (Withdraw). New keys start with Read only, so also tick Trade. Leave Withdraw off. A bot never needs to move money out of your account.

.. warning::

   Never turn on withdrawals for a BitTrade trading bot key. Bind the key to your server's IP address when BitTrade lets you, keep the secret out of your code and out of Git, and delete the key if it ever leaks.

Connect BitTrade to LumiBot
---------------------------

The simplest way: put these lines in a ``.env`` file next to your strategy. LumiBot loads the file, sees ``TRADING_BROKER=bittrade`` and connects to BitTrade for you, so your strategy needs no broker code.

.. code-block:: bash

   TRADING_BROKER=bittrade
   BITTRADE_API_KEY=your_apiKey
   BITTRADE_API_SECRET=your_secret

LumiBot reads exactly the fields CCXT needs for BitTrade (``apiKey``, ``secret``). If one is missing, LumiBot stops at start-up and names the variable you still need.

You can also build the broker in code. This is handy when one script talks to more than one exchange, or when you need extra CCXT options. The keys in the config are CCXT's own credential names for BitTrade:

.. code-block:: python

   import os

   BITTRADE_CONFIG = {
       "exchange_id": "bittrade",
       "apiKey": os.environ.get("BITTRADE_API_KEY"),
       "secret": os.environ.get("BITTRADE_API_SECRET"),
       "sandbox": False,  # no sandbox for this exchange
   }

   from lumibot.brokers import Ccxt

   broker = Ccxt(BITTRADE_CONFIG)
   # then: MyStrategy(broker=broker, ...)

Either way, LumiBot turns on CCXT's built-in rate limiting for you.

Testing on BitTrade
-------------------

BitTrade has no sandbox, and CCXT lists no test URL for it, so test with a very small amount. With environment variables, leave ``BITTRADE_SANDBOX`` unset. In a code config, set ``"sandbox": False``.

Algorithmic trading example: a simple BitTrade bot
--------------------------------------------------

This bot buys about 7500 JPY of BTC on BitTrade once and then holds it. It is a starting point to check that your keys, balances and orders work. If the exchange's minimum order is larger, raise the amount.

.. code-block:: python

   from lumibot.entities import Asset
   from lumibot.strategies import Strategy


   class BittradeBuyOnce(Strategy):
       """Buy a small amount of BTC once, then hold it."""

       def initialize(self):
           self.sleeptime = "1H"
           self.set_market("24/7")  # crypto trades all day, every day

       def on_trading_iteration(self):
           coin = Asset("BTC", asset_type=Asset.AssetType.CRYPTO)
           if self.get_position(coin) is not None:
               return  # already holding BTC
           price = self.get_last_price(coin, quote=self.quote_asset)
           if price:
               quantity = round(7500 / price, 6)  # about 7500 JPY worth
               order = self.create_order(coin, quantity, "buy", quote=self.quote_asset)
               self.submit_order(order)


   if __name__ == "__main__":
       # LumiBot reads TRADING_BROKER and the keys from your .env file.
       strategy = BittradeBuyOnce(quote_asset=Asset("JPY", asset_type=Asset.AssetType.CRYPTO))
       strategy.run_live()

Agentic trading example: an AI agent that trades on BitTrade
------------------------------------------------------------

Agentic trading means an AI agent reads the market and decides what to do. In this example one LumiBot agent looks at prices and your BitTrade account, then places the orders itself. There is no Python logic in between: you set the rules in plain English in the prompt, such as what it may trade and how big each order can be. This follows the same pattern as LumiBot's AI trading team examples.

.. code-block:: python

   from lumibot.entities import Asset
   from lumibot.strategies import Strategy


   class BittradeAITrader(Strategy):
       """One AI agent researches the market and places the trades itself."""

       def initialize(self):
           self.sleeptime = "4H"
           self.set_market("24/7")
           self.agents.create(
               name="trader",
               model="openai/gpt-6-luna",
               reasoning_effort="high",
               allow_trading=True,
               system_prompt=(
                   "You manage a small crypto account on BitTrade. "
                   "You may trade BTC and ETH against JPY (asset_type 'crypto', quote_symbol 'JPY'), or hold cash. "
                   "Before every order, call account_portfolio, account_positions and "
                   "market_last_price for that exact symbol in the same run. "
                   "Keep each order under 10% of the account value. "
                   "Explain each decision in one short paragraph."
               ),
           )

       def on_trading_iteration(self):
           self.agents["trader"].run(
               task_prompt="Review recent BTC/JPY and ETH/JPY prices and your current holdings, then decide whether to buy, sell or hold.",
               context={"exchange": "BitTrade", "quote": "JPY", "date": self.get_datetime().isoformat()},
           )


   if __name__ == "__main__":
       # LumiBot reads TRADING_BROKER and the keys from your .env file.
       strategy = BittradeAITrader(quote_asset=Asset("JPY", asset_type=Asset.AssetType.CRYPTO))
       strategy.run_live()

The agent needs a model key such as ``OPENAI_API_KEY`` in your environment. See the :doc:`AI agents quickstart <agents_quickstart>` for models, tools and memory.

Fees and partner IDs on BitTrade
--------------------------------

You pay BitTrade's normal trading fees. LumiBot may attach its own exchange partner ID. That costs you nothing extra. LumiBot never adds an extra builder fee unless one is turned on, and it logs a warning when one is.

BitTrade tips
-------------

* BitTrade markets are priced in Japanese yen, so use ``JPY`` as your quote asset (for example ``BTC/JPY``).
* Set an IP address on every bot key. BitTrade keys without an IP restriction stop working after 90 days, which can quietly break a long-running bot.
* You can create at most 5 API keys. BitTrade's help pages and API docs are in Japanese.
* BitTrade's API host is ``api-cloud.bittrade.co.jp``. CCXT uses it for you, so you do not need to set it.

Frequently asked questions
--------------------------

**Can I build a BitTrade trading bot in Python?**

Yes. Install LumiBot (``pip install lumibot``), set your BitTrade keys and use the ``bittrade`` CCXT exchange id as shown above.

**Does BitTrade have a testnet?**

No testnet is set up for BitTrade in LumiBot. Start with a small amount, and in a code config set ``"sandbox": False``.

**Which API permissions does a BitTrade bot need?**

BitTrade has three permissions: 読取 (Read), 取引 (Trade) and 出金 (Withdraw). New keys start with Read only, so also tick Trade. Leave Withdraw off. A bot never needs to move money out of your account.

**Can an AI agent trade on BitTrade by itself?**

Yes. The agentic example above gives one agent permission to trade. You control what it may trade and how much through its prompt.

**Can I trade BitTrade perpetual futures with LumiBot?**

CCXT does not list perpetual swaps for BitTrade, so use spot markets.

**Is LumiBot free?**

Yes. LumiBot is open source on GitHub at https://github.com/Lumiwealth/lumibot. You pay only your exchange's trading fees and, for AI agents, your model provider.
