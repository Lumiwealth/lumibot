What is Extended?
-----------------

Extended is a decentralized exchange with leveraged perpetual markets on crypto and real-world assets, plus crypto spot trading against USDC. You sign in with your own crypto wallet.

Sign up for Extended
--------------------

#. Open Extended and connect a wallet. Extended works with EVM and Starknet wallets.
#. Sign the account creation request, then sign the registration request. This creates your Extended trading account and turns on trading.
#. For practice, also connect a wallet on the Extended testnet at https://starknet.sepolia.extended.exchange and claim free test USDC (up to $1,000 worth per wallet per day).

`Open a Extended account <https://extended.exchange/>`_

Set up a Extended API wallet
----------------------------

#. Log in to Extended with your wallet.
#. Pick the sub-account (trading account) you want the bot to use. You can make up to 10 per wallet from the Account section at the bottom right of the Trade screen.
#. Open the API management page (https://app.extended.exchange/api-management).
#. Create or copy the API key for that sub-account.
#. Copy the Stark private key for the same sub-account. LumiBot sends it to CCXT as ``privateKey`` to sign orders. Never share it with anyone.

**Which permissions to turn on:** Extended has no permission checkboxes. The API key alone can only read data: Extended says it cannot create orders, transfer funds or withdraw. Orders need the API key plus a signature from the Stark private key, and so do withdrawals. Extended only sends withdrawals to wallets linked to your account, but treat the Stark private key like a password and keep only bot money in the bot's sub-account.

.. warning::

   A Extended private key is as powerful as the money it controls. Use a separate wallet or API wallet that holds only what you want the bot to trade, keep the key out of your code and out of Git, and move your funds if the key ever leaks.

Connect Extended to LumiBot
---------------------------

The simplest way: put these lines in a ``.env`` file next to your strategy. LumiBot loads the file, sees ``TRADING_BROKER=extended`` and connects to Extended for you, so your strategy needs no broker code.

.. code-block:: bash

   TRADING_BROKER=extended
   EXTENDED_API_KEY=your_apiKey
   EXTENDED_PRIVATE_KEY=your_privateKey
   EXTENDED_SANDBOX=true   # testnet; remove this line for your live account

LumiBot reads exactly the fields CCXT needs for Extended (``apiKey``, ``privateKey``). If one is missing, LumiBot stops at start-up and names the variable you still need.

You can also build the broker in code. This is handy when one script talks to more than one exchange, or when you need extra CCXT options. The keys in the config are CCXT's own credential names for Extended:

.. code-block:: python

   import os

   EXTENDED_CONFIG = {
       "exchange_id": "extended",
       "apiKey": os.environ.get("EXTENDED_API_KEY"),
       "privateKey": os.environ.get("EXTENDED_PRIVATE_KEY"),
       "sandbox": True,  # testnet first; set False for your live account
   }

   from lumibot.brokers import Ccxt

   broker = Ccxt(EXTENDED_CONFIG)
   # then: MyStrategy(broker=broker, ...)

Either way, LumiBot turns on CCXT's built-in rate limiting for you.

Algorithmic trading example: a simple Extended bot
--------------------------------------------------

This bot buys about 50 USDC of BTC on Extended once and then holds it. It is a starting point to check that your keys, balances and orders work. If the exchange's minimum order is larger, raise the amount.

.. code-block:: python

   from lumibot.entities import Asset
   from lumibot.strategies import Strategy


   class ExtendedBuyOnce(Strategy):
       """Buy a small amount of BTC once, then hold it."""

       def initialize(self):
           self.sleeptime = "1H"
           self.set_market("24/7")  # crypto trades all day, every day

       def on_trading_iteration(self):
           coin = Asset("BTC", asset_type=Asset.AssetType.CRYPTO)
           if self.get_position(coin) is not None:
               return  # already holding BTC
           price = self.get_last_price(coin, quote=self.quote_asset)
           if price:
               quantity = round(50 / price, 6)  # about 50 USDC worth
               order = self.create_order(coin, quantity, "buy", quote=self.quote_asset)
               self.submit_order(order)


   if __name__ == "__main__":
       # LumiBot reads TRADING_BROKER and the keys from your .env file.
       strategy = ExtendedBuyOnce(quote_asset=Asset("USDC", asset_type=Asset.AssetType.CRYPTO))
       strategy.run_live()

Agentic trading example: an AI agent that trades on Extended
------------------------------------------------------------

Agentic trading means an AI agent reads the market and decides what to do. In this example one LumiBot agent looks at prices and your Extended account, then places the orders itself. There is no Python logic in between: you set the rules in plain English in the prompt, such as what it may trade and how big each order can be. This follows the same pattern as LumiBot's AI trading team examples.

.. code-block:: python

   from lumibot.entities import Asset
   from lumibot.strategies import Strategy


   class ExtendedAITrader(Strategy):
       """One AI agent researches the market and places the trades itself."""

       def initialize(self):
           self.sleeptime = "4H"
           self.set_market("24/7")
           self.agents.create(
               name="trader",
               model="openai/gpt-6-luna",
               reasoning_effort="high",
               allow_trading=True,
               system_prompt=(
                   "You manage a small crypto account on Extended. "
                   "You may trade BTC and ETH against USDC (asset_type 'crypto', quote_symbol 'USDC'), or hold cash. "
                   "Before every order, call account_portfolio, account_positions and "
                   "market_last_price for that exact symbol in the same run. "
                   "Keep each order under 10% of the account value. "
                   "Explain each decision in one short paragraph."
               ),
           )

       def on_trading_iteration(self):
           self.agents["trader"].run(
               task_prompt="Review recent BTC/USDC and ETH/USDC prices and your current holdings, then decide whether to buy, sell or hold.",
               context={"exchange": "Extended", "quote": "USDC", "date": self.get_datetime().isoformat()},
           )


   if __name__ == "__main__":
       # LumiBot reads TRADING_BROKER and the keys from your .env file.
       strategy = ExtendedAITrader(quote_asset=Asset("USDC", asset_type=Asset.AssetType.CRYPTO))
       strategy.run_live()

The agent needs a model key such as ``OPENAI_API_KEY`` in your environment. See the :doc:`AI agents quickstart <agents_quickstart>` for models, tools and memory.

Extended tips
-------------

* Each Extended sub-account has its own API key and Stark key. Use a separate sub-account for each bot so its money and trades stay apart.
* Perpetual symbols use the full CCXT form, for example ``BTC/USDC:USDC``. Spot is plain ``BTC/USDC``. Spot always trades at 1x leverage.
* Extended moved its settlement network from Starknet to Arc (a blockchain from Circle) starting 22 October 2026. Extended says you keep the same wallet and keys. If your bot cannot connect after the move, check that your CCXT version is current.

Frequently asked questions
--------------------------

**Can I build a Extended trading bot in Python?**

Yes. Install LumiBot (``pip install lumibot``), set your Extended keys and use the ``extended`` CCXT exchange id as shown above.

**Does Extended have a testnet?**

Yes. Set ``EXTENDED_SANDBOX=true`` and use keys from the Extended testnet.

**Which keys does a Extended bot need?**

Extended has no permission checkboxes. The API key alone can only read data: Extended says it cannot create orders, transfer funds or withdraw. Orders need the API key plus a signature from the Stark private key, and so do withdrawals. Extended only sends withdrawals to wallets linked to your account, but treat the Stark private key like a password and keep only bot money in the bot's sub-account.

**Can an AI agent trade on Extended by itself?**

Yes. The agentic example above gives one agent permission to trade. You control what it may trade and how much through its prompt.

**Can I trade Extended perpetual futures with LumiBot?**

CCXT lists perpetual swaps for this exchange. Use the full contract symbol, such as ``BTC/USDT:USDT``.

**Is LumiBot free?**

Yes. LumiBot is open source on GitHub at https://github.com/Lumiwealth/lumibot. You pay only your exchange's trading fees and, for AI agents, your model provider.
