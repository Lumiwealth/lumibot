What is Latoken?
----------------

LATOKEN is a crypto exchange that focuses on listing new tokens. It offers spot trading on hundreds of crypto pairs, plus an instant swap and token sales.

Sign up for Latoken
-------------------

#. Click Sign up on https://latoken.com, enter your email and a password, and confirm your email with the 6-digit code LATOKEN sends you.
#. Turn on two-factor authentication under Profile, then the Security tab (Google Authenticator or SMS).
#. Identity verification (KYC) is only needed if you want API keys that can transfer or withdraw funds. A trading bot does not need those.

`Open a Latoken account <https://latoken.com/>`_

Create a Latoken API key
------------------------

#. Stay logged in for at least 24 hours without a break. LATOKEN only lets you create API keys after that, and a disconnect restarts the timer.
#. Click Profile in the top-right corner and select API Keys (https://latoken.com/account/apikeys/create-apikey).
#. Click Create API Key and enter a label you will recognize.
#. Choose the Trading on Spot permission set (see below) and click Create API Key.
#. Save the Public Key and Private Key right away. LATOKEN will not show them again.

**Which permissions to turn on:** Choose the Trading on Spot permission set. It can view your account and market data and place and cancel orders (PLACE_ORDER, CANCEL_ORDER), but it cannot move funds. Do not pick the sets that add transfers, withdrawals (WITHDRAW_WALLET) or BYPASS_2FA. A bot never needs to move money out of your account.

.. warning::

   Never turn on withdrawals for a Latoken trading bot key. Bind the key to your server's IP address when Latoken lets you, keep the secret out of your code and out of Git, and delete the key if it ever leaks.

Connect Latoken to LumiBot
--------------------------

The simplest way: put these lines in a ``.env`` file next to your strategy. LumiBot loads the file, sees ``TRADING_BROKER=latoken`` and connects to Latoken for you, so your strategy needs no broker code.

.. code-block:: bash

   TRADING_BROKER=latoken
   LATOKEN_API_KEY=your_apiKey
   LATOKEN_API_SECRET=your_secret

LumiBot reads exactly the fields CCXT needs for Latoken (``apiKey``, ``secret``). If one is missing, LumiBot stops at start-up and names the variable you still need.

You can also build the broker in code. This is handy when one script talks to more than one exchange, or when you need extra CCXT options. The keys in the config are CCXT's own credential names for Latoken:

.. code-block:: python

   import os

   LATOKEN_CONFIG = {
       "exchange_id": "latoken",
       "apiKey": os.environ.get("LATOKEN_API_KEY"),
       "secret": os.environ.get("LATOKEN_API_SECRET"),
       "sandbox": False,  # no sandbox for this exchange
   }

   from lumibot.brokers import Ccxt

   broker = Ccxt(LATOKEN_CONFIG)
   # then: MyStrategy(broker=broker, ...)

Either way, LumiBot turns on CCXT's built-in rate limiting for you.

Testing on Latoken
------------------

LATOKEN has no sandbox, and CCXT lists no test URL for it, so test with a very small amount. With environment variables, leave ``LATOKEN_SANDBOX`` unset. In a code config, set ``"sandbox": False``.

Algorithmic trading example: a simple Latoken bot
-------------------------------------------------

This bot buys about 50 USDT of BTC on Latoken once and then holds it. It is a starting point to check that your keys, balances and orders work. If the exchange's minimum order is larger, raise the amount.

.. code-block:: python

   from lumibot.entities import Asset
   from lumibot.strategies import Strategy


   class LatokenBuyOnce(Strategy):
       """Buy a small amount of BTC once, then hold it."""

       def initialize(self):
           self.sleeptime = "1H"
           self.set_market("24/7")  # crypto trades all day, every day

       def on_trading_iteration(self):
           coin = Asset("BTC", asset_type=Asset.AssetType.CRYPTO)
           if self.get_position(coin) is not None:
               return  # already holding BTC
           price = self.get_last_price(coin, quote=self.quote_asset)
           if price:
               quantity = round(50 / price, 6)  # about 50 USDT worth
               order = self.create_order(coin, quantity, "buy", quote=self.quote_asset)
               self.submit_order(order)


   if __name__ == "__main__":
       # LumiBot reads TRADING_BROKER and the keys from your .env file.
       strategy = LatokenBuyOnce(quote_asset=Asset("USDT", asset_type=Asset.AssetType.CRYPTO))
       strategy.run_live()

Agentic trading example: an AI agent that trades on Latoken
-----------------------------------------------------------

Agentic trading means an AI agent reads the market and decides what to do. In this example one LumiBot agent looks at prices and your Latoken account, then places the orders itself. There is no Python logic in between: you set the rules in plain English in the prompt, such as what it may trade and how big each order can be. This follows the same pattern as LumiBot's AI trading team examples.

.. code-block:: python

   from lumibot.entities import Asset
   from lumibot.strategies import Strategy


   class LatokenAITrader(Strategy):
       """One AI agent researches the market and places the trades itself."""

       def initialize(self):
           self.sleeptime = "4H"
           self.set_market("24/7")
           self.agents.create(
               name="trader",
               model="openai/gpt-6-luna",
               reasoning_effort="high",
               allow_trading=True,
               system_prompt=(
                   "You manage a small crypto account on Latoken. "
                   "You may trade BTC and ETH against USDT (asset_type 'crypto', quote_symbol 'USDT'), or hold cash. "
                   "Before every order, call account_portfolio, account_positions and "
                   "market_last_price for that exact symbol in the same run. "
                   "Keep each order under 10% of the account value. "
                   "Explain each decision in one short paragraph."
               ),
           )

       def on_trading_iteration(self):
           self.agents["trader"].run(
               task_prompt="Review recent BTC/USDT and ETH/USDT prices and your current holdings, then decide whether to buy, sell or hold.",
               context={"exchange": "Latoken", "quote": "USDT", "date": self.get_datetime().isoformat()},
           )


   if __name__ == "__main__":
       # LumiBot reads TRADING_BROKER and the keys from your .env file.
       strategy = LatokenAITrader(quote_asset=Asset("USDT", asset_type=Asset.AssetType.CRYPTO))
       strategy.run_live()

The agent needs a model key such as ``OPENAI_API_KEY`` in your environment. See the :doc:`AI agents quickstart <agents_quickstart>` for models, tools and memory.

Latoken tips
------------

* LATOKEN splits your money into a Wallet account (deposits and withdrawals) and a Spot account (trading). The bot can only trade coins in the Spot account, so move funds from Wallet to Spot first, or turn on Auto-transfer in settings.
* The Trading on Spot set keeps the bot limited to your Spot balance. Coins left in your Wallet account stay out of its reach.
* To revoke a key, click the x in the top-right corner of its box on the API Keys page. This deletes the key for good.

Frequently asked questions
--------------------------

**Can I build a Latoken trading bot in Python?**

Yes. Install LumiBot (``pip install lumibot``), set your Latoken keys and use the ``latoken`` CCXT exchange id as shown above.

**Does Latoken have a testnet?**

No testnet is set up for Latoken in LumiBot. Start with a small amount, and in a code config set ``"sandbox": False``.

**Which API permissions does a Latoken bot need?**

Choose the Trading on Spot permission set. It can view your account and market data and place and cancel orders (PLACE_ORDER, CANCEL_ORDER), but it cannot move funds. Do not pick the sets that add transfers, withdrawals (WITHDRAW_WALLET) or BYPASS_2FA. A bot never needs to move money out of your account.

**Can an AI agent trade on Latoken by itself?**

Yes. The agentic example above gives one agent permission to trade. You control what it may trade and how much through its prompt.

**Can I trade Latoken perpetual futures with LumiBot?**

CCXT does not list perpetual swaps for Latoken, so use spot markets.

**Is LumiBot free?**

Yes. LumiBot is open source on GitHub at https://github.com/Lumiwealth/lumibot. You pay only your exchange's trading fees and, for AI agents, your model provider.
