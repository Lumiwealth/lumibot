# Star History README Chart

One-line description: Root-cause note for the broken README star history embed.

Last Updated: 2026-07-08

Status: Fixed locally

Audience: Maintainers and release agents

## Overview

The README Project Growth chart broke because it depended on Star History's live
SVG endpoint:

```text
https://api.star-history.com/svg?repos=Lumiwealth/lumibot&type=Date
```

On 2026-07-06, Star History documented that GitHub's 2026-06-30 stargazer API
restriction broke live README embeds. The stargazer timestamp endpoint now
requires authentication for the repository, so a third-party server that is not
a repository collaborator can no longer build the public chart reliably.

Local verification on 2026-07-08:

- The old Star History SVG endpoint returned HTTP 503.
- Unauthenticated GitHub API access to
  `repos/Lumiwealth/lumibot/stargazers` returned HTTP 401.
- Authenticated `gh api` access returned `starred_at` timestamps.

## Fix

The README now points to a repository-owned SVG:

```text
docs/assets/readme/star_history.svg
```

The SVG is generated by:

```text
scripts/update_star_history_chart.py
```

The scheduled/manual GitHub Action at:

```text
.github/workflows/star-history.yml
```

refreshes the asset using the repository's GitHub token and commits the updated
SVG only when the aggregate chart changes.

## Maintenance Notes

- Do not put a personal access token or Star History encrypted token in the
  public README.
- The committed SVG contains only aggregate monthly star counts, not individual
  stargazer identities.
- If GitHub changes the stargazer timestamp endpoint again, update the generator
  or replace the chart with a static, repo-owned asset rather than restoring the
  third-party live embed.
