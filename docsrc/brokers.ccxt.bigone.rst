What is BigONE?
---------------

BigONE is a crypto exchange with spot trading, leverage and futures. Its contract API covers USDT-margined and coin-margined contracts.

Sign up for BigONE
------------------

#. Sign up on the BigONE website or app with an email address or phone number, and enter the code BigONE sends within 15 minutes.
#. Set a password and agree to the User Agreement and Privacy Statement.
#. Turn on two-factor authentication (email or Google Authenticator), which BigONE asks for when you create an API key. Complete KYC too; BigONE's Help Center has a KYC guide.

`Open a BigONE account <https://big.one>`_

Create a BigONE API key
-----------------------

#. Log in to your BigONE account and go to API Settings (also listed as User Center, API Management).
#. Click Create API Key.
#. Choose the permission scopes (see below) and add your bot's IP address to the IP whitelist.
#. Finish the two-factor authentication (2FA) check.
#. Save the API Secret right away. BigONE shows it only once. If you lose it, delete the key and make a new one.

**Which permissions to turn on:** Turn on View Account Balance Information, View Order Information, Create Orders and View Trade Information. For contracts, also turn on Access Contract and Create Contract. Leave Execute Withdrawals off. A bot never needs to move money out of your account.

.. warning::

   Never turn on withdrawals for a BigONE trading bot key. Bind the key to your server's IP address when BigONE lets you, keep the secret out of your code and out of Git, and delete the key if it ever leaks.

Connect BigONE to LumiBot
-------------------------

The simplest way: put these lines in a ``.env`` file next to your strategy. LumiBot loads the file, sees ``TRADING_BROKER=bigone`` and connects to BigONE for you, so your strategy needs no broker code.

.. code-block:: bash

   TRADING_BROKER=bigone
   BIGONE_API_KEY=your_apiKey
   BIGONE_API_SECRET=your_secret

LumiBot reads exactly the fields CCXT needs for BigONE (``apiKey``, ``secret``). If one is missing, LumiBot stops at start-up and names the variable you still need.

You can also build the broker in code. This is handy when one script talks to more than one exchange, or when you need extra CCXT options. The keys in the config are CCXT's own credential names for BigONE:

.. code-block:: python

   import os

   BIGONE_CONFIG = {
       "exchange_id": "bigone",
       "apiKey": os.environ.get("BIGONE_API_KEY"),
       "secret": os.environ.get("BIGONE_API_SECRET"),
       "sandbox": False,  # no sandbox for this exchange
   }

   from lumibot.brokers import Ccxt

   broker = Ccxt(BIGONE_CONFIG)
   # then: MyStrategy(broker=broker, ...)

Either way, LumiBot turns on CCXT's built-in rate limiting for you.

Testing on BigONE
-----------------

BigONE has no sandbox. Test with a very small amount, leave ``BIGONE_SANDBOX`` unset, and in a code config set ``"sandbox": False``.

Algorithmic trading example: a simple BigONE bot
------------------------------------------------

This bot buys about 50 USDT of BTC on BigONE once and then holds it. It is a starting point to check that your keys, balances and orders work. If the exchange's minimum order is larger, raise the amount.

.. code-block:: python

   from lumibot.entities import Asset
   from lumibot.strategies import Strategy


   class BigoneBuyOnce(Strategy):
       """Buy a small amount of BTC once, then hold it."""

       def initialize(self):
           self.sleeptime = "1H"
           self.set_market("24/7")  # crypto trades all day, every day

       def on_trading_iteration(self):
           coin = Asset("BTC", asset_type=Asset.AssetType.CRYPTO)
           if self.get_position(coin) is not None:
               return  # already holding BTC
           price = self.get_last_price(coin, quote=self.quote_asset)
           if price:
               quantity = round(50 / price, 6)  # about 50 USDT worth
               order = self.create_order(coin, quantity, "buy", quote=self.quote_asset)
               self.submit_order(order)


   if __name__ == "__main__":
       # LumiBot reads TRADING_BROKER and the keys from your .env file.
       strategy = BigoneBuyOnce(quote_asset=Asset("USDT", asset_type=Asset.AssetType.CRYPTO))
       strategy.run_live()

Agentic trading example: an AI agent that trades on BigONE
----------------------------------------------------------

Agentic trading means an AI agent reads the market and decides what to do. In this example one LumiBot agent looks at prices and your BigONE account, then places the orders itself. There is no Python logic in between: you set the rules in plain English in the prompt, such as what it may trade and how big each order can be. This follows the same pattern as LumiBot's AI trading team examples.

.. code-block:: python

   from lumibot.entities import Asset
   from lumibot.strategies import Strategy


   class BigoneAITrader(Strategy):
       """One AI agent researches the market and places the trades itself."""

       def initialize(self):
           self.sleeptime = "4H"
           self.set_market("24/7")
           self.agents.create(
               name="trader",
               model="openai/gpt-6-luna",
               reasoning_effort="high",
               allow_trading=True,
               system_prompt=(
                   "You manage a small crypto account on BigONE. "
                   "You may trade BTC and ETH against USDT (asset_type 'crypto', quote_symbol 'USDT'), or hold cash. "
                   "Before every order, call account_portfolio, account_positions and "
                   "market_last_price for that exact symbol in the same run. "
                   "Keep each order under 10% of the account value. "
                   "Explain each decision in one short paragraph."
               ),
           )

       def on_trading_iteration(self):
           self.agents["trader"].run(
               task_prompt="Review recent BTC/USDT and ETH/USDT prices and your current holdings, then decide whether to buy, sell or hold.",
               context={"exchange": "BigONE", "quote": "USDT", "date": self.get_datetime().isoformat()},
           )


   if __name__ == "__main__":
       # LumiBot reads TRADING_BROKER and the keys from your .env file.
       strategy = BigoneAITrader(quote_asset=Asset("USDT", asset_type=Asset.AssetType.CRYPTO))
       strategy.run_live()

The agent needs a model key such as ``OPENAI_API_KEY`` in your environment. See the :doc:`AI agents quickstart <agents_quickstart>` for models, tools and memory.

BigONE tips
-----------

* BigONE needs only two credentials: the API key (``BIGONE_API_KEY``) and the API Secret (``BIGONE_API_SECRET``). There is no passphrase.
* Each key can be bound to up to 20 IP addresses or ranges (CIDR like ``192.168.1.0/24`` works). BigONE recommends always using the IP whitelist.
* A 10403 Permission denied error means the key is missing a scope or the request came from an IP that is not on the whitelist. You can edit scopes and IPs later, but you cannot see the secret again.
* Spot symbols look like ``BTC/USDT``. USDT-margined contracts use the CCXT form ``BTC/USDT:USDT``, and coin-margined ones ``BTC/USD:BTC``.

Frequently asked questions
--------------------------

**Can I build a BigONE trading bot in Python?**

Yes. Install LumiBot (``pip install lumibot``), set your BigONE keys and use the ``bigone`` CCXT exchange id as shown above.

**Does BigONE have a testnet?**

No testnet is set up for BigONE in LumiBot. Start with a small amount, and in a code config set ``"sandbox": False``.

**Which API permissions does a BigONE bot need?**

Turn on View Account Balance Information, View Order Information, Create Orders and View Trade Information. For contracts, also turn on Access Contract and Create Contract. Leave Execute Withdrawals off. A bot never needs to move money out of your account.

**Can an AI agent trade on BigONE by itself?**

Yes. The agentic example above gives one agent permission to trade. You control what it may trade and how much through its prompt.

**Can I trade BigONE perpetual futures with LumiBot?**

CCXT lists perpetual swaps for this exchange. Use the full contract symbol, such as ``BTC/USDT:USDT``.

**Is LumiBot free?**

Yes. LumiBot is open source on GitHub at https://github.com/Lumiwealth/lumibot. You pay only your exchange's trading fees and, for AI agents, your model provider.
