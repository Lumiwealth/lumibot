What is Coins.ph?
-----------------

Coins.ph is an e-wallet and crypto app where you can buy and sell crypto in pesos (PHP). Its Spot Trade exchange offers PHP and crypto trading pairs, and that is what LumiBot trades on.

Sign up for Coins.ph
--------------------

#. Create a Coins.ph account.
#. Finish ID and selfie verification (or higher). Coins.ph requires this before you can create an API key.
#. Turn on two-factor authentication (2FA). Coins.ph will not let you create an API key or a sub-account without it.

`Open a Coins.ph account <https://coins.ph/>`_

Create a Coins.ph API key
-------------------------

#. Log in to Coins.ph on the website, click your profile in the lower left and open Account Settings.
#. Under the Security section, click Manage next to API Management.
#. Click Create API at the top and enter API Remarks (a name for the key).
#. Enter your Google Authenticator (2FA) code.
#. Copy the Secret right away. Coins.ph shows it only once. If you lose it, you must delete the key and make a new one.
#. Click Bind IP Whitelist and add the IP address of your bot. Each key needs at least 1 and at most 5 whitelisted IP addresses.

**Which permissions to turn on:** Coins.ph API keys list their access as Read only, Enable Spot, Enable Convert, Enable Crypto Wallet, Enable Fiat and Enable Account. For a trading bot, turn on Enable Spot. Leave Enable Crypto Wallet and Enable Fiat off, and keep withdrawals off. A bot never needs to move money out of your account.

.. warning::

   Never turn on withdrawals for a Coins.ph trading bot key. Bind the key to your server's IP address when Coins.ph lets you, keep the secret out of your code and out of Git, and delete the key if it ever leaks.

Connect Coins.ph to LumiBot
---------------------------

The simplest way: put these lines in a ``.env`` file next to your strategy. LumiBot loads the file, sees ``TRADING_BROKER=coinsph`` and connects to Coins.ph for you, so your strategy needs no broker code.

.. code-block:: bash

   TRADING_BROKER=coinsph
   COINSPH_API_KEY=your_apiKey
   COINSPH_API_SECRET=your_secret

LumiBot reads exactly the fields CCXT needs for Coins.ph (``apiKey``, ``secret``). If one is missing, LumiBot stops at start-up and names the variable you still need.

You can also build the broker in code. This is handy when one script talks to more than one exchange, or when you need extra CCXT options. The keys in the config are CCXT's own credential names for Coins.ph:

.. code-block:: python

   import os

   COINSPH_CONFIG = {
       "exchange_id": "coinsph",
       "apiKey": os.environ.get("COINSPH_API_KEY"),
       "secret": os.environ.get("COINSPH_API_SECRET"),
       "sandbox": False,  # live connection
   }

   from lumibot.brokers import Ccxt

   broker = Ccxt(COINSPH_CONFIG)
   # then: MyStrategy(broker=broker, ...)

Either way, LumiBot turns on CCXT's built-in rate limiting for you.

Testing on Coins.ph
-------------------

Coins.ph has no sandbox, and CCXT lists no test URL for it, so test with a very small amount. With environment variables, leave ``COINSPH_SANDBOX`` unset. In a code config, set ``"sandbox": False``.

Algorithmic trading example: a simple Coins.ph bot
--------------------------------------------------

This bot buys about 3000 PHP of BTC on Coins.ph once and then holds it. It is a starting point to check that your keys, balances and orders work. If the exchange's minimum order is larger, raise the amount. Coins.ph accepts only limit orders through CCXT, so the example places a limit order just above the last price.

.. code-block:: python

   from lumibot.entities import Asset
   from lumibot.strategies import Strategy


   class CoinsphBuyOnce(Strategy):
       """Buy a small amount of BTC once, then hold it."""

       def initialize(self):
           self.sleeptime = "1H"
           self.set_market("24/7")  # crypto trades all day, every day

       def on_trading_iteration(self):
           coin = Asset("BTC", asset_type=Asset.AssetType.CRYPTO)
           if self.get_position(coin) is not None:
               return  # already holding BTC
           price = self.get_last_price(coin, quote=self.quote_asset)
           if price:
               quantity = round(3000 / price, 6)  # about 3000 PHP worth
               # This exchange takes only limit orders through CCXT.
               order = self.create_order(coin, quantity, "buy", limit_price=price * 1.002, quote=self.quote_asset)
               self.submit_order(order)


   if __name__ == "__main__":
       # LumiBot reads TRADING_BROKER and the keys from your .env file.
       strategy = CoinsphBuyOnce(quote_asset=Asset("PHP", asset_type=Asset.AssetType.CRYPTO))
       strategy.run_live()

Agentic trading example: an AI agent that trades on Coins.ph
------------------------------------------------------------

Agentic trading means an AI agent reads the market and decides what to do. In this example one LumiBot agent looks at prices and your Coins.ph account, then places the orders itself. There is no Python logic in between: you set the rules in plain English in the prompt, such as what it may trade and how big each order can be. This follows the same pattern as LumiBot's AI trading team examples.

.. code-block:: python

   from lumibot.entities import Asset
   from lumibot.strategies import Strategy


   class CoinsphAITrader(Strategy):
       """One AI agent researches the market and places the trades itself."""

       def initialize(self):
           self.sleeptime = "4H"
           self.set_market("24/7")
           self.agents.create(
               name="trader",
               model="openai/gpt-6-luna",
               reasoning_effort="high",
               allow_trading=True,
               system_prompt=(
                   "You manage a small crypto account on Coins.ph. "
                   "You may trade BTC and ETH against PHP (asset_type 'crypto', quote_symbol 'PHP'), or hold cash. "
                   "Before every order, call account_portfolio, account_positions and "
                   "market_last_price for that exact symbol in the same run. "
                   "Keep each order under 10% of the account value. "
                   "Explain each decision in one short paragraph."
               ),
           )

       def on_trading_iteration(self):
           self.agents["trader"].run(
               task_prompt="Review recent BTC/PHP and ETH/PHP prices and your current holdings, then decide whether to buy, sell or hold.",
               context={"exchange": "Coins.ph", "quote": "PHP", "date": self.get_datetime().isoformat()},
           )


   if __name__ == "__main__":
       # LumiBot reads TRADING_BROKER and the keys from your .env file.
       strategy = CoinsphAITrader(quote_asset=Asset("PHP", asset_type=Asset.AssetType.CRYPTO))
       strategy.run_live()

The agent needs a model key such as ``OPENAI_API_KEY`` in your environment. See the :doc:`AI agents quickstart <agents_quickstart>` for models, tools and memory.

Fees and partner IDs on Coins.ph
--------------------------------

You pay Coins.ph's normal trading fees. LumiBot may attach its own exchange partner ID. That costs you nothing extra. LumiBot never adds an extra builder fee unless one is turned on, and it logs a warning when one is.

Coins.ph tips
-------------

* Each Coins.ph account can create only 1 API key. If you need more, use sub-accounts: a main account can have up to 30, each with its own API key.
* Coins.ph sub-accounts can only trade through the API, and their trade history is only visible through the API, not the website. A separate sub-account per bot keeps bot trades apart from your own.
* Coins.ph Spot Trade markets are quoted in PHP, USDT or USDC, for example ``BTC/PHP`` or ``BTC/USDT``. Minimum order sizes vary by pair.

Frequently asked questions
--------------------------

**Can I build a Coins.ph trading bot in Python?**

Yes. Install LumiBot (``pip install lumibot``), set your Coins.ph keys and use the ``coinsph`` CCXT exchange id as shown above.

**Does Coins.ph have a testnet?**

No testnet is set up for Coins.ph in LumiBot. Start with a small amount, and in a code config set ``"sandbox": False``.

**Which API permissions does a Coins.ph bot need?**

Coins.ph API keys list their access as Read only, Enable Spot, Enable Convert, Enable Crypto Wallet, Enable Fiat and Enable Account. For a trading bot, turn on Enable Spot. Leave Enable Crypto Wallet and Enable Fiat off, and keep withdrawals off. A bot never needs to move money out of your account.

**Can an AI agent trade on Coins.ph by itself?**

Yes. The agentic example above gives one agent permission to trade. You control what it may trade and how much through its prompt.

**Can I trade Coins.ph perpetual futures with LumiBot?**

CCXT does not list perpetual swaps for Coins.ph, so use spot markets.

**Is LumiBot free?**

Yes. LumiBot is open source on GitHub at https://github.com/Lumiwealth/lumibot. You pay only your exchange's trading fees and, for AI agents, your model provider.
