What is Bitrue?
---------------

Bitrue is a crypto exchange for spot trading plus USDT-margined and coin-margined futures. Its API covers spot trading, futures trading, asset transfers and market data.

Sign up for Bitrue
------------------

#. Register an account on bitrue.com.
#. Finish KYC: click Verification, then ID Verification. Level 1 asks for personal details and your mobile number. Level 2 asks for an ID document and its number.
#. Bind Google Authenticator under Account Security and back up the security key. Bitrue needs it to create an API key.

`Open a Bitrue account <https://www.bitrue.com>`_

Create a Bitrue API key
-----------------------

#. Log in and click the API menu under your avatar in the top bar (https://www.bitrue.com/account/api).
#. Create a new API key and enter a note name for it, for example the name of your bot.
#. Enter the code from your Google Authenticator app.
#. Open the link in the email Bitrue sends you to finish verification, then select the permissions you need.
#. Add your bot's IP address (up to 16 per key, separated by commas).
#. Copy the secret key right away. Bitrue shows it only once, when the key is created.

**Which permissions to turn on:** Pick read and trading access only. Bitrue's help guide shows the permission choices on screen but does not name them in text, so choose the trading permission for the market you trade (spot or futures). Leave withdrawals off. Bitrue's API docs say a withdraw permission also needs an IP limit and a withdraw address whitelist, so a bot key without it is safer.

.. warning::

   Never turn on withdrawals for a Bitrue trading bot key. Bind the key to your server's IP address when Bitrue lets you, keep the secret out of your code and out of Git, and delete the key if it ever leaks.

Connect Bitrue to LumiBot
-------------------------

The simplest way: put these lines in a ``.env`` file next to your strategy. LumiBot loads the file, sees ``TRADING_BROKER=bitrue`` and connects to Bitrue for you, so your strategy needs no broker code.

.. code-block:: bash

   TRADING_BROKER=bitrue
   BITRUE_API_KEY=your_apiKey
   BITRUE_API_SECRET=your_secret

LumiBot reads exactly the fields CCXT needs for Bitrue (``apiKey``, ``secret``). If one is missing, LumiBot stops at start-up and names the variable you still need.

You can also build the broker in code. This is handy when one script talks to more than one exchange, or when you need extra CCXT options. The keys in the config are CCXT's own credential names for Bitrue:

.. code-block:: python

   import os

   BITRUE_CONFIG = {
       "exchange_id": "bitrue",
       "apiKey": os.environ.get("BITRUE_API_KEY"),
       "secret": os.environ.get("BITRUE_API_SECRET"),
       "sandbox": False,  # no sandbox for this exchange
   }

   from lumibot.brokers import Ccxt

   broker = Ccxt(BITRUE_CONFIG)
   # then: MyStrategy(broker=broker, ...)

Either way, LumiBot turns on CCXT's built-in rate limiting for you.

Algorithmic trading example: a simple Bitrue bot
------------------------------------------------

This bot buys about 50 USDT of BTC on Bitrue once and then holds it. It is a starting point to check that your keys, balances and orders work. If the exchange's minimum order is larger, raise the amount.

.. code-block:: python

   from lumibot.entities import Asset
   from lumibot.strategies import Strategy


   class BitrueBuyOnce(Strategy):
       """Buy a small amount of BTC once, then hold it."""

       def initialize(self):
           self.sleeptime = "1H"
           self.set_market("24/7")  # crypto trades all day, every day

       def on_trading_iteration(self):
           coin = Asset("BTC", asset_type=Asset.AssetType.CRYPTO)
           if self.get_position(coin) is not None:
               return  # already holding BTC
           price = self.get_last_price(coin, quote=self.quote_asset)
           if price:
               quantity = round(50 / price, 6)  # about 50 USDT worth
               order = self.create_order(coin, quantity, "buy", quote=self.quote_asset)
               self.submit_order(order)


   if __name__ == "__main__":
       # LumiBot reads TRADING_BROKER and the keys from your .env file.
       strategy = BitrueBuyOnce(quote_asset=Asset("USDT", asset_type=Asset.AssetType.CRYPTO))
       strategy.run_live()

Agentic trading example: an AI agent that trades on Bitrue
----------------------------------------------------------

Agentic trading means an AI agent reads the market and decides what to do. In this example one LumiBot agent looks at prices and your Bitrue account, then places the orders itself. There is no Python logic in between: you set the rules in plain English in the prompt, such as what it may trade and how big each order can be. This follows the same pattern as LumiBot's AI trading team examples.

.. code-block:: python

   from lumibot.entities import Asset
   from lumibot.strategies import Strategy


   class BitrueAITrader(Strategy):
       """One AI agent researches the market and places the trades itself."""

       def initialize(self):
           self.sleeptime = "4H"
           self.set_market("24/7")
           self.agents.create(
               name="trader",
               model="openai/gpt-6-luna",
               reasoning_effort="high",
               allow_trading=True,
               system_prompt=(
                   "You manage a small crypto account on Bitrue. "
                   "You may trade BTC and ETH against USDT (asset_type 'crypto', quote_symbol 'USDT'), or hold cash. "
                   "Before every order, call account_portfolio, account_positions and "
                   "market_last_price for that exact symbol in the same run. "
                   "Keep each order under 10% of the account value. "
                   "Explain each decision in one short paragraph."
               ),
           )

       def on_trading_iteration(self):
           self.agents["trader"].run(
               task_prompt="Review recent BTC/USDT and ETH/USDT prices and your current holdings, then decide whether to buy, sell or hold.",
               context={"exchange": "Bitrue", "quote": "USDT", "date": self.get_datetime().isoformat()},
           )


   if __name__ == "__main__":
       # LumiBot reads TRADING_BROKER and the keys from your .env file.
       strategy = BitrueAITrader(quote_asset=Asset("USDT", asset_type=Asset.AssetType.CRYPTO))
       strategy.run_live()

The agent needs a model key such as ``OPENAI_API_KEY`` in your environment. See the :doc:`AI agents quickstart <agents_quickstart>` for models, tools and memory.

Bitrue tips
-----------

* Bitrue's spot REST API lives at https://openapi.bitrue.com. Bitrue writes symbols with no separator (``BTCUSDT``); in LumiBot and CCXT use ``BTC/USDT`` for spot and ``BTC/USDT:USDT`` for the USDT-margined perpetual.
* Keep polling modest. Bitrue's docs list order limits of 100 weight per 60 seconds and warn that repeated 429 errors lead to an automatic IP ban lasting from 2 minutes to 3 days.
* API keys and secrets are case sensitive. Copy them exactly.
