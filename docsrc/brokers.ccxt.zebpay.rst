What is Zebpay?
---------------

ZebPay is a crypto exchange with spot markets, including crypto pairs priced in Indian rupees (INR), and perpetual futures. ZebPay says it has 40+ spot markets and 60+ futures markets that share one API sign-in system.

Sign up for Zebpay
------------------

#. Create a ZebPay account and finish KYC verification. Your KYC status shows on the My Account page.
#. Make sure your mobile number and email are confirmed. ZebPay sends a 6-digit code to both when you create an API key.
#. ZebPay's own docs describe no public testnet, so plan to test with a very small amount.

`Open a Zebpay account <https://zebpay.com/>`_

Create a Zebpay API key
-----------------------

#. Log in to ZebPay in a web browser.
#. Go to API Trading from the navigation bar on the left and click Create New API Key.
#. Name your key and choose the permissions (see below).
#. Add your bot's IP address to the IP whitelist. It is optional, but it limits the key to your machine.
#. Enter the 6-digit code ZebPay sends to your mobile number and email.
#. Save the Secret Key right away. ZebPay shows it only once.

**Which permissions to turn on:** ZebPay keys have Read, Trade and Withdraw permissions. Turn on Read and Trade. Leave Withdraw off. A trading bot never needs to move money out of your account.

.. warning::

   Never turn on withdrawals for a Zebpay trading bot key. Bind the key to your server's IP address when Zebpay lets you, keep the secret out of your code and out of Git, and delete the key if it ever leaks.

Connect Zebpay to LumiBot
-------------------------

The simplest way: put these lines in a ``.env`` file next to your strategy. LumiBot loads the file, sees ``TRADING_BROKER=zebpay`` and connects to Zebpay for you, so your strategy needs no broker code.

.. code-block:: bash

   TRADING_BROKER=zebpay
   ZEBPAY_API_KEY=your_apiKey
   ZEBPAY_API_SECRET=your_secret

LumiBot reads exactly the fields CCXT needs for Zebpay (``apiKey``, ``secret``). If one is missing, LumiBot stops at start-up and names the variable you still need.

You can also build the broker in code. This is handy when one script talks to more than one exchange, or when you need extra CCXT options. The keys in the config are CCXT's own credential names for Zebpay:

.. code-block:: python

   import os

   ZEBPAY_CONFIG = {
       "exchange_id": "zebpay",
       "apiKey": os.environ.get("ZEBPAY_API_KEY"),
       "secret": os.environ.get("ZEBPAY_API_SECRET"),
       "sandbox": False,  # no sandbox for this exchange
   }

   from lumibot.brokers import Ccxt

   broker = Ccxt(ZEBPAY_CONFIG)
   # then: MyStrategy(broker=broker, ...)

Either way, LumiBot turns on CCXT's built-in rate limiting for you.

Testing on Zebpay
-----------------

CCXT lists a ZebPay staging address (zebstage.com), but ZebPay's own API docs do not describe a public testnet or how to get keys for it. Test with a very small amount on the live exchange instead. With environment variables, leave ``ZEBPAY_SANDBOX`` unset. In a code config, set ``"sandbox": False``.

Algorithmic trading example: a simple Zebpay bot
------------------------------------------------

This bot buys about 4500 INR of BTC on Zebpay once and then holds it. It is a starting point to check that your keys, balances and orders work. If the exchange's minimum order is larger, raise the amount.

.. code-block:: python

   from lumibot.entities import Asset
   from lumibot.strategies import Strategy


   class ZebpayBuyOnce(Strategy):
       """Buy a small amount of BTC once, then hold it."""

       def initialize(self):
           self.sleeptime = "1H"
           self.set_market("24/7")  # crypto trades all day, every day

       def on_trading_iteration(self):
           coin = Asset("BTC", asset_type=Asset.AssetType.CRYPTO)
           if self.get_position(coin) is not None:
               return  # already holding BTC
           price = self.get_last_price(coin, quote=self.quote_asset)
           if price:
               quantity = round(4500 / price, 6)  # about 4500 INR worth
               order = self.create_order(coin, quantity, "buy", quote=self.quote_asset)
               self.submit_order(order)


   if __name__ == "__main__":
       # LumiBot reads TRADING_BROKER and the keys from your .env file.
       strategy = ZebpayBuyOnce(quote_asset=Asset("INR", asset_type=Asset.AssetType.CRYPTO))
       strategy.run_live()

Agentic trading example: an AI agent that trades on Zebpay
----------------------------------------------------------

Agentic trading means an AI agent reads the market and decides what to do. In this example one LumiBot agent looks at prices and your Zebpay account, then places the orders itself. There is no Python logic in between: you set the rules in plain English in the prompt, such as what it may trade and how big each order can be. This follows the same pattern as LumiBot's AI trading team examples.

.. code-block:: python

   from lumibot.entities import Asset
   from lumibot.strategies import Strategy


   class ZebpayAITrader(Strategy):
       """One AI agent researches the market and places the trades itself."""

       def initialize(self):
           self.sleeptime = "4H"
           self.set_market("24/7")
           self.agents.create(
               name="trader",
               model="openai/gpt-6-luna",
               reasoning_effort="high",
               allow_trading=True,
               system_prompt=(
                   "You manage a small crypto account on Zebpay. "
                   "You may trade BTC and ETH against INR (asset_type 'crypto', quote_symbol 'INR'), or hold cash. "
                   "Before every order, call account_portfolio, account_positions and "
                   "market_last_price for that exact symbol in the same run. "
                   "Keep each order under 10% of the account value. "
                   "Explain each decision in one short paragraph."
               ),
           )

       def on_trading_iteration(self):
           self.agents["trader"].run(
               task_prompt="Review recent BTC/INR and ETH/INR prices and your current holdings, then decide whether to buy, sell or hold.",
               context={"exchange": "Zebpay", "quote": "INR", "date": self.get_datetime().isoformat()},
           )


   if __name__ == "__main__":
       # LumiBot reads TRADING_BROKER and the keys from your .env file.
       strategy = ZebpayAITrader(quote_asset=Asset("INR", asset_type=Asset.AssetType.CRYPTO))
       strategy.run_live()

The agent needs a model key such as ``OPENAI_API_KEY`` in your environment. See the :doc:`AI agents quickstart <agents_quickstart>` for models, tools and memory.

Zebpay tips
-----------

* ZebPay spot markets include rupee pairs such as ``BTC/INR`` and USDT pairs such as ``BTC/USDT``. Perpetual futures use the full CCXT form, for example ``BTC/USDT:USDT``.
* Spot and futures use different API hosts (sapi.zebpay.com for spot, futuresbe.zebpay.com for futures), but ZebPay says they share the same authentication framework. CCXT picks the right host for you.
* You can see each key's rate limits and revoke a key at any time from My Account.
* ZebPay's official API docs are on GitHub at https://github.com/zebpay/zebpay-api-references. ZebPay notes the spot docs are still being expanded.

Frequently asked questions
--------------------------

**Can I build a Zebpay trading bot in Python?**

Yes. Install LumiBot (``pip install lumibot``), set your Zebpay keys and use the ``zebpay`` CCXT exchange id as shown above.

**Does Zebpay have a testnet?**

No testnet is set up for Zebpay in LumiBot. Start with a small amount, and in a code config set ``"sandbox": False``.

**Which API permissions does a Zebpay bot need?**

ZebPay keys have Read, Trade and Withdraw permissions. Turn on Read and Trade. Leave Withdraw off. A trading bot never needs to move money out of your account.

**Can an AI agent trade on Zebpay by itself?**

Yes. The agentic example above gives one agent permission to trade. You control what it may trade and how much through its prompt.

**Can I trade Zebpay perpetual futures with LumiBot?**

CCXT lists perpetual swaps for this exchange. Use the full contract symbol, such as ``BTC/USDT:USDT``.

**Is LumiBot free?**

Yes. LumiBot is open source on GitHub at https://github.com/Lumiwealth/lumibot. You pay only your exchange's trading fees and, for AI agents, your model provider.
