What is CoinEx?
---------------

CoinEx is a crypto exchange for spot trading and futures. Its v2 API serves both spot and futures markets from one base address.

Sign up for CoinEx
------------------

#. Create a CoinEx account on the website or app.
#. Turn on two-factor authentication (SMS, an authenticator app or a passkey). CoinEx asks for a 2FA code when you create an API key.
#. CoinEx has no testnet, so plan to start with a very small trade.

`Open a CoinEx account <https://www.coinex.com/>`_

Create a CoinEx API key
-----------------------

#. Log in at https://www.coinex.com, click your avatar in the top right corner and pick API Management.
#. Click Create API.
#. Enter an API Remark (a name for the key) and the Applicable IP address: the public IP of the machine running your bot. You can list up to 50 addresses, one per line.
#. Tick Trade. Leave Withdraw unticked.
#. Enter your 2FA code (SMS, authenticator app or passkey) and click Create.
#. Copy the Access ID (your API key) and Secret Key. The key starts working within 10 to 15 minutes.

**Which permissions to turn on:** Tick Trade so the bot can place and cancel orders. Leave Withdraw unticked. A trading bot never needs to move money out of your account.

.. warning::

   Never turn on withdrawals for a CoinEx trading bot key. Bind the key to your server's IP address when CoinEx lets you, keep the secret out of your code and out of Git, and delete the key if it ever leaks.

Connect CoinEx to LumiBot
-------------------------

The simplest way: put these lines in a ``.env`` file next to your strategy. LumiBot loads the file, sees ``TRADING_BROKER=coinex`` and connects to CoinEx for you, so your strategy needs no broker code.

.. code-block:: bash

   TRADING_BROKER=coinex
   COINEX_API_KEY=your_apiKey
   COINEX_API_SECRET=your_secret

LumiBot reads exactly the fields CCXT needs for CoinEx (``apiKey``, ``secret``). If one is missing, LumiBot stops at start-up and names the variable you still need.

You can also build the broker in code. This is handy when one script talks to more than one exchange, or when you need extra CCXT options. The keys in the config are CCXT's own credential names for CoinEx:

.. code-block:: python

   import os

   COINEX_CONFIG = {
       "exchange_id": "coinex",
       "apiKey": os.environ.get("COINEX_API_KEY"),
       "secret": os.environ.get("COINEX_API_SECRET"),
       "sandbox": False,  # no sandbox for this exchange
   }

   from lumibot.brokers import Ccxt

   broker = Ccxt(COINEX_CONFIG)
   # then: MyStrategy(broker=broker, ...)

Either way, LumiBot turns on CCXT's built-in rate limiting for you.

Testing on CoinEx
-----------------

CoinEx has no sandbox. Test with a very small amount, leave ``COINEX_SANDBOX`` unset, and in a code config set ``"sandbox": False``.

Algorithmic trading example: a simple CoinEx bot
------------------------------------------------

This bot buys about 50 USDT of BTC on CoinEx once and then holds it. It is a starting point to check that your keys, balances and orders work. If the exchange's minimum order is larger, raise the amount.

.. code-block:: python

   from lumibot.entities import Asset
   from lumibot.strategies import Strategy


   class CoinexBuyOnce(Strategy):
       """Buy a small amount of BTC once, then hold it."""

       def initialize(self):
           self.sleeptime = "1H"
           self.set_market("24/7")  # crypto trades all day, every day

       def on_trading_iteration(self):
           coin = Asset("BTC", asset_type=Asset.AssetType.CRYPTO)
           if self.get_position(coin) is not None:
               return  # already holding BTC
           price = self.get_last_price(coin, quote=self.quote_asset)
           if price:
               quantity = round(50 / price, 6)  # about 50 USDT worth
               order = self.create_order(coin, quantity, "buy", quote=self.quote_asset)
               self.submit_order(order)


   if __name__ == "__main__":
       # LumiBot reads TRADING_BROKER and the keys from your .env file.
       strategy = CoinexBuyOnce(quote_asset=Asset("USDT", asset_type=Asset.AssetType.CRYPTO))
       strategy.run_live()

Agentic trading example: an AI agent that trades on CoinEx
----------------------------------------------------------

Agentic trading means an AI agent reads the market and decides what to do. In this example one LumiBot agent looks at prices and your CoinEx account, then places the orders itself. There is no Python logic in between: you set the rules in plain English in the prompt, such as what it may trade and how big each order can be. This follows the same pattern as LumiBot's AI trading team examples.

.. code-block:: python

   from lumibot.entities import Asset
   from lumibot.strategies import Strategy


   class CoinexAITrader(Strategy):
       """One AI agent researches the market and places the trades itself."""

       def initialize(self):
           self.sleeptime = "4H"
           self.set_market("24/7")
           self.agents.create(
               name="trader",
               model="openai/gpt-6-luna",
               reasoning_effort="high",
               allow_trading=True,
               system_prompt=(
                   "You manage a small crypto account on CoinEx. "
                   "You may trade BTC and ETH against USDT (asset_type 'crypto', quote_symbol 'USDT'), or hold cash. "
                   "Before every order, call account_portfolio, account_positions and "
                   "market_last_price for that exact symbol in the same run. "
                   "Keep each order under 10% of the account value. "
                   "Explain each decision in one short paragraph."
               ),
           )

       def on_trading_iteration(self):
           self.agents["trader"].run(
               task_prompt="Review recent BTC/USDT and ETH/USDT prices and your current holdings, then decide whether to buy, sell or hold.",
               context={"exchange": "CoinEx", "quote": "USDT", "date": self.get_datetime().isoformat()},
           )


   if __name__ == "__main__":
       # LumiBot reads TRADING_BROKER and the keys from your .env file.
       strategy = CoinexAITrader(quote_asset=Asset("USDT", asset_type=Asset.AssetType.CRYPTO))
       strategy.run_live()

The agent needs a model key such as ``OPENAI_API_KEY`` in your environment. See the :doc:`AI agents quickstart <agents_quickstart>` for models, tools and memory.

Perpetual futures example on CoinEx
-----------------------------------

CoinEx also lists perpetual swaps. This bot opens one small long position in ``BTC/USDT:USDT`` worth about 50 USDT and then holds it. LumiBot treats a perpetual as ``asset_type="crypto_future"`` and sizes it in contracts, the same model as LumiBot's Bitunix futures broker. Contract symbols can differ by exchange, so check the symbol in ``self.broker.api.markets`` before going live. In hedge mode, add ``position_side="long"`` to ``create_order``.

.. code-block:: python

   from lumibot.entities import Asset
   from lumibot.strategies import Strategy


   class CoinexOpenOneLong(Strategy):
       """Open one small long BTC perpetual position, then hold it."""

       def initialize(self):
           self.sleeptime = "1H"
           self.set_market("24/7")  # crypto trades all day, every day

       def on_trading_iteration(self):
           # The full CCXT symbol keeps the settlement currency clear.
           contract = self.broker.get_asset("BTC/USDT:USDT")
           if self.get_position(contract) is not None:
               return  # already holding the position
           price = self.get_last_price(contract)
           if price:
               # Each contract covers contract.multiplier BTC; size the order to about 50 USDT.
               quantity = round(50 / (price * contract.multiplier), 6)
               order = self.create_order(contract, quantity, "buy")
               self.submit_order(order)


   if __name__ == "__main__":
       # LumiBot reads TRADING_BROKER and the keys from your .env file.
       strategy = CoinexOpenOneLong(quote_asset=Asset("USDT", asset_type=Asset.AssetType.CRYPTO))
       strategy.run_live()

Fees and partner IDs on CoinEx
------------------------------

You pay CoinEx's normal trading fees. CCXT, the library underneath, normally tags CoinEx orders with its own partner ID. LumiBot removes that tag. LumiBot may attach its own exchange partner ID instead. That costs you nothing extra. LumiBot never adds an extra builder fee unless one is turned on, and it logs a warning when one is.

CoinEx tips
-----------

* Bind a fixed IP address. CoinEx says a key with no fixed IP expires after 90 days, and you must click Renew on the API Management page to keep it working.
* If you see an IP Prohibited error, your bot's IP is not on the key's list. If you see access_id not exist right after making a key, wait about 10 minutes and try again.
* CoinEx calls the API key the Access ID. Put it in ``COINEX_API_KEY`` and the Secret Key in ``COINEX_API_SECRET``. No passphrase is needed.
* A main account can create up to 20 sub-accounts. CoinEx suggests them for running separate strategies, so each bot can have its own sub-account and key.

Frequently asked questions
--------------------------

**Can I build a CoinEx trading bot in Python?**

Yes. Install LumiBot (``pip install lumibot``), set your CoinEx keys and use the ``coinex`` CCXT exchange id as shown above.

**Does CoinEx have a testnet?**

No testnet is set up for CoinEx in LumiBot. Start with a small amount, and in a code config set ``"sandbox": False``.

**Which API permissions does a CoinEx bot need?**

Tick Trade so the bot can place and cancel orders. Leave Withdraw unticked. A trading bot never needs to move money out of your account.

**Can an AI agent trade on CoinEx by itself?**

Yes. The agentic example above gives one agent permission to trade. You control what it may trade and how much through its prompt.

**Can I trade CoinEx perpetual futures with LumiBot?**

CCXT lists perpetual swaps for this exchange. Use the full contract symbol, such as ``BTC/USDT:USDT``.

**Is LumiBot free?**

Yes. LumiBot is open source on GitHub at https://github.com/Lumiwealth/lumibot. You pay only your exchange's trading fees and, for AI agents, your model provider.
