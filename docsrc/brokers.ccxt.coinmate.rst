What is CoinMate?
-----------------

Coinmate is a crypto exchange run by COINMATE a.s. It offers spot trading between crypto and fiat money, with markets priced in euros (EUR) and Czech koruna (CZK).

Sign up for CoinMate
--------------------

#. Apply for a Coinmate account on https://coinmate.io and verify your email address.
#. Provide the identity details Coinmate asks for. You can deposit, trade and withdraw once Coinmate approves your account.
#. Set up Google Authenticator if you want to use it. Coinmate asks you to confirm API changes with an email code or a Google Authenticator code.

`Open a CoinMate account <https://coinmate.io/>`_

Create a CoinMate API key
-------------------------

#. Log in and open Account, then API (https://coinmate.io/account/api). API access is off until you turn it on there.
#. Note your client ID, which is shown on the same page.
#. Generate a new API key pair. You get a public key and a private key.
#. Choose the access level (trading only), then confirm the change with your email code or Google Authenticator code.
#. Store the private key somewhere safe and never share it. Anyone with your keys and client ID can use your API access.

**Which permissions to turn on:** Coinmate has two API levels: one for remote trading only, and one that also allows withdrawals. Pick the trading-only level for a bot and leave withdrawals off. Coinmate warns that a key with withdrawals can move money without the usual email or Google Authenticator check.

.. warning::

   Never turn on withdrawals for a CoinMate trading bot key. Bind the key to your server's IP address when CoinMate lets you, keep the secret out of your code and out of Git, and delete the key if it ever leaks.

Connect CoinMate to LumiBot
---------------------------

The simplest way: put these lines in a ``.env`` file next to your strategy. LumiBot loads the file, sees ``TRADING_BROKER=coinmate`` and connects to CoinMate for you, so your strategy needs no broker code.

.. code-block:: bash

   TRADING_BROKER=coinmate
   COINMATE_API_KEY=your_apiKey
   COINMATE_API_SECRET=your_secret
   COINMATE_UID=your_uid

LumiBot reads exactly the fields CCXT needs for CoinMate (``apiKey``, ``secret``, ``uid``). If one is missing, LumiBot stops at start-up and names the variable you still need.

You can also build the broker in code. This is handy when one script talks to more than one exchange, or when you need extra CCXT options. The keys in the config are CCXT's own credential names for CoinMate:

.. code-block:: python

   import os

   COINMATE_CONFIG = {
       "exchange_id": "coinmate",
       "apiKey": os.environ.get("COINMATE_API_KEY"),
       "secret": os.environ.get("COINMATE_API_SECRET"),
       "uid": os.environ.get("COINMATE_UID"),
       "sandbox": False,  # no sandbox for this exchange
   }

   from lumibot.brokers import Ccxt

   broker = Ccxt(COINMATE_CONFIG)
   # then: MyStrategy(broker=broker, ...)

Either way, LumiBot turns on CCXT's built-in rate limiting for you.

Testing on CoinMate
-------------------

Coinmate has no sandbox, and CCXT lists no test URL for it, so test with a very small amount. With environment variables, leave ``COINMATE_SANDBOX`` unset. In a code config, set ``"sandbox": False``.

Algorithmic trading example: a simple CoinMate bot
--------------------------------------------------

This bot buys about 45 EUR of BTC on CoinMate once and then holds it. It is a starting point to check that your keys, balances and orders work. If the exchange's minimum order is larger, raise the amount.

.. code-block:: python

   from lumibot.entities import Asset
   from lumibot.strategies import Strategy


   class CoinmateBuyOnce(Strategy):
       """Buy a small amount of BTC once, then hold it."""

       def initialize(self):
           self.sleeptime = "1H"
           self.set_market("24/7")  # crypto trades all day, every day

       def on_trading_iteration(self):
           coin = Asset("BTC", asset_type=Asset.AssetType.CRYPTO)
           if self.get_position(coin) is not None:
               return  # already holding BTC
           price = self.get_last_price(coin, quote=self.quote_asset)
           if price:
               quantity = round(45 / price, 6)  # about 45 EUR worth
               order = self.create_order(coin, quantity, "buy", quote=self.quote_asset)
               self.submit_order(order)


   if __name__ == "__main__":
       # LumiBot reads TRADING_BROKER and the keys from your .env file.
       strategy = CoinmateBuyOnce(quote_asset=Asset("EUR", asset_type=Asset.AssetType.CRYPTO))
       strategy.run_live()

Agentic trading example: an AI agent that trades on CoinMate
------------------------------------------------------------

Agentic trading means an AI agent reads the market and decides what to do. In this example one LumiBot agent looks at prices and your CoinMate account, then places the orders itself. There is no Python logic in between: you set the rules in plain English in the prompt, such as what it may trade and how big each order can be. This follows the same pattern as LumiBot's AI trading team examples.

.. code-block:: python

   from lumibot.entities import Asset
   from lumibot.strategies import Strategy


   class CoinmateAITrader(Strategy):
       """One AI agent researches the market and places the trades itself."""

       def initialize(self):
           self.sleeptime = "4H"
           self.set_market("24/7")
           self.agents.create(
               name="trader",
               model="openai/gpt-6-luna",
               reasoning_effort="high",
               allow_trading=True,
               system_prompt=(
                   "You manage a small crypto account on CoinMate. "
                   "You may trade BTC and ETH against EUR (asset_type 'crypto', quote_symbol 'EUR'), or hold cash. "
                   "Before every order, call account_portfolio, account_positions and "
                   "market_last_price for that exact symbol in the same run. "
                   "Keep each order under 10% of the account value. "
                   "Explain each decision in one short paragraph."
               ),
           )

       def on_trading_iteration(self):
           self.agents["trader"].run(
               task_prompt="Review recent BTC/EUR and ETH/EUR prices and your current holdings, then decide whether to buy, sell or hold.",
               context={"exchange": "CoinMate", "quote": "EUR", "date": self.get_datetime().isoformat()},
           )


   if __name__ == "__main__":
       # LumiBot reads TRADING_BROKER and the keys from your .env file.
       strategy = CoinmateAITrader(quote_asset=Asset("EUR", asset_type=Asset.AssetType.CRYPTO))
       strategy.run_live()

The agent needs a model key such as ``OPENAI_API_KEY`` in your environment. See the :doc:`AI agents quickstart <agents_quickstart>` for models, tools and memory.

Fees and partner IDs on CoinMate
--------------------------------

You pay CoinMate's normal trading fees. LumiBot may attach its own exchange partner ID. That costs you nothing extra. LumiBot never adds an extra builder fee unless one is turned on, and it logs a warning when one is.

CoinMate tips
-------------

* Coinmate needs three values: the public key goes in ``COINMATE_API_KEY``, the private key in ``COINMATE_API_SECRET`` and your client ID in ``COINMATE_UID`` (CCXT's ``uid`` field). Every private request is signed with all three.
* Coinmate requires each request with a key pair to use a larger nonce than the one before. If two programs share one key pair, requests can arrive out of order and Coinmate answers access denied. Give each bot its own key pair (Coinmate lets one account create several).
* Coinmate asks for no more than 100 requests per minute and says it will ban the IP address of clients that go over.
* Markets are priced in EUR and CZK, for example ``BTC/EUR`` or ``BTC/CZK``.

Frequently asked questions
--------------------------

**Can I build a CoinMate trading bot in Python?**

Yes. Install LumiBot (``pip install lumibot``), set your CoinMate keys and use the ``coinmate`` CCXT exchange id as shown above.

**Does CoinMate have a testnet?**

No testnet is set up for CoinMate in LumiBot. Start with a small amount, and in a code config set ``"sandbox": False``.

**Which API permissions does a CoinMate bot need?**

Coinmate has two API levels: one for remote trading only, and one that also allows withdrawals. Pick the trading-only level for a bot and leave withdrawals off. Coinmate warns that a key with withdrawals can move money without the usual email or Google Authenticator check.

**Can an AI agent trade on CoinMate by itself?**

Yes. The agentic example above gives one agent permission to trade. You control what it may trade and how much through its prompt.

**Can I trade CoinMate perpetual futures with LumiBot?**

CCXT does not list perpetual swaps for CoinMate, so use spot markets.

**Is LumiBot free?**

Yes. LumiBot is open source on GitHub at https://github.com/Lumiwealth/lumibot. You pay only your exchange's trading fees and, for AI agents, your model provider.
