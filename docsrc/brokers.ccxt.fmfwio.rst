What is FMFW.io?
----------------

FMFW.io is a crypto exchange for spot trading, margin trading and perpetual futures. Its API v3 covers spot, margin and futures trading plus wallet management.

Sign up for FMFW.io
-------------------

#. Create an account on fmfw.io and confirm your email address.
#. Turn on 2FA: click Settings, open the Security tab (https://fmfw.io/settings/security), click Add GAuth, save the backup code and confirm with the email link within 10 minutes. Email plus 2FA gives you the default Individual level.
#. For higher withdrawal limits, verify for Individual Pro on the KYC tab (https://fmfw.io/settings/know-your-customer) with a photo ID and a selfie. FMFW.io says this can take up to 24 hours.

`Open a FMFW.io account <https://fmfw.io>`_

Create a FMFW.io API key
------------------------

#. Log in, open Settings and go to the API Settings page. FMFW.io's API docs say this is where keys are made.
#. Create a new API key. You can have several keys, each with its own access rights.
#. Choose the access rights (see below).
#. Copy the API key and secret key and store them safely. LumiBot needs both.

**Which permissions to turn on:** Turn on the "Orderbook, History, Trading balance" and "Place/cancel orders" access rights. Leave "Withdraw cryptocurrencies" and "Payment information" off. A bot never needs to move money out of your account.

.. warning::

   Never turn on withdrawals for a FMFW.io trading bot key. Bind the key to your server's IP address when FMFW.io lets you, keep the secret out of your code and out of Git, and delete the key if it ever leaks.

Connect FMFW.io to LumiBot
--------------------------

The simplest way: put these lines in a ``.env`` file next to your strategy. LumiBot loads the file, sees ``TRADING_BROKER=fmfwio`` and connects to FMFW.io for you, so your strategy needs no broker code.

.. code-block:: bash

   TRADING_BROKER=fmfwio
   FMFWIO_API_KEY=your_apiKey
   FMFWIO_API_SECRET=your_secret

LumiBot reads exactly the fields CCXT needs for FMFW.io (``apiKey``, ``secret``). If one is missing, LumiBot stops at start-up and names the variable you still need.

You can also build the broker in code. This is handy when one script talks to more than one exchange, or when you need extra CCXT options. The keys in the config are CCXT's own credential names for FMFW.io:

.. code-block:: python

   import os

   FMFWIO_CONFIG = {
       "exchange_id": "fmfwio",
       "apiKey": os.environ.get("FMFWIO_API_KEY"),
       "secret": os.environ.get("FMFWIO_API_SECRET"),
       "sandbox": False,  # no sandbox for this exchange
   }

   from lumibot.brokers import Ccxt

   broker = Ccxt(FMFWIO_CONFIG)
   # then: MyStrategy(broker=broker, ...)

Either way, LumiBot turns on CCXT's built-in rate limiting for you.

Testing on FMFW.io
------------------

FMFW.io's own docs do not describe a sandbox or testnet. CCXT's sandbox setting for fmfwio points at a HitBTC demo server (api.demo.hitbtc.com), which is not an FMFW.io service, so do not use it. Test with a very small amount on your real account, leave ``FMFWIO_SANDBOX`` unset, and in a code config set ``"sandbox": False``.

Algorithmic trading example: a simple FMFW.io bot
-------------------------------------------------

This bot buys about 50 USDT of BTC on FMFW.io once and then holds it. It is a starting point to check that your keys, balances and orders work. If the exchange's minimum order is larger, raise the amount.

.. code-block:: python

   from lumibot.entities import Asset
   from lumibot.strategies import Strategy


   class FmfwioBuyOnce(Strategy):
       """Buy a small amount of BTC once, then hold it."""

       def initialize(self):
           self.sleeptime = "1H"
           self.set_market("24/7")  # crypto trades all day, every day

       def on_trading_iteration(self):
           coin = Asset("BTC", asset_type=Asset.AssetType.CRYPTO)
           if self.get_position(coin) is not None:
               return  # already holding BTC
           price = self.get_last_price(coin, quote=self.quote_asset)
           if price:
               quantity = round(50 / price, 6)  # about 50 USDT worth
               order = self.create_order(coin, quantity, "buy", quote=self.quote_asset)
               self.submit_order(order)


   if __name__ == "__main__":
       # LumiBot reads TRADING_BROKER and the keys from your .env file.
       strategy = FmfwioBuyOnce(quote_asset=Asset("USDT", asset_type=Asset.AssetType.CRYPTO))
       strategy.run_live()

Agentic trading example: an AI agent that trades on FMFW.io
-----------------------------------------------------------

Agentic trading means an AI agent reads the market and decides what to do. In this example one LumiBot agent looks at prices and your FMFW.io account, then places the orders itself. There is no Python logic in between: you set the rules in plain English in the prompt, such as what it may trade and how big each order can be. This follows the same pattern as LumiBot's AI trading team examples.

.. code-block:: python

   from lumibot.entities import Asset
   from lumibot.strategies import Strategy


   class FmfwioAITrader(Strategy):
       """One AI agent researches the market and places the trades itself."""

       def initialize(self):
           self.sleeptime = "4H"
           self.set_market("24/7")
           self.agents.create(
               name="trader",
               model="openai/gpt-6-luna",
               reasoning_effort="high",
               allow_trading=True,
               system_prompt=(
                   "You manage a small crypto account on FMFW.io. "
                   "You may trade BTC and ETH against USDT (asset_type 'crypto', quote_symbol 'USDT'), or hold cash. "
                   "Before every order, call account_portfolio, account_positions and "
                   "market_last_price for that exact symbol in the same run. "
                   "Keep each order under 10% of the account value. "
                   "Explain each decision in one short paragraph."
               ),
           )

       def on_trading_iteration(self):
           self.agents["trader"].run(
               task_prompt="Review recent BTC/USDT and ETH/USDT prices and your current holdings, then decide whether to buy, sell or hold.",
               context={"exchange": "FMFW.io", "quote": "USDT", "date": self.get_datetime().isoformat()},
           )


   if __name__ == "__main__":
       # LumiBot reads TRADING_BROKER and the keys from your .env file.
       strategy = FmfwioAITrader(quote_asset=Asset("USDT", asset_type=Asset.AssetType.CRYPTO))
       strategy.run_live()

The agent needs a model key such as ``OPENAI_API_KEY`` in your environment. See the :doc:`AI agents quickstart <agents_quickstart>` for models, tools and memory.

Perpetual futures example on FMFW.io
------------------------------------

FMFW.io also lists perpetual swaps. This bot opens one small long position in ``BTC/USDT:USDT`` worth about 50 USDT and then holds it. LumiBot treats a perpetual as ``asset_type="crypto_future"`` and sizes it in contracts, the same model as LumiBot's Bitunix futures broker. Contract symbols can differ by exchange, so check the symbol in ``self.broker.api.markets`` before going live. In hedge mode, add ``position_side="long"`` to ``create_order``.

.. code-block:: python

   from lumibot.entities import Asset
   from lumibot.strategies import Strategy


   class FmfwioOpenOneLong(Strategy):
       """Open one small long BTC perpetual position, then hold it."""

       def initialize(self):
           self.sleeptime = "1H"
           self.set_market("24/7")  # crypto trades all day, every day

       def on_trading_iteration(self):
           # The full CCXT symbol keeps the settlement currency clear.
           contract = self.broker.get_asset("BTC/USDT:USDT")
           if self.get_position(contract) is not None:
               return  # already holding the position
           price = self.get_last_price(contract)
           if price:
               # Each contract covers contract.multiplier BTC; size the order to about 50 USDT.
               quantity = round(50 / (price * contract.multiplier), 6)
               order = self.create_order(contract, quantity, "buy")
               self.submit_order(order)


   if __name__ == "__main__":
       # LumiBot reads TRADING_BROKER and the keys from your .env file.
       strategy = FmfwioOpenOneLong(quote_asset=Asset("USDT", asset_type=Asset.AssetType.CRYPTO))
       strategy.run_live()

Fees and partner IDs on FMFW.io
-------------------------------

You pay FMFW.io's normal trading fees. LumiBot may attach its own exchange partner ID. That costs you nothing extra. LumiBot never adds an extra builder fee unless one is turned on, and it logs a warning when one is.

FMFW.io tips
------------

* FMFW.io keeps a wallet balance and a separate trading balance. Move funds into your trading balance before the bot starts, or it will see no money to trade with.
* Sub-accounts are a good way to give each bot its own funds. Each sub-account needs its own email and its own 2FA, and withdrawals are off on sub-accounts by default.
* Keep polling modest. FMFW.io's default REST limit is 20 requests per second per IP (30 burst), and an account can have at most 2000 open orders per symbol.
* The REST API lives at https://api.fmfw.io/api/3 and uses Basic authentication with your API key and secret.

Frequently asked questions
--------------------------

**Can I build a FMFW.io trading bot in Python?**

Yes. Install LumiBot (``pip install lumibot``), set your FMFW.io keys and use the ``fmfwio`` CCXT exchange id as shown above.

**Does FMFW.io have a testnet?**

No testnet is set up for FMFW.io in LumiBot. Start with a small amount, and in a code config set ``"sandbox": False``.

**Which API permissions does a FMFW.io bot need?**

Turn on the "Orderbook, History, Trading balance" and "Place/cancel orders" access rights. Leave "Withdraw cryptocurrencies" and "Payment information" off. A bot never needs to move money out of your account.

**Can an AI agent trade on FMFW.io by itself?**

Yes. The agentic example above gives one agent permission to trade. You control what it may trade and how much through its prompt.

**Can I trade FMFW.io perpetual futures with LumiBot?**

CCXT lists perpetual swaps for this exchange. Use the full contract symbol, such as ``BTC/USDT:USDT``.

**Is LumiBot free?**

Yes. LumiBot is open source on GitHub at https://github.com/Lumiwealth/lumibot. You pay only your exchange's trading fees and, for AI agents, your model provider.
