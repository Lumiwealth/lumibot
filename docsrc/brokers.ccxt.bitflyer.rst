What is bitFlyer?
-----------------

bitFlyer is a bitcoin and crypto exchange. Its bitFlyer Lightning trading platform offers spot trading and a bitcoin CFD product (Crypto CFD), with a public and private HTTP API.

Sign up for bitFlyer
--------------------

#. Create a bitFlyer account on the official site.
#. Finish account verification. bitFlyer says you must sign up and verify your account to use its APIs and bitFlyer Lightning.
#. Turn on two-factor authentication. bitFlyer highly recommends it.

`Open a bitFlyer account <https://bitflyer.com/>`_

Create a bitFlyer API key
-------------------------

#. Log in to bitFlyer Lightning at https://lightning.bitflyer.com.
#. Open the developer page (https://lightning.bitflyer.com/developer), where bitFlyer issues API keys.
#. Generate a new API key and set its permissions. bitFlyer lets you pick permissions for each key.
#. Save the API key and API secret somewhere safe. bitFlyer says never to store the secret in plain text, in your program or in Git.
#. Optional: the private endpoint GET /v1/me/getpermissions lists what your key is allowed to do, so you can check it.

**Which permissions to turn on:** Give the key the permissions to read your balance, orders and executions, and to place and cancel orders. Leave withdrawals off. A bot never needs to move money out of your account.

.. warning::

   Never turn on withdrawals for a bitFlyer trading bot key. Bind the key to your server's IP address when bitFlyer lets you, keep the secret out of your code and out of Git, and delete the key if it ever leaks.

Connect bitFlyer to LumiBot
---------------------------

The simplest way: put these lines in a ``.env`` file next to your strategy. LumiBot loads the file, sees ``TRADING_BROKER=bitflyer`` and connects to bitFlyer for you, so your strategy needs no broker code.

.. code-block:: bash

   TRADING_BROKER=bitflyer
   BITFLYER_API_KEY=your_apiKey
   BITFLYER_API_SECRET=your_secret

LumiBot reads exactly the fields CCXT needs for bitFlyer (``apiKey``, ``secret``). If one is missing, LumiBot stops at start-up and names the variable you still need.

You can also build the broker in code. This is handy when one script talks to more than one exchange, or when you need extra CCXT options. The keys in the config are CCXT's own credential names for bitFlyer:

.. code-block:: python

   import os

   BITFLYER_CONFIG = {
       "exchange_id": "bitflyer",
       "apiKey": os.environ.get("BITFLYER_API_KEY"),
       "secret": os.environ.get("BITFLYER_API_SECRET"),
       "sandbox": False,  # live connection
   }

   from lumibot.brokers import Ccxt

   broker = Ccxt(BITFLYER_CONFIG)
   # then: MyStrategy(broker=broker, ...)

Either way, LumiBot turns on CCXT's built-in rate limiting for you.

Testing on bitFlyer
-------------------

bitFlyer has no sandbox, and CCXT lists no test URL for it. The bitFlyer Lightning API Playground is a live environment that uses real funds, so it is not a test site. Test with a very small amount, leave ``BITFLYER_SANDBOX`` unset, and in a code config set ``"sandbox": False``.

Algorithmic trading example: a simple bitFlyer bot
--------------------------------------------------

This bot buys about 7500 JPY of BTC on bitFlyer once and then holds it. It is a starting point to check that your keys, balances and orders work. If the exchange's minimum order is larger, raise the amount. bitFlyer accepts only limit orders through CCXT, so the example places a limit order just above the last price.

.. code-block:: python

   from lumibot.entities import Asset
   from lumibot.strategies import Strategy


   class BitflyerBuyOnce(Strategy):
       """Buy a small amount of BTC once, then hold it."""

       def initialize(self):
           self.sleeptime = "1H"
           self.set_market("24/7")  # crypto trades all day, every day

       def on_trading_iteration(self):
           coin = Asset("BTC", asset_type=Asset.AssetType.CRYPTO)
           if self.get_position(coin) is not None:
               return  # already holding BTC
           price = self.get_last_price(coin, quote=self.quote_asset)
           if price:
               quantity = round(7500 / price, 6)  # about 7500 JPY worth
               # This exchange takes only limit orders through CCXT.
               order = self.create_order(coin, quantity, "buy", limit_price=price * 1.002, quote=self.quote_asset)
               self.submit_order(order)


   if __name__ == "__main__":
       # LumiBot reads TRADING_BROKER and the keys from your .env file.
       strategy = BitflyerBuyOnce(quote_asset=Asset("JPY", asset_type=Asset.AssetType.CRYPTO))
       strategy.run_live()

Agentic trading example: an AI agent that trades on bitFlyer
------------------------------------------------------------

Agentic trading means an AI agent reads the market and decides what to do. In this example one LumiBot agent looks at prices and your bitFlyer account, then places the orders itself. There is no Python logic in between: you set the rules in plain English in the prompt, such as what it may trade and how big each order can be. This follows the same pattern as LumiBot's AI trading team examples.

.. code-block:: python

   from lumibot.entities import Asset
   from lumibot.strategies import Strategy


   class BitflyerAITrader(Strategy):
       """One AI agent researches the market and places the trades itself."""

       def initialize(self):
           self.sleeptime = "4H"
           self.set_market("24/7")
           self.agents.create(
               name="trader",
               model="openai/gpt-6-luna",
               reasoning_effort="high",
               allow_trading=True,
               system_prompt=(
                   "You manage a small crypto account on bitFlyer. "
                   "You may trade BTC and ETH against JPY (asset_type 'crypto', quote_symbol 'JPY'), or hold cash. "
                   "Before every order, call account_portfolio, account_positions and "
                   "market_last_price for that exact symbol in the same run. "
                   "Keep each order under 10% of the account value. "
                   "Explain each decision in one short paragraph."
               ),
           )

       def on_trading_iteration(self):
           self.agents["trader"].run(
               task_prompt="Review recent BTC/JPY and ETH/JPY prices and your current holdings, then decide whether to buy, sell or hold.",
               context={"exchange": "bitFlyer", "quote": "JPY", "date": self.get_datetime().isoformat()},
           )


   if __name__ == "__main__":
       # LumiBot reads TRADING_BROKER and the keys from your .env file.
       strategy = BitflyerAITrader(quote_asset=Asset("JPY", asset_type=Asset.AssetType.CRYPTO))
       strategy.run_live()

The agent needs a model key such as ``OPENAI_API_KEY`` in your environment. See the :doc:`AI agents quickstart <agents_quickstart>` for models, tools and memory.

Fees and partner IDs on bitFlyer
--------------------------------

You pay bitFlyer's normal trading fees. LumiBot may attach its own exchange partner ID. That costs you nothing extra. LumiBot never adds an extra builder fee unless one is turned on, and it logs a warning when one is.

bitFlyer tips
-------------

* bitFlyer product codes look like ``BTC_JPY``. In LumiBot use the CCXT form, for example ``BTC/JPY``. CCXT also lists ``BTC/USD`` and ``BTC/EUR``; use the market your bitFlyer account can trade.
* The bitcoin CFD product uses the product code ``FX_BTC_JPY`` on bitFlyer. In CCXT it shows up as ``BTC/JPY:JPY``.
* bitFlyer limits private API calls to 500 per 5 minutes, and some order calls to 300 per 5 minutes in total. Going over blocks requests for a while, so avoid very short bot loops.
* bitFlyer only needs an API key and secret. There is no passphrase.

Frequently asked questions
--------------------------

**Can I build a bitFlyer trading bot in Python?**

Yes. Install LumiBot (``pip install lumibot``), set your bitFlyer keys and use the ``bitflyer`` CCXT exchange id as shown above.

**Does bitFlyer have a testnet?**

No testnet is set up for bitFlyer in LumiBot. Start with a small amount, and in a code config set ``"sandbox": False``.

**Which API permissions does a bitFlyer bot need?**

Give the key the permissions to read your balance, orders and executions, and to place and cancel orders. Leave withdrawals off. A bot never needs to move money out of your account.

**Can an AI agent trade on bitFlyer by itself?**

Yes. The agentic example above gives one agent permission to trade. You control what it may trade and how much through its prompt.

**Can I trade bitFlyer perpetual futures with LumiBot?**

CCXT does not list perpetual swaps for bitFlyer, so use spot markets.

**Is LumiBot free?**

Yes. LumiBot is open source on GitHub at https://github.com/Lumiwealth/lumibot. You pay only your exchange's trading fees and, for AI agents, your model provider.
