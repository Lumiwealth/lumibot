What is Mudrex?
---------------

Mudrex is a crypto platform for buying, selling and trading Bitcoin and hundreds of other assets, plus crypto futures. Its trading API is for futures (perpetual contracts quoted in USDT).

Sign up for Mudrex
------------------

#. Create an account on Mudrex at https://mudrex.com/ or in the Mudrex app.
#. Finish identity verification (KYC). Mudrex requires PAN and Aadhaar verification through DigiLocker before you can use the API.
#. Turn on TOTP two-factor authentication (an authenticator app). Mudrex needs it to create, rotate or revoke API keys. Mudrex has no testnet, so plan to test with a very small amount.

`Open a Mudrex account <https://mudrex.com/>`_

Create a Mudrex API key
-----------------------

#. Log in to Mudrex and go to API key generation. Mudrex's API page (https://mudrex.com/pro-trading) has a Generate API Key button.
#. Give the key a clear name and click Generate Key. Mudrex currently allows one API key per user.
#. Copy both the API key and the API secret and store them safely. Mudrex shows the secret only once.
#. The secret is what signs every request. In CCXT, Mudrex only needs the ``secret`` value.
#. If the secret ever leaks, use Rotate in API Key Management to get a new secret (the old one stops working at once), or Revoke to shut the key off for good.

**Which permissions to turn on:** Mudrex's docs do not offer permission choices when you create a key. A key can trade futures, manage positions and move funds between your own spot and futures wallets, and the API docs list no endpoint for withdrawing crypto out of Mudrex. Keep withdrawals in the app, and treat the API secret like a password.

.. warning::

   Never turn on withdrawals for a Mudrex trading bot key. Bind the key to your server's IP address when Mudrex lets you, keep the secret out of your code and out of Git, and delete the key if it ever leaks.

Connect Mudrex to LumiBot
-------------------------

The simplest way: put these lines in a ``.env`` file next to your strategy. LumiBot loads the file, sees ``TRADING_BROKER=mudrex`` and connects to Mudrex for you, so your strategy needs no broker code.

.. code-block:: bash

   TRADING_BROKER=mudrex
   MUDREX_API_SECRET=your_secret

LumiBot reads exactly the fields CCXT needs for Mudrex (``secret``). If one is missing, LumiBot stops at start-up and names the variable you still need.

You can also build the broker in code. This is handy when one script talks to more than one exchange, or when you need extra CCXT options. The keys in the config are CCXT's own credential names for Mudrex:

.. code-block:: python

   import os

   MUDREX_CONFIG = {
       "exchange_id": "mudrex",
       "secret": os.environ.get("MUDREX_API_SECRET"),
       "sandbox": False,  # no sandbox for this exchange
   }

   from lumibot.brokers import Ccxt

   broker = Ccxt(MUDREX_CONFIG)
   # then: MyStrategy(broker=broker, ...)

Either way, LumiBot turns on CCXT's built-in rate limiting for you.

Testing on Mudrex
-----------------

Mudrex has no sandbox, and CCXT lists no test URL for it, so test with a very small amount. With environment variables, leave ``MUDREX_SANDBOX`` unset. In a code config, set ``"sandbox": False``.

Algorithmic trading example: a simple Mudrex bot
------------------------------------------------

CCXT lists no spot market for Mudrex, so this example trades a perpetual contract. It opens one small long BTC position worth about 50 USDT and then holds it. It is a starting point to check that your keys, balances and orders work. If the exchange's minimum order is larger, raise the amount. If your account uses hedge mode, add ``position_side="long"`` to ``create_order``.

.. code-block:: python

   from lumibot.entities import Asset
   from lumibot.strategies import Strategy


   class MudrexOpenOneLong(Strategy):
       """Open one small long BTC perpetual position, then hold it."""

       def initialize(self):
           self.sleeptime = "1H"
           self.set_market("24/7")  # crypto trades all day, every day

       def on_trading_iteration(self):
           # The full CCXT symbol keeps the settlement currency clear.
           contract = self.broker.get_asset("BTC/USDT:USDT")
           if self.get_position(contract) is not None:
               return  # already holding the position
           price = self.get_last_price(contract)
           if price:
               # Each contract covers contract.multiplier BTC; size the order to about 50 USDT.
               quantity = round(50 / (price * contract.multiplier), 6)
               order = self.create_order(contract, quantity, "buy")
               self.submit_order(order)


   if __name__ == "__main__":
       # LumiBot reads TRADING_BROKER and the keys from your .env file.
       strategy = MudrexOpenOneLong(quote_asset=Asset("USDT", asset_type=Asset.AssetType.CRYPTO))
       strategy.run_live()

Agentic trading example: an AI agent that trades on Mudrex
----------------------------------------------------------

Agentic trading means an AI agent reads the market and decides what to do. In this example one LumiBot agent looks at prices and your Mudrex account, then places the orders itself. There is no Python logic in between: you set the rules in plain English in the prompt, such as what it may trade and how big each order can be. This follows the same pattern as LumiBot's AI trading team examples.

.. code-block:: python

   from lumibot.entities import Asset
   from lumibot.strategies import Strategy


   class MudrexAITrader(Strategy):
       """One AI agent researches the market and places the trades itself."""

       def initialize(self):
           self.sleeptime = "4H"
           self.set_market("24/7")
           self.agents.create(
               name="trader",
               model="openai/gpt-6-luna",
               reasoning_effort="high",
               allow_trading=True,
               system_prompt=(
                   "You manage a small crypto account on Mudrex. "
                   "You may trade the BTC/USDT:USDT perpetual contract (asset_type 'crypto_future'), long or short, or stay flat. "
                   "Before every order, call account_portfolio, account_positions and "
                   "market_last_price for that exact symbol in the same run. "
                   "Keep each order under 10% of the account value. "
                   "Explain each decision in one short paragraph."
               ),
           )

       def on_trading_iteration(self):
           self.agents["trader"].run(
               task_prompt="Review recent BTC/USDT:USDT prices and your current position, then decide whether to buy, sell or hold.",
               context={"exchange": "Mudrex", "quote": "USDT", "date": self.get_datetime().isoformat()},
           )


   if __name__ == "__main__":
       # LumiBot reads TRADING_BROKER and the keys from your .env file.
       strategy = MudrexAITrader(quote_asset=Asset("USDT", asset_type=Asset.AssetType.CRYPTO))
       strategy.run_live()

The agent needs a model key such as ``OPENAI_API_KEY`` in your environment. See the :doc:`AI agents quickstart <agents_quickstart>` for models, tools and memory.

Mudrex tips
-----------

* Mudrex's API covers futures only, so use the CCXT perpetual form, for example ``BTC/USDT:USDT`` (Mudrex calls it ``BTCUSDT``). Before trading, move funds from your spot wallet to your futures wallet; the API can do that transfer.
* Mudrex futures can use USDT or INR as margin on the same USDT-priced contracts. USDT is the default. Leverage is stored separately for each currency, and the API cannot convert INR to USDT; do that in the Mudrex app.
* Because there is only one API key per user, run one bot per Mudrex account, or make sure your bots share the key's rate limits (10 requests per second and 500 per minute on trading endpoints).
* CCXT cannot load Mudrex markets without the API secret, so set the secret before starting the bot, even for data checks.

Frequently asked questions
--------------------------

**Can I build a Mudrex trading bot in Python?**

Yes. Install LumiBot (``pip install lumibot``), set your Mudrex keys and use the ``mudrex`` CCXT exchange id as shown above.

**Does Mudrex have a testnet?**

No testnet is set up for Mudrex in LumiBot. Start with a small amount, and in a code config set ``"sandbox": False``.

**Which API permissions does a Mudrex bot need?**

Mudrex's docs do not offer permission choices when you create a key. A key can trade futures, manage positions and move funds between your own spot and futures wallets, and the API docs list no endpoint for withdrawing crypto out of Mudrex. Keep withdrawals in the app, and treat the API secret like a password.

**Can an AI agent trade on Mudrex by itself?**

Yes. The agentic example above gives one agent permission to trade. You control what it may trade and how much through its prompt.

**Can I trade Mudrex perpetual futures with LumiBot?**

CCXT lists perpetual swaps for this exchange. Use the full contract symbol, such as ``BTC/USDT:USDT``.

**Is LumiBot free?**

Yes. LumiBot is open source on GitHub at https://github.com/Lumiwealth/lumibot. You pay only your exchange's trading fees and, for AI agents, your model provider.
