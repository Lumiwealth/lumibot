What is BitoPro?
----------------

BitoPro is a crypto exchange for spot trading in BTC, ETH, USDT and other coins. It supports deposits in New Taiwan dollars (TWD).

Sign up for BitoPro
-------------------

#. Register a BitoPro account and finish identity verification. BitoPro asks for this before you can use the API.
#. Turn on two-factor authentication with Google Authenticator (Account, Security, 2FA). BitoPro suggests using it for both login and withdrawals.
#. BitoPro has no testnet, so plan to test with a very small amount.

`Open a BitoPro account <https://www.bitopro.com/>`_

Create a BitoPro API key
------------------------

#. Log in on the BitoPro website, click your username or avatar in the top right corner and choose API.
#. On the API Management page, click Create new API key.
#. Enter a name for the key and choose its permissions (see below), then submit.
#. Open the confirmation email BitoPro sends to your account email and click the confirm button to turn the key on.
#. Copy the API key and secret right away. BitoPro shows the secret only once and cannot show it again. If you lose it, delete the key and make a new one.

**Which permissions to turn on:** Give the key permission to read account information and to trade. Leave withdrawals off. A trading bot never needs to move money out of your account.

.. warning::

   Never turn on withdrawals for a BitoPro trading bot key. Bind the key to your server's IP address when BitoPro lets you, keep the secret out of your code and out of Git, and delete the key if it ever leaks.

Connect BitoPro to LumiBot
--------------------------

The simplest way: put these lines in a ``.env`` file next to your strategy. LumiBot loads the file, sees ``TRADING_BROKER=bitopro`` and connects to BitoPro for you, so your strategy needs no broker code.

.. code-block:: bash

   TRADING_BROKER=bitopro
   BITOPRO_API_KEY=your_apiKey
   BITOPRO_API_SECRET=your_secret

LumiBot reads exactly the fields CCXT needs for BitoPro (``apiKey``, ``secret``). If one is missing, LumiBot stops at start-up and names the variable you still need.

You can also build the broker in code. This is handy when one script talks to more than one exchange, or when you need extra CCXT options. The keys in the config are CCXT's own credential names for BitoPro:

.. code-block:: python

   import os

   BITOPRO_CONFIG = {
       "exchange_id": "bitopro",
       "apiKey": os.environ.get("BITOPRO_API_KEY"),
       "secret": os.environ.get("BITOPRO_API_SECRET"),
       "sandbox": False,  # no sandbox for this exchange
   }

   from lumibot.brokers import Ccxt

   broker = Ccxt(BITOPRO_CONFIG)
   # then: MyStrategy(broker=broker, ...)

Either way, LumiBot turns on CCXT's built-in rate limiting for you.

Testing on BitoPro
------------------

BitoPro has no sandbox, and CCXT lists no test URL for it, so test with a very small amount. With environment variables, leave ``BITOPRO_SANDBOX`` unset. In a code config, set ``"sandbox": False``.

Algorithmic trading example: a simple BitoPro bot
-------------------------------------------------

This bot buys about 1500 TWD of BTC on BitoPro once and then holds it. It is a starting point to check that your keys, balances and orders work. If the exchange's minimum order is larger, raise the amount.

.. code-block:: python

   from lumibot.entities import Asset
   from lumibot.strategies import Strategy


   class BitoproBuyOnce(Strategy):
       """Buy a small amount of BTC once, then hold it."""

       def initialize(self):
           self.sleeptime = "1H"
           self.set_market("24/7")  # crypto trades all day, every day

       def on_trading_iteration(self):
           coin = Asset("BTC", asset_type=Asset.AssetType.CRYPTO)
           if self.get_position(coin) is not None:
               return  # already holding BTC
           price = self.get_last_price(coin, quote=self.quote_asset)
           if price:
               quantity = round(1500 / price, 6)  # about 1500 TWD worth
               order = self.create_order(coin, quantity, "buy", quote=self.quote_asset)
               self.submit_order(order)


   if __name__ == "__main__":
       # LumiBot reads TRADING_BROKER and the keys from your .env file.
       strategy = BitoproBuyOnce(quote_asset=Asset("TWD", asset_type=Asset.AssetType.CRYPTO))
       strategy.run_live()

Agentic trading example: an AI agent that trades on BitoPro
-----------------------------------------------------------

Agentic trading means an AI agent reads the market and decides what to do. In this example one LumiBot agent looks at prices and your BitoPro account, then places the orders itself. There is no Python logic in between: you set the rules in plain English in the prompt, such as what it may trade and how big each order can be. This follows the same pattern as LumiBot's AI trading team examples.

.. code-block:: python

   from lumibot.entities import Asset
   from lumibot.strategies import Strategy


   class BitoproAITrader(Strategy):
       """One AI agent researches the market and places the trades itself."""

       def initialize(self):
           self.sleeptime = "4H"
           self.set_market("24/7")
           self.agents.create(
               name="trader",
               model="openai/gpt-6-luna",
               reasoning_effort="high",
               allow_trading=True,
               system_prompt=(
                   "You manage a small crypto account on BitoPro. "
                   "You may trade BTC and ETH against TWD (asset_type 'crypto', quote_symbol 'TWD'), or hold cash. "
                   "Before every order, call account_portfolio, account_positions and "
                   "market_last_price for that exact symbol in the same run. "
                   "Keep each order under 10% of the account value. "
                   "Explain each decision in one short paragraph."
               ),
           )

       def on_trading_iteration(self):
           self.agents["trader"].run(
               task_prompt="Review recent BTC/TWD and ETH/TWD prices and your current holdings, then decide whether to buy, sell or hold.",
               context={"exchange": "BitoPro", "quote": "TWD", "date": self.get_datetime().isoformat()},
           )


   if __name__ == "__main__":
       # LumiBot reads TRADING_BROKER and the keys from your .env file.
       strategy = BitoproAITrader(quote_asset=Asset("TWD", asset_type=Asset.AssetType.CRYPTO))
       strategy.run_live()

The agent needs a model key such as ``OPENAI_API_KEY`` in your environment. See the :doc:`AI agents quickstart <agents_quickstart>` for models, tools and memory.

BitoPro tips
------------

* Add an IP whitelist to your key. BitoPro says keys with an IP whitelist never expire, while keys without one expire 365 days after they are made (BitoPro emails you 30 days and 7 days before). After that, requests fail with HTTP 401.
* BitoPro markets are quoted in TWD or USDT, for example ``BTC/TWD`` or ``BTC/USDT``.
* BitoPro deleted API keys made before 2026-05-27 during a July 2026 login update. If your bot uses an older key, check API Management and make a new key.

Frequently asked questions
--------------------------

**Can I build a BitoPro trading bot in Python?**

Yes. Install LumiBot (``pip install lumibot``), set your BitoPro keys and use the ``bitopro`` CCXT exchange id as shown above.

**Does BitoPro have a testnet?**

No testnet is set up for BitoPro in LumiBot. Start with a small amount, and in a code config set ``"sandbox": False``.

**Which API permissions does a BitoPro bot need?**

Give the key permission to read account information and to trade. Leave withdrawals off. A trading bot never needs to move money out of your account.

**Can an AI agent trade on BitoPro by itself?**

Yes. The agentic example above gives one agent permission to trade. You control what it may trade and how much through its prompt.

**Can I trade BitoPro perpetual futures with LumiBot?**

CCXT does not list perpetual swaps for BitoPro, so use spot markets.

**Is LumiBot free?**

Yes. LumiBot is open source on GitHub at https://github.com/Lumiwealth/lumibot. You pay only your exchange's trading fees and, for AI agents, your model provider.
