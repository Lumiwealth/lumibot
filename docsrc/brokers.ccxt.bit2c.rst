What is Bit2C?
--------------

Bit2C is a crypto exchange. You trade coins such as Bitcoin and Ethereum against the shekel.

Sign up for Bit2C
-----------------

#. Register with your mobile phone number, then choose a username, a strong password and your email address.
#. Confirm your email with the link Bit2C sends, then confirm your phone with the link in the SMS.
#. Finish identity verification (KYC) and upload the documents Bit2C asks for before you trade.

`Open a Bit2C account <https://bit2c.co.il/account/register>`_

Create a Bit2C API key
----------------------

#. Log in to your Bit2C account.
#. Go to the API keys screen in your account settings.
#. Create a new API key. You can also edit or delete keys there.
#. Enter the code Bit2C sends you by SMS. Bit2C asks for this code every time you create, edit or delete a key.
#. Save the public key and the secret key somewhere safe.

**Which permissions to turn on:** Bit2C's own pages do not list the permission names. Give the key what it needs to read your balance and orders and to trade. If the key screen offers withdrawals, leave them off.

.. warning::

   Never turn on withdrawals for a Bit2C trading bot key. Bind the key to your server's IP address when Bit2C lets you, keep the secret out of your code and out of Git, and delete the key if it ever leaks.

Connect Bit2C to LumiBot
------------------------

The simplest way: put these lines in a ``.env`` file next to your strategy. LumiBot loads the file, sees ``TRADING_BROKER=bit2c`` and connects to Bit2C for you, so your strategy needs no broker code.

.. code-block:: bash

   TRADING_BROKER=bit2c
   BIT2C_API_KEY=your_apiKey
   BIT2C_API_SECRET=your_secret

LumiBot reads exactly the fields CCXT needs for Bit2C (``apiKey``, ``secret``). If one is missing, LumiBot stops at start-up and names the variable you still need.

You can also build the broker in code. This is handy when one script talks to more than one exchange, or when you need extra CCXT options. The keys in the config are CCXT's own credential names for Bit2C:

.. code-block:: python

   import os

   BIT2C_CONFIG = {
       "exchange_id": "bit2c",
       "apiKey": os.environ.get("BIT2C_API_KEY"),
       "secret": os.environ.get("BIT2C_API_SECRET"),
       "sandbox": False,  # no sandbox for this exchange
   }

   from lumibot.brokers import Ccxt

   broker = Ccxt(BIT2C_CONFIG)
   # then: MyStrategy(broker=broker, ...)

Either way, LumiBot turns on CCXT's built-in rate limiting for you.

Testing on Bit2C
----------------

Bit2C has no sandbox, so test with a very small amount. With environment variables, leave ``BIT2C_SANDBOX`` unset. In a code config, set ``"sandbox": False``.

Algorithmic trading example: a simple Bit2C bot
-----------------------------------------------

This bot buys about 150 NIS of BTC on Bit2C once and then holds it. It is a starting point to check that your keys, balances and orders work. If the exchange's minimum order is larger, raise the amount.

.. code-block:: python

   from lumibot.entities import Asset
   from lumibot.strategies import Strategy


   class Bit2cBuyOnce(Strategy):
       """Buy a small amount of BTC once, then hold it."""

       def initialize(self):
           self.sleeptime = "1H"
           self.set_market("24/7")  # crypto trades all day, every day

       def on_trading_iteration(self):
           coin = Asset("BTC", asset_type=Asset.AssetType.CRYPTO)
           if self.get_position(coin) is not None:
               return  # already holding BTC
           price = self.get_last_price(coin, quote=self.quote_asset)
           if price:
               quantity = round(150 / price, 6)  # about 150 NIS worth
               order = self.create_order(coin, quantity, "buy", quote=self.quote_asset)
               self.submit_order(order)


   if __name__ == "__main__":
       # LumiBot reads TRADING_BROKER and the keys from your .env file.
       strategy = Bit2cBuyOnce(quote_asset=Asset("NIS", asset_type=Asset.AssetType.CRYPTO))
       strategy.run_live()

Agentic trading example: an AI agent that trades on Bit2C
---------------------------------------------------------

Agentic trading means an AI agent reads the market and decides what to do. In this example one LumiBot agent looks at prices and your Bit2C account, then places the orders itself. There is no Python logic in between: you set the rules in plain English in the prompt, such as what it may trade and how big each order can be. This follows the same pattern as LumiBot's AI trading team examples.

.. code-block:: python

   from lumibot.entities import Asset
   from lumibot.strategies import Strategy


   class Bit2cAITrader(Strategy):
       """One AI agent researches the market and places the trades itself."""

       def initialize(self):
           self.sleeptime = "4H"
           self.set_market("24/7")
           self.agents.create(
               name="trader",
               model="openai/gpt-6-luna",
               reasoning_effort="high",
               allow_trading=True,
               system_prompt=(
                   "You manage a small crypto account on Bit2C. "
                   "You may trade BTC and ETH against NIS (asset_type 'crypto', quote_symbol 'NIS'), or hold cash. "
                   "Before every order, call account_portfolio, account_positions and "
                   "market_last_price for that exact symbol in the same run. "
                   "Keep each order under 10% of the account value. "
                   "Explain each decision in one short paragraph."
               ),
           )

       def on_trading_iteration(self):
           self.agents["trader"].run(
               task_prompt="Review recent BTC/NIS and ETH/NIS prices and your current holdings, then decide whether to buy, sell or hold.",
               context={"exchange": "Bit2C", "quote": "NIS", "date": self.get_datetime().isoformat()},
           )


   if __name__ == "__main__":
       # LumiBot reads TRADING_BROKER and the keys from your .env file.
       strategy = Bit2cAITrader(quote_asset=Asset("NIS", asset_type=Asset.AssetType.CRYPTO))
       strategy.run_live()

The agent needs a model key such as ``OPENAI_API_KEY`` in your environment. See the :doc:`AI agents quickstart <agents_quickstart>` for models, tools and memory.

Fees and partner IDs on Bit2C
-----------------------------

You pay Bit2C's normal trading fees. LumiBot may attach its own exchange partner ID. That costs you nothing extra. LumiBot never adds an extra builder fee unless one is turned on, and it logs a warning when one is.

Bit2C tips
----------

* Bit2C prices are in shekels, and CCXT names the pair ``BTC/NIS``.
* Bit2C uses two-step checks with a code sent by SMS. You need it to log in, to send crypto out, and to manage API keys, so keep your phone number current.
* Every private request carries a nonce that must go up each time. Run only one bot per key so two programs do not fight over the nonce.

Frequently asked questions
--------------------------

**Can I build a Bit2C trading bot in Python?**

Yes. Install LumiBot (``pip install lumibot``), set your Bit2C keys and use the ``bit2c`` CCXT exchange id as shown above.

**Does Bit2C have a testnet?**

No testnet is set up for Bit2C in LumiBot. Start with a small amount, and in a code config set ``"sandbox": False``.

**Which API permissions does a Bit2C bot need?**

Bit2C's own pages do not list the permission names. Give the key what it needs to read your balance and orders and to trade. If the key screen offers withdrawals, leave them off.

**Can an AI agent trade on Bit2C by itself?**

Yes. The agentic example above gives one agent permission to trade. You control what it may trade and how much through its prompt.

**Can I trade Bit2C perpetual futures with LumiBot?**

CCXT does not list perpetual swaps for Bit2C, so use spot markets.

**Is LumiBot free?**

Yes. LumiBot is open source on GitHub at https://github.com/Lumiwealth/lumibot. You pay only your exchange's trading fees and, for AI agents, your model provider.
