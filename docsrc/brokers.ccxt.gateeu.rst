What is Gate EU?
----------------

Gate EU (Gate Europe) is the European platform of the Gate crypto exchange. It offers spot trading, convert, staking and euro funding.

Sign up for Gate EU
-------------------

#. Create a Gate EU account at https://www.gate.com/en-eu/signup.
#. Finish account verification. Gate asks for this before you can create API keys.
#. Set a fund password and turn on two-factor authentication. Gate needs both to confirm a new API key.

`Open a Gate EU account <https://www.gate.com/en-eu/signup>`_

Create a Gate EU API key
------------------------

#. Log in, hover over the profile icon and choose API Management (Gate's docs call this account management, then APIv4 keys).
#. Click Create API Key and choose an API v4 key.
#. Add a note (remark) and, if your bot has a fixed IP address, bind the key to it.
#. Set the permissions (see below) and pick the currency pairs the key may trade.
#. Read and accept the risk reminder, then enter your fund password and 2FA code to confirm.
#. Copy the API key and secret and store them somewhere safe.

**Which permissions to turn on:** Gate EU groups permissions into spot, wallet and withdrawal, and each can be off, read-only or read-write. For a trading bot, set spot to read-write. Leave withdrawal off. A bot never needs to move money out of your account.

.. warning::

   Never turn on withdrawals for a Gate EU trading bot key. Bind the key to your server's IP address when Gate EU lets you, keep the secret out of your code and out of Git, and delete the key if it ever leaks.

Connect Gate EU to LumiBot
--------------------------

The simplest way: put these lines in a ``.env`` file next to your strategy. LumiBot loads the file, sees ``TRADING_BROKER=gateeu`` and connects to Gate EU for you, so your strategy needs no broker code.

.. code-block:: bash

   TRADING_BROKER=gateeu
   GATEEU_API_KEY=your_apiKey
   GATEEU_API_SECRET=your_secret

LumiBot reads exactly the fields CCXT needs for Gate EU (``apiKey``, ``secret``). If one is missing, LumiBot stops at start-up and names the variable you still need.

You can also build the broker in code. This is handy when one script talks to more than one exchange, or when you need extra CCXT options. The keys in the config are CCXT's own credential names for Gate EU:

.. code-block:: python

   import os

   GATEEU_CONFIG = {
       "exchange_id": "gateeu",
       "apiKey": os.environ.get("GATEEU_API_KEY"),
       "secret": os.environ.get("GATEEU_API_SECRET"),
       "sandbox": False,  # no sandbox for this exchange
   }

   from lumibot.brokers import Ccxt

   broker = Ccxt(GATEEU_CONFIG)
   # then: MyStrategy(broker=broker, ...)

Either way, LumiBot turns on CCXT's built-in rate limiting for you.

Testing on Gate EU
------------------

Gate EU's API docs do not describe a testnet for Gate EU accounts, so test with a very small amount. With environment variables, leave ``GATEEU_SANDBOX`` unset. In a code config, set ``"sandbox": False``.

Algorithmic trading example: a simple Gate EU bot
-------------------------------------------------

This bot buys about 45 EUR of BTC on Gate EU once and then holds it. It is a starting point to check that your keys, balances and orders work. If the exchange's minimum order is larger, raise the amount.

.. code-block:: python

   from lumibot.entities import Asset
   from lumibot.strategies import Strategy


   class GateeuBuyOnce(Strategy):
       """Buy a small amount of BTC once, then hold it."""

       def initialize(self):
           self.sleeptime = "1H"
           self.set_market("24/7")  # crypto trades all day, every day

       def on_trading_iteration(self):
           coin = Asset("BTC", asset_type=Asset.AssetType.CRYPTO)
           if self.get_position(coin) is not None:
               return  # already holding BTC
           price = self.get_last_price(coin, quote=self.quote_asset)
           if price:
               quantity = round(45 / price, 6)  # about 45 EUR worth
               order = self.create_order(coin, quantity, "buy", quote=self.quote_asset)
               self.submit_order(order)


   if __name__ == "__main__":
       # LumiBot reads TRADING_BROKER and the keys from your .env file.
       strategy = GateeuBuyOnce(quote_asset=Asset("EUR", asset_type=Asset.AssetType.CRYPTO))
       strategy.run_live()

Agentic trading example: an AI agent that trades on Gate EU
-----------------------------------------------------------

Agentic trading means an AI agent reads the market and decides what to do. In this example one LumiBot agent looks at prices and your Gate EU account, then places the orders itself. There is no Python logic in between: you set the rules in plain English in the prompt, such as what it may trade and how big each order can be. This follows the same pattern as LumiBot's AI trading team examples.

.. code-block:: python

   from lumibot.entities import Asset
   from lumibot.strategies import Strategy


   class GateeuAITrader(Strategy):
       """One AI agent researches the market and places the trades itself."""

       def initialize(self):
           self.sleeptime = "4H"
           self.set_market("24/7")
           self.agents.create(
               name="trader",
               model="openai/gpt-6-luna",
               reasoning_effort="high",
               allow_trading=True,
               system_prompt=(
                   "You manage a small crypto account on Gate EU. "
                   "You may trade BTC and ETH against EUR (asset_type 'crypto', quote_symbol 'EUR'), or hold cash. "
                   "Before every order, call account_portfolio, account_positions and "
                   "market_last_price for that exact symbol in the same run. "
                   "Keep each order under 10% of the account value. "
                   "Explain each decision in one short paragraph."
               ),
           )

       def on_trading_iteration(self):
           self.agents["trader"].run(
               task_prompt="Review recent BTC/EUR and ETH/EUR prices and your current holdings, then decide whether to buy, sell or hold.",
               context={"exchange": "Gate EU", "quote": "EUR", "date": self.get_datetime().isoformat()},
           )


   if __name__ == "__main__":
       # LumiBot reads TRADING_BROKER and the keys from your .env file.
       strategy = GateeuAITrader(quote_asset=Asset("EUR", asset_type=Asset.AssetType.CRYPTO))
       strategy.run_live()

The agent needs a model key such as ``OPENAI_API_KEY`` in your environment. See the :doc:`AI agents quickstart <agents_quickstart>` for models, tools and memory.

Fees and partner IDs on Gate EU
-------------------------------

You pay Gate EU's normal trading fees. LumiBot may attach its own exchange partner ID. That costs you nothing extra. LumiBot never adds an extra builder fee unless one is turned on, and it logs a warning when one is.

Gate EU tips
------------

* Gate EU has its own API host, ``https://api.gateeu.com/api/v4``, hosted in Paris. Use the ``gateeu`` id with keys from your Gate EU account. The global Gate site uses a separate CCXT id, ``gate``.
* If you do not bind an IP address, Gate's help says the key works from any address but expires after 90 days. Bind your bot's IP (up to 20 IPv4 addresses per key) to avoid a surprise expiry.
* Gate writes pairs as ``BTC_EUR``. In LumiBot and CCXT use ``BTC/EUR``. Gate EU also lists USDC pairs such as ``BTC/USDC``.
* Each Gate account can hold several API v4 keys with separate permissions, so you can give each bot its own key.

Frequently asked questions
--------------------------

**Can I build a Gate EU trading bot in Python?**

Yes. Install LumiBot (``pip install lumibot``), set your Gate EU keys and use the ``gateeu`` CCXT exchange id as shown above.

**Does Gate EU have a testnet?**

No testnet is set up for Gate EU in LumiBot. Start with a small amount, and in a code config set ``"sandbox": False``.

**Which API permissions does a Gate EU bot need?**

Gate EU groups permissions into spot, wallet and withdrawal, and each can be off, read-only or read-write. For a trading bot, set spot to read-write. Leave withdrawal off. A bot never needs to move money out of your account.

**Can an AI agent trade on Gate EU by itself?**

Yes. The agentic example above gives one agent permission to trade. You control what it may trade and how much through its prompt.

**Can I trade Gate EU perpetual futures with LumiBot?**

CCXT does not list perpetual swaps for Gate EU, so use spot markets.

**Is LumiBot free?**

Yes. LumiBot is open source on GitHub at https://github.com/Lumiwealth/lumibot. You pay only your exchange's trading fees and, for AI agents, your model provider.
