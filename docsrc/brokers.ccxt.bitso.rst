What is Bitso?
--------------

Bitso is a crypto exchange for buying, selling and trading digital and fiat currencies. Its order books include BTC against MXN, USD, USDT, BRL and ARS.

Sign up for Bitso
-----------------

#. Create a Bitso account and finish identity verification.
#. Turn on two-step verification with an authenticator app. Bitso will not let you create API keys without it.
#. For practice, also create a separate account on Bitso's testing site at https://stage.bitso.com. Testing keys only work there.

`Open a Bitso account <https://bitso.com/>`_

Create a Bitso API key
----------------------

#. Log in from the web, not the app. Bitso only lets you make keys on the web.
#. Click your profile icon, choose API in the left menu, and click Add new API.
#. Read the security message, check the box and continue.
#. Name the key. If you like, add up to five IP addresses that may use it.
#. Choose the permissions (see below) and enter your two-step code.
#. Save the key and secret right away. Bitso shows them only once.

**Which permissions to turn on:** Turn on Buy/sell orders and Balance inquiry. Bitso's API docs call these Place orders and View balances. Leave withdrawals off. A bot never needs to move money out of your account.

.. warning::

   Never turn on withdrawals for a Bitso trading bot key. Bind the key to your server's IP address when Bitso lets you, keep the secret out of your code and out of Git, and delete the key if it ever leaks.

Connect Bitso to LumiBot
------------------------

The simplest way: put these lines in a ``.env`` file next to your strategy. LumiBot loads the file, sees ``TRADING_BROKER=bitso`` and connects to Bitso for you, so your strategy needs no broker code.

.. code-block:: bash

   TRADING_BROKER=bitso
   BITSO_API_KEY=your_apiKey
   BITSO_API_SECRET=your_secret
   BITSO_SANDBOX=true   # testnet; remove this line for your live account

LumiBot reads exactly the fields CCXT needs for Bitso (``apiKey``, ``secret``). If one is missing, LumiBot stops at start-up and names the variable you still need.

You can also build the broker in code. This is handy when one script talks to more than one exchange, or when you need extra CCXT options. The keys in the config are CCXT's own credential names for Bitso:

.. code-block:: python

   import os

   BITSO_CONFIG = {
       "exchange_id": "bitso",
       "apiKey": os.environ.get("BITSO_API_KEY"),
       "secret": os.environ.get("BITSO_API_SECRET"),
       "sandbox": True,  # testnet first; set False for your live account
   }

   from lumibot.brokers import Ccxt

   broker = Ccxt(BITSO_CONFIG)
   # then: MyStrategy(broker=broker, ...)

Either way, LumiBot turns on CCXT's built-in rate limiting for you.

Practice on the Bitso testnet
-----------------------------

Bitso has a separate testing environment at https://stage.bitso.com with its own accounts and keys. Bitso says to test there, not in production. Set ``BITSO_SANDBOX=true`` (or ``"sandbox": True`` in a code config) to use it.

CCXT sends sandbox requests to: https://stage.bitso.com/api. Testnet and live accounts use different keys.

Algorithmic trading example: a simple Bitso bot
-----------------------------------------------

This bot buys about 1000 MXN of BTC on Bitso once and then holds it. It is a starting point to check that your keys, balances and orders work. If the exchange's minimum order is larger, raise the amount.

.. code-block:: python

   from lumibot.entities import Asset
   from lumibot.strategies import Strategy


   class BitsoBuyOnce(Strategy):
       """Buy a small amount of BTC once, then hold it."""

       def initialize(self):
           self.sleeptime = "1H"
           self.set_market("24/7")  # crypto trades all day, every day

       def on_trading_iteration(self):
           coin = Asset("BTC", asset_type=Asset.AssetType.CRYPTO)
           if self.get_position(coin) is not None:
               return  # already holding BTC
           price = self.get_last_price(coin, quote=self.quote_asset)
           if price:
               quantity = round(1000 / price, 6)  # about 1000 MXN worth
               order = self.create_order(coin, quantity, "buy", quote=self.quote_asset)
               self.submit_order(order)


   if __name__ == "__main__":
       # LumiBot reads TRADING_BROKER and the keys from your .env file.
       strategy = BitsoBuyOnce(quote_asset=Asset("MXN", asset_type=Asset.AssetType.CRYPTO))
       strategy.run_live()

Agentic trading example: an AI agent that trades on Bitso
---------------------------------------------------------

Agentic trading means an AI agent reads the market and decides what to do. In this example one LumiBot agent looks at prices and your Bitso account, then places the orders itself. There is no Python logic in between: you set the rules in plain English in the prompt, such as what it may trade and how big each order can be. This follows the same pattern as LumiBot's AI trading team examples.

.. code-block:: python

   from lumibot.entities import Asset
   from lumibot.strategies import Strategy


   class BitsoAITrader(Strategy):
       """One AI agent researches the market and places the trades itself."""

       def initialize(self):
           self.sleeptime = "4H"
           self.set_market("24/7")
           self.agents.create(
               name="trader",
               model="openai/gpt-6-luna",
               reasoning_effort="high",
               allow_trading=True,
               system_prompt=(
                   "You manage a small crypto account on Bitso. "
                   "You may trade BTC and ETH against MXN (asset_type 'crypto', quote_symbol 'MXN'), or hold cash. "
                   "Before every order, call account_portfolio, account_positions and "
                   "market_last_price for that exact symbol in the same run. "
                   "Keep each order under 10% of the account value. "
                   "Explain each decision in one short paragraph."
               ),
           )

       def on_trading_iteration(self):
           self.agents["trader"].run(
               task_prompt="Review recent BTC/MXN and ETH/MXN prices and your current holdings, then decide whether to buy, sell or hold.",
               context={"exchange": "Bitso", "quote": "MXN", "date": self.get_datetime().isoformat()},
           )


   if __name__ == "__main__":
       # LumiBot reads TRADING_BROKER and the keys from your .env file.
       strategy = BitsoAITrader(quote_asset=Asset("MXN", asset_type=Asset.AssetType.CRYPTO))
       strategy.run_live()

The agent needs a model key such as ``OPENAI_API_KEY`` in your environment. See the :doc:`AI agents quickstart <agents_quickstart>` for models, tools and memory.

Fees and partner IDs on Bitso
-----------------------------

You pay Bitso's normal trading fees. LumiBot may attach its own exchange partner ID. That costs you nothing extra. LumiBot never adds an extra builder fee unless one is turned on, and it logs a warning when one is.

Bitso tips
----------

* You can have up to six active API keys. If you hit the limit, delete a key you no longer use.
* Testing and production accounts are separate. Make keys in each one and use the right keys for each environment.
* If you lose the secret, you cannot see it again. Delete that key and create a new one.

Frequently asked questions
--------------------------

**Can I build a Bitso trading bot in Python?**

Yes. Install LumiBot (``pip install lumibot``), set your Bitso keys and use the ``bitso`` CCXT exchange id as shown above.

**Does Bitso have a testnet?**

Yes. Set ``BITSO_SANDBOX=true`` and use keys from the Bitso testnet.

**Which API permissions does a Bitso bot need?**

Turn on Buy/sell orders and Balance inquiry. Bitso's API docs call these Place orders and View balances. Leave withdrawals off. A bot never needs to move money out of your account.

**Can an AI agent trade on Bitso by itself?**

Yes. The agentic example above gives one agent permission to trade. You control what it may trade and how much through its prompt.

**Can I trade Bitso perpetual futures with LumiBot?**

CCXT does not list perpetual swaps for Bitso, so use spot markets.

**Is LumiBot free?**

Yes. LumiBot is open source on GitHub at https://github.com/Lumiwealth/lumibot. You pay only your exchange's trading fees and, for AI agents, your model provider.
