What is Phemex?
---------------

Phemex is a crypto exchange founded in 2019 that offers spot trading and perpetual futures. Phemex says more than 10 million traders use it.

Sign up for Phemex
------------------

#. Create a Phemex account with an email address (or another sign-in method Phemex offers).
#. Finish identity verification (KYC) and turn on two-factor authentication.
#. For practice, also create a separate account on the Phemex testnet at https://testnet.phemex.com. Testnet keys only work on the testnet.

`Open a Phemex account <https://phemex.com/register>`_

Create a Phemex API key
-----------------------

#. Log in and open API Management from your account menu (https://phemex.com/account/api-management).
#. Click Create New API Key.
#. Choose Default API entry. The High Rate Limit entry is meant for heavy, professional use.
#. Enter a name and the IP address of the machine that will run your bot.
#. Pick the permission level, click Confirm and enter the email verification code.
#. Copy the key and secret right away. Phemex shows the key only once.

**Which permissions to turn on:** Use read and trade access. Leave withdrawals off. A bot never needs to move money out of your account.

.. warning::

   Never turn on withdrawals for a Phemex trading bot key. Bind the key to your server's IP address when Phemex lets you, keep the secret out of your code and out of Git, and delete the key if it ever leaks.

Connect Phemex to LumiBot
-------------------------

The simplest way: put these lines in a ``.env`` file next to your strategy. LumiBot loads the file, sees ``TRADING_BROKER=phemex`` and connects to Phemex for you, so your strategy needs no broker code.

.. code-block:: bash

   TRADING_BROKER=phemex
   PHEMEX_API_KEY=your_apiKey
   PHEMEX_API_SECRET=your_secret
   PHEMEX_SANDBOX=true   # testnet; remove this line for your live account

LumiBot reads exactly the fields CCXT needs for Phemex (``apiKey``, ``secret``). If one is missing, LumiBot stops at start-up and names the variable you still need.

You can also build the broker in code. This is handy when one script talks to more than one exchange, or when you need extra CCXT options. The keys in the config are CCXT's own credential names for Phemex:

.. code-block:: python

   import os

   PHEMEX_CONFIG = {
       "exchange_id": "phemex",
       "apiKey": os.environ.get("PHEMEX_API_KEY"),
       "secret": os.environ.get("PHEMEX_API_SECRET"),
       "sandbox": True,  # testnet first; set False for your live account
   }

   from lumibot.brokers import Ccxt

   broker = Ccxt(PHEMEX_CONFIG)
   # then: MyStrategy(broker=broker, ...)

Either way, LumiBot turns on CCXT's built-in rate limiting for you.

Practice on the Phemex testnet
------------------------------

Phemex runs a full testnet at https://testnet.phemex.com with its own accounts and keys. Set ``PHEMEX_SANDBOX=true`` (or ``"sandbox": True`` in a code config) to send LumiBot requests there.

CCXT sends sandbox requests to: https://testnet-api.phemex.com/v1, https://testnet-api.phemex.com. Testnet and live accounts use different keys.

Algorithmic trading example: a simple Phemex bot
------------------------------------------------

This bot buys about 50 USDT of BTC on Phemex once and then holds it. It is a starting point to check that your keys, balances and orders work. If the exchange's minimum order is larger, raise the amount. Phemex accepts only limit orders through CCXT, so the example places a limit order just above the last price.

.. code-block:: python

   from lumibot.entities import Asset
   from lumibot.strategies import Strategy


   class PhemexBuyOnce(Strategy):
       """Buy a small amount of BTC once, then hold it."""

       def initialize(self):
           self.sleeptime = "1H"
           self.set_market("24/7")  # crypto trades all day, every day

       def on_trading_iteration(self):
           coin = Asset("BTC", asset_type=Asset.AssetType.CRYPTO)
           if self.get_position(coin) is not None:
               return  # already holding BTC
           price = self.get_last_price(coin, quote=self.quote_asset)
           if price:
               quantity = round(50 / price, 6)  # about 50 USDT worth
               # This exchange takes only limit orders through CCXT.
               order = self.create_order(coin, quantity, "buy", limit_price=price * 1.002, quote=self.quote_asset)
               self.submit_order(order)


   if __name__ == "__main__":
       # LumiBot reads TRADING_BROKER and the keys from your .env file.
       strategy = PhemexBuyOnce(quote_asset=Asset("USDT", asset_type=Asset.AssetType.CRYPTO))
       strategy.run_live()

Agentic trading example: an AI agent that trades on Phemex
----------------------------------------------------------

Agentic trading means an AI agent reads the market and decides what to do. In this example one LumiBot agent looks at prices and your Phemex account, then places the orders itself. There is no Python logic in between: you set the rules in plain English in the prompt, such as what it may trade and how big each order can be. This follows the same pattern as LumiBot's AI trading team examples.

.. code-block:: python

   from lumibot.entities import Asset
   from lumibot.strategies import Strategy


   class PhemexAITrader(Strategy):
       """One AI agent researches the market and places the trades itself."""

       def initialize(self):
           self.sleeptime = "4H"
           self.set_market("24/7")
           self.agents.create(
               name="trader",
               model="openai/gpt-6-luna",
               reasoning_effort="high",
               allow_trading=True,
               system_prompt=(
                   "You manage a small crypto account on Phemex. "
                   "You may trade BTC and ETH against USDT (asset_type 'crypto', quote_symbol 'USDT'), or hold cash. "
                   "Before every order, call account_portfolio, account_positions and "
                   "market_last_price for that exact symbol in the same run. "
                   "Keep each order under 10% of the account value. "
                   "Explain each decision in one short paragraph."
               ),
           )

       def on_trading_iteration(self):
           self.agents["trader"].run(
               task_prompt="Review recent BTC/USDT and ETH/USDT prices and your current holdings, then decide whether to buy, sell or hold.",
               context={"exchange": "Phemex", "quote": "USDT", "date": self.get_datetime().isoformat()},
           )


   if __name__ == "__main__":
       # LumiBot reads TRADING_BROKER and the keys from your .env file.
       strategy = PhemexAITrader(quote_asset=Asset("USDT", asset_type=Asset.AssetType.CRYPTO))
       strategy.run_live()

The agent needs a model key such as ``OPENAI_API_KEY`` in your environment. See the :doc:`AI agents quickstart <agents_quickstart>` for models, tools and memory.

Perpetual futures example on Phemex
-----------------------------------

Phemex also lists perpetual swaps. This bot opens one small long position in ``BTC/USDT:USDT`` worth about 50 USDT and then holds it. LumiBot treats a perpetual as ``asset_type="crypto_future"`` and sizes it in contracts, the same model as LumiBot's Bitunix futures broker. Contract symbols can differ by exchange, so check the symbol in ``self.broker.api.markets`` before going live. In hedge mode, add ``position_side="long"`` to ``create_order``. Phemex accepts only limit orders through CCXT, so the example places a limit order just above the last price.

.. code-block:: python

   from lumibot.entities import Asset
   from lumibot.strategies import Strategy


   class PhemexOpenOneLong(Strategy):
       """Open one small long BTC perpetual position, then hold it."""

       def initialize(self):
           self.sleeptime = "1H"
           self.set_market("24/7")  # crypto trades all day, every day

       def on_trading_iteration(self):
           # The full CCXT symbol keeps the settlement currency clear.
           contract = self.broker.get_asset("BTC/USDT:USDT")
           if self.get_position(contract) is not None:
               return  # already holding the position
           price = self.get_last_price(contract)
           if price:
               # Each contract covers contract.multiplier BTC; size the order to about 50 USDT.
               quantity = round(50 / (price * contract.multiplier), 6)
               # This exchange takes only limit orders through CCXT.
               order = self.create_order(contract, quantity, "buy", limit_price=price * 1.002)
               self.submit_order(order)


   if __name__ == "__main__":
       # LumiBot reads TRADING_BROKER and the keys from your .env file.
       strategy = PhemexOpenOneLong(quote_asset=Asset("USDT", asset_type=Asset.AssetType.CRYPTO))
       strategy.run_live()

Fees and partner IDs on Phemex
------------------------------

You pay Phemex's normal trading fees. CCXT, the library underneath, normally tags Phemex orders with its own partner ID. LumiBot removes that tag. LumiBot may attach its own exchange partner ID instead. That costs you nothing extra. LumiBot never adds an extra builder fee unless one is turned on, and it logs a warning when one is.

Phemex tips
-----------

* Phemex perpetual symbols use the full CCXT form, for example ``BTC/USDT:USDT`` (settled in USDT) or ``BTC/USD:BTC`` (inverse, settled in BTC). Spot is plain ``BTC/USDT``.
* Phemex also offers sub-accounts, and you can share one API key with sub-accounts from API Management. A separate sub-account per bot keeps bot trades apart from manual trades.

Frequently asked questions
--------------------------

**Can I build a Phemex trading bot in Python?**

Yes. Install LumiBot (``pip install lumibot``), set your Phemex keys and use the ``phemex`` CCXT exchange id as shown above.

**Does Phemex have a testnet?**

Yes. Set ``PHEMEX_SANDBOX=true`` and use keys from the Phemex testnet.

**Which API permissions does a Phemex bot need?**

Use read and trade access. Leave withdrawals off. A bot never needs to move money out of your account.

**Can an AI agent trade on Phemex by itself?**

Yes. The agentic example above gives one agent permission to trade. You control what it may trade and how much through its prompt.

**Can I trade Phemex perpetual futures with LumiBot?**

CCXT lists perpetual swaps for this exchange. Use the full contract symbol, such as ``BTC/USDT:USDT``.

**Is LumiBot free?**

Yes. LumiBot is open source on GitHub at https://github.com/Lumiwealth/lumibot. You pay only your exchange's trading fees and, for AI agents, your model provider.
