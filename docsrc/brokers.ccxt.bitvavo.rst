What is Bitvavo?
----------------

Bitvavo is a crypto exchange based in the Netherlands. It offers spot trading with prices in euros.

Sign up for Bitvavo
-------------------

#. Create a Bitvavo account and finish identity verification.
#. Turn on two-factor authentication. Bitvavo will not let you create API keys without it.
#. Bitvavo has no testnet, so plan to test with a very small amount.

`Open a Bitvavo account <https://bitvavo.com/>`_

Create a Bitvavo API key
------------------------

#. Log in on the website (keys cannot be made in the app), click your name and choose Settings.
#. Open the API tab and click Add new API key.
#. Enter a name and the IP address of your bot. Separate more than one IP with commas.
#. Choose the permissions (see below).
#. Enter your two-factor code and click Confirm. Save the key and secret right away; you cannot see the secret again.

**Which permissions to turn on:** Turn on View access and Trade digital assets. Bitvavo needs both to read your orders and trades. Leave Withdraw digital assets off: Bitvavo warns that API withdrawals skip two-factor and email checks.

.. warning::

   Never turn on withdrawals for a Bitvavo trading bot key. Bind the key to your server's IP address when Bitvavo lets you, keep the secret out of your code and out of Git, and delete the key if it ever leaks.

Connect Bitvavo to LumiBot
--------------------------

The simplest way: put these lines in a ``.env`` file next to your strategy. LumiBot loads the file, sees ``TRADING_BROKER=bitvavo`` and connects to Bitvavo for you, so your strategy needs no broker code.

.. code-block:: bash

   TRADING_BROKER=bitvavo
   BITVAVO_API_KEY=your_apiKey
   BITVAVO_API_SECRET=your_secret

LumiBot reads exactly the fields CCXT needs for Bitvavo (``apiKey``, ``secret``). If one is missing, LumiBot stops at start-up and names the variable you still need.

You can also build the broker in code. This is handy when one script talks to more than one exchange, or when you need extra CCXT options. The keys in the config are CCXT's own credential names for Bitvavo:

.. code-block:: python

   import os

   BITVAVO_CONFIG = {
       "exchange_id": "bitvavo",
       "apiKey": os.environ.get("BITVAVO_API_KEY"),
       "secret": os.environ.get("BITVAVO_API_SECRET"),
       "sandbox": False,  # no sandbox for this exchange
   }

   from lumibot.brokers import Ccxt

   broker = Ccxt(BITVAVO_CONFIG)
   # then: MyStrategy(broker=broker, ...)

Either way, LumiBot turns on CCXT's built-in rate limiting for you.

Testing on Bitvavo
------------------

Bitvavo has no sandbox, and CCXT lists no test URL for it, so test with a very small amount. With environment variables, leave ``BITVAVO_SANDBOX`` unset. In a code config, always set ``"sandbox": False``: a code config without it turns sandbox mode on, and CCXT then fails because Bitvavo has no test site.

Algorithmic trading example: a simple Bitvavo bot
-------------------------------------------------

This bot buys about 50 EUR of BTC on Bitvavo once and then holds it. It is a starting point to check that your keys, balances and orders work. If the exchange's minimum order is larger, raise the amount.

.. code-block:: python

   from lumibot.entities import Asset
   from lumibot.strategies import Strategy


   class BitvavoBuyOnce(Strategy):
       """Buy a small amount of BTC once, then hold it."""

       def initialize(self):
           self.sleeptime = "1H"
           self.set_market("24/7")  # crypto trades all day, every day

       def on_trading_iteration(self):
           coin = Asset("BTC", asset_type=Asset.AssetType.CRYPTO)
           if self.get_position(coin) is not None:
               return  # already holding BTC
           price = self.get_last_price(coin, quote=self.quote_asset)
           if price:
               quantity = round(50 / price, 6)  # about 50 EUR worth
               order = self.create_order(coin, quantity, "buy", quote=self.quote_asset)
               self.submit_order(order)


   if __name__ == "__main__":
       # LumiBot reads TRADING_BROKER and the keys from your .env file.
       strategy = BitvavoBuyOnce(quote_asset=Asset("EUR", asset_type=Asset.AssetType.CRYPTO))
       strategy.run_live()

Agentic trading example: an AI agent that trades on Bitvavo
-----------------------------------------------------------

Agentic trading means an AI agent reads the market and decides what to do. In this example one LumiBot agent looks at prices and your Bitvavo account, then places the orders itself. There is no Python logic in between: you set the rules in plain English in the prompt, such as what it may trade and how big each order can be. This follows the same pattern as LumiBot's AI trading team examples.

.. code-block:: python

   from lumibot.entities import Asset
   from lumibot.strategies import Strategy


   class BitvavoAITrader(Strategy):
       """One AI agent researches the market and places the trades itself."""

       def initialize(self):
           self.sleeptime = "4H"
           self.set_market("24/7")
           self.agents.create(
               name="trader",
               model="openai/gpt-6-luna",
               reasoning_effort="high",
               allow_trading=True,
               system_prompt=(
                   "You manage a small crypto account on Bitvavo. "
                   "You may trade BTC and ETH against EUR (asset_type 'crypto', quote_symbol 'EUR'), or hold cash. "
                   "Before every order, call account_portfolio, account_positions and "
                   "market_last_price for that exact symbol in the same run. "
                   "Keep each order under 10% of the account value. "
                   "Explain each decision in one short paragraph."
               ),
           )

       def on_trading_iteration(self):
           self.agents["trader"].run(
               task_prompt="Review recent BTC/EUR and ETH/EUR prices and your current holdings, then decide whether to buy, sell or hold.",
               context={"exchange": "Bitvavo", "quote": "EUR", "date": self.get_datetime().isoformat()},
           )


   if __name__ == "__main__":
       # LumiBot reads TRADING_BROKER and the keys from your .env file.
       strategy = BitvavoAITrader(quote_asset=Asset("EUR", asset_type=Asset.AssetType.CRYPTO))
       strategy.run_live()

The agent needs a model key such as ``OPENAI_API_KEY`` in your environment. See the :doc:`AI agents quickstart <agents_quickstart>` for models, tools and memory.

Fees and partner IDs on Bitvavo
-------------------------------

You pay Bitvavo's normal trading fees. LumiBot may attach its own exchange partner ID. That costs you nothing extra. LumiBot never adds an extra builder fee unless one is turned on, and it logs a warning when one is.

Bitvavo tips
------------

* Bitvavo markets are priced in euros, so use ``EUR`` as your quote asset (for example ``BTC/EUR``).
* Bitvavo supports sub-accounts. An API key can be given access to sub-accounts and internal transfers, but a trading bot does not need those permissions.

Frequently asked questions
--------------------------

**Can I build a Bitvavo trading bot in Python?**

Yes. Install LumiBot (``pip install lumibot``), set your Bitvavo keys and use the ``bitvavo`` CCXT exchange id as shown above.

**Does Bitvavo have a testnet?**

No testnet is set up for Bitvavo in LumiBot. Start with a small amount, and in a code config set ``"sandbox": False``.

**Which API permissions does a Bitvavo bot need?**

Turn on View access and Trade digital assets. Bitvavo needs both to read your orders and trades. Leave Withdraw digital assets off: Bitvavo warns that API withdrawals skip two-factor and email checks.

**Can an AI agent trade on Bitvavo by itself?**

Yes. The agentic example above gives one agent permission to trade. You control what it may trade and how much through its prompt.

**Can I trade Bitvavo perpetual futures with LumiBot?**

CCXT does not list perpetual swaps for Bitvavo, so use spot markets.

**Is LumiBot free?**

Yes. LumiBot is open source on GitHub at https://github.com/Lumiwealth/lumibot. You pay only your exchange's trading fees and, for AI agents, your model provider.
