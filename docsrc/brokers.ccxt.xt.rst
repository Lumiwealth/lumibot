What is XT?
-----------

XT.COM is a crypto exchange that offers spot trading, futures, margin trading and copy trading. Its API covers spot and futures trading, among other services.

Sign up for XT
--------------

#. Visit www.xt.com, click Sign up and register with your email or phone number. Enter the 6-digit code XT.COM sends you.
#. Complete identity verification: go to Profile, then KYC Verification, click Verify Now and follow the steps (ID document photos and a live face check). XT.COM says review usually takes up to 2 business days.
#. Turn on Google Authenticator. You need its code to create an API key.

`Open a XT account <https://www.xt.com>`_

Create a XT API key
-------------------

#. Log in at www.xt.com and open API Management in the User Center.
#. Apply for API trading first: click Create API, then Submit for Review. XT.COM reviews the request for risk control, which can take 3 to 5 business days.
#. Once approved, go back to API Management, enter an Alias Name and your bot's IP address in Whitelist IP.
#. Enter your Google verification code and click Create API.
#. Copy the Public Key and Private Key (secret) right away. XT.COM shows them only once and cannot recover a lost secret.
#. Click Modify on the new key to turn on trading permission (see below).

**Which permissions to turn on:** A new XT.COM key has query (read) permission only. Use Modify to turn on trading for the markets you trade. Leave withdrawal off. A bot never needs to move money out of your account.

.. warning::

   Never turn on withdrawals for a XT trading bot key. Bind the key to your server's IP address when XT lets you, keep the secret out of your code and out of Git, and delete the key if it ever leaks.

Connect XT to LumiBot
---------------------

The simplest way: put these lines in a ``.env`` file next to your strategy. LumiBot loads the file, sees ``TRADING_BROKER=xt`` and connects to XT for you, so your strategy needs no broker code.

.. code-block:: bash

   TRADING_BROKER=xt
   XT_API_KEY=your_apiKey
   XT_API_SECRET=your_secret

LumiBot reads exactly the fields CCXT needs for XT (``apiKey``, ``secret``). If one is missing, LumiBot stops at start-up and names the variable you still need.

You can also build the broker in code. This is handy when one script talks to more than one exchange, or when you need extra CCXT options. The keys in the config are CCXT's own credential names for XT:

.. code-block:: python

   import os

   XT_CONFIG = {
       "exchange_id": "xt",
       "apiKey": os.environ.get("XT_API_KEY"),
       "secret": os.environ.get("XT_API_SECRET"),
       "sandbox": False,  # no sandbox for this exchange
   }

   from lumibot.brokers import Ccxt

   broker = Ccxt(XT_CONFIG)
   # then: MyStrategy(broker=broker, ...)

Either way, LumiBot turns on CCXT's built-in rate limiting for you.

Testing on XT
-------------

XT.COM has no sandbox or testnet. Test with a very small amount on your real account, leave ``XT_SANDBOX`` unset, and in a code config set ``"sandbox": False``.

Algorithmic trading example: a simple XT bot
--------------------------------------------

This bot buys about 50 USDT of BTC on XT once and then holds it. It is a starting point to check that your keys, balances and orders work. If the exchange's minimum order is larger, raise the amount.

.. code-block:: python

   from lumibot.entities import Asset
   from lumibot.strategies import Strategy


   class XtBuyOnce(Strategy):
       """Buy a small amount of BTC once, then hold it."""

       def initialize(self):
           self.sleeptime = "1H"
           self.set_market("24/7")  # crypto trades all day, every day

       def on_trading_iteration(self):
           coin = Asset("BTC", asset_type=Asset.AssetType.CRYPTO)
           if self.get_position(coin) is not None:
               return  # already holding BTC
           price = self.get_last_price(coin, quote=self.quote_asset)
           if price:
               quantity = round(50 / price, 6)  # about 50 USDT worth
               order = self.create_order(coin, quantity, "buy", quote=self.quote_asset)
               self.submit_order(order)


   if __name__ == "__main__":
       # LumiBot reads TRADING_BROKER and the keys from your .env file.
       strategy = XtBuyOnce(quote_asset=Asset("USDT", asset_type=Asset.AssetType.CRYPTO))
       strategy.run_live()

Agentic trading example: an AI agent that trades on XT
------------------------------------------------------

Agentic trading means an AI agent reads the market and decides what to do. In this example one LumiBot agent looks at prices and your XT account, then places the orders itself. There is no Python logic in between: you set the rules in plain English in the prompt, such as what it may trade and how big each order can be. This follows the same pattern as LumiBot's AI trading team examples.

.. code-block:: python

   from lumibot.entities import Asset
   from lumibot.strategies import Strategy


   class XtAITrader(Strategy):
       """One AI agent researches the market and places the trades itself."""

       def initialize(self):
           self.sleeptime = "4H"
           self.set_market("24/7")
           self.agents.create(
               name="trader",
               model="openai/gpt-6-luna",
               reasoning_effort="high",
               allow_trading=True,
               system_prompt=(
                   "You manage a small crypto account on XT. "
                   "You may trade BTC and ETH against USDT (asset_type 'crypto', quote_symbol 'USDT'), or hold cash. "
                   "Before every order, call account_portfolio, account_positions and "
                   "market_last_price for that exact symbol in the same run. "
                   "Keep each order under 10% of the account value. "
                   "Explain each decision in one short paragraph."
               ),
           )

       def on_trading_iteration(self):
           self.agents["trader"].run(
               task_prompt="Review recent BTC/USDT and ETH/USDT prices and your current holdings, then decide whether to buy, sell or hold.",
               context={"exchange": "XT", "quote": "USDT", "date": self.get_datetime().isoformat()},
           )


   if __name__ == "__main__":
       # LumiBot reads TRADING_BROKER and the keys from your .env file.
       strategy = XtAITrader(quote_asset=Asset("USDT", asset_type=Asset.AssetType.CRYPTO))
       strategy.run_live()

The agent needs a model key such as ``OPENAI_API_KEY`` in your environment. See the :doc:`AI agents quickstart <agents_quickstart>` for models, tools and memory.

XT tips
-------

* API trading on XT.COM needs approval before your key can trade. XT.COM says a balance above 50,000 USDT speeds up the review, so apply early and wait for approval before starting the bot.
* Each user can create up to 10 API keys. Sub-accounts (up to 20 per main account) can each have their own keys, which helps keep each bot's funds apart.
* The spot REST API lives at https://sapi.xt.com. XT.COM advises against reaching the API through a proxy because of latency and stability problems.
* In LumiBot and CCXT use ``BTC/USDT`` for spot and ``BTC/USDT:USDT`` for the USDT perpetual.

Frequently asked questions
--------------------------

**Can I build a XT trading bot in Python?**

Yes. Install LumiBot (``pip install lumibot``), set your XT keys and use the ``xt`` CCXT exchange id as shown above.

**Does XT have a testnet?**

No testnet is set up for XT in LumiBot. Start with a small amount, and in a code config set ``"sandbox": False``.

**Which API permissions does a XT bot need?**

A new XT.COM key has query (read) permission only. Use Modify to turn on trading for the markets you trade. Leave withdrawal off. A bot never needs to move money out of your account.

**Can an AI agent trade on XT by itself?**

Yes. The agentic example above gives one agent permission to trade. You control what it may trade and how much through its prompt.

**Can I trade XT perpetual futures with LumiBot?**

CCXT lists perpetual swaps for this exchange. Use the full contract symbol, such as ``BTC/USDT:USDT``.

**Is LumiBot free?**

Yes. LumiBot is open source on GitHub at https://github.com/Lumiwealth/lumibot. You pay only your exchange's trading fees and, for AI agents, your model provider.
