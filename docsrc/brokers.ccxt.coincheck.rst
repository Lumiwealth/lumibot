What is Coincheck?
------------------

Coincheck is a crypto exchange run by Coincheck, Inc. It has a simple buy and sell desk and the Coincheck exchange, an order book for spot trading. Its API places and cancels orders on the exchange and checks your balance.

Sign up for Coincheck
---------------------

#. Open a personal account in the Coincheck app. Coincheck asks you to set up a passkey and agree to its terms.
#. Submit your identity document and basic details, then wait for Coincheck's review to finish.
#. Set up two-step authentication with an authenticator app. Coincheck asks for its code when you create an API key.

`Open a Coincheck account <https://coincheck.com>`_

Create a Coincheck API key
--------------------------

#. Log in and open the API page (https://coincheck.com/api_settings). You can also click the gear icon, then API Keys.
#. Click Add a new API key.
#. Under API key permissions, check the boxes the bot needs (see below). Enter the IP address of the machine that runs your bot, or leave it blank.
#. Type the same password you use to log in to Coincheck and click OK.
#. Enter the code from your authenticator app.
#. Copy the Access key and Secret Access key and keep them private.

**Which permissions to turn on:** Check the boxes for the order functions (new order, unsettled order list, cancel order, order transactions) and for account balance. Leave the send crypto and withdraw boxes off. A bot never needs to move money out of your account.

.. warning::

   Never turn on withdrawals for a Coincheck trading bot key. Bind the key to your server's IP address when Coincheck lets you, keep the secret out of your code and out of Git, and delete the key if it ever leaks.

Connect Coincheck to LumiBot
----------------------------

The simplest way: put these lines in a ``.env`` file next to your strategy. LumiBot loads the file, sees ``TRADING_BROKER=coincheck`` and connects to Coincheck for you, so your strategy needs no broker code.

.. code-block:: bash

   TRADING_BROKER=coincheck
   COINCHECK_API_KEY=your_apiKey
   COINCHECK_API_SECRET=your_secret

LumiBot reads exactly the fields CCXT needs for Coincheck (``apiKey``, ``secret``). If one is missing, LumiBot stops at start-up and names the variable you still need.

You can also build the broker in code. This is handy when one script talks to more than one exchange, or when you need extra CCXT options. The keys in the config are CCXT's own credential names for Coincheck:

.. code-block:: python

   import os

   COINCHECK_CONFIG = {
       "exchange_id": "coincheck",
       "apiKey": os.environ.get("COINCHECK_API_KEY"),
       "secret": os.environ.get("COINCHECK_API_SECRET"),
       "sandbox": False,  # live connection
   }

   from lumibot.brokers import Ccxt

   broker = Ccxt(COINCHECK_CONFIG)
   # then: MyStrategy(broker=broker, ...)

Either way, LumiBot turns on CCXT's built-in rate limiting for you.

Coincheck has no sandbox. Test with a very small amount, leave ``COINCHECK_SANDBOX`` unset, and in a code config set ``"sandbox": False``.

Algorithmic trading example: a simple Coincheck bot
---------------------------------------------------

This bot buys about 7500 JPY of BTC on Coincheck once and then holds it. It is a starting point to check that your keys, balances and orders work. If the exchange's minimum order is larger, raise the amount. Coincheck accepts only limit orders through CCXT, so the example places a limit order just above the last price.

.. code-block:: python

   from lumibot.entities import Asset
   from lumibot.strategies import Strategy


   class CoincheckBuyOnce(Strategy):
       """Buy a small amount of BTC once, then hold it."""

       def initialize(self):
           self.sleeptime = "1H"
           self.set_market("24/7")  # crypto trades all day, every day

       def on_trading_iteration(self):
           coin = Asset("BTC", asset_type=Asset.AssetType.CRYPTO)
           if self.get_position(coin) is not None:
               return  # already holding BTC
           price = self.get_last_price(coin, quote=self.quote_asset)
           if price:
               quantity = round(7500 / price, 6)  # about 7500 JPY worth
               # This exchange takes only limit orders through CCXT.
               order = self.create_order(coin, quantity, "buy", limit_price=price * 1.002, quote=self.quote_asset)
               self.submit_order(order)


   if __name__ == "__main__":
       # LumiBot reads TRADING_BROKER and the keys from your .env file.
       strategy = CoincheckBuyOnce(quote_asset=Asset("JPY", asset_type=Asset.AssetType.CRYPTO))
       strategy.run_live()

Agentic trading example: an AI agent that trades on Coincheck
-------------------------------------------------------------

Agentic trading means an AI agent reads the market and decides what to do. In this example one LumiBot agent looks at prices and your Coincheck account, then places the orders itself. There is no Python logic in between: you set the rules in plain English in the prompt, such as what it may trade and how big each order can be. This follows the same pattern as LumiBot's AI trading team examples.

.. code-block:: python

   from lumibot.entities import Asset
   from lumibot.strategies import Strategy


   class CoincheckAITrader(Strategy):
       """One AI agent researches the market and places the trades itself."""

       def initialize(self):
           self.sleeptime = "4H"
           self.set_market("24/7")
           self.agents.create(
               name="trader",
               model="openai/gpt-6-luna",
               reasoning_effort="high",
               allow_trading=True,
               system_prompt=(
                   "You manage a small crypto account on Coincheck. "
                   "You may trade BTC and ETH against JPY (asset_type 'crypto', quote_symbol 'JPY'), or hold cash. "
                   "Before every order, call account_portfolio, account_positions and "
                   "market_last_price for that exact symbol in the same run. "
                   "Keep each order under 10% of the account value. "
                   "Explain each decision in one short paragraph."
               ),
           )

       def on_trading_iteration(self):
           self.agents["trader"].run(
               task_prompt="Review recent BTC/JPY and ETH/JPY prices and your current holdings, then decide whether to buy, sell or hold.",
               context={"exchange": "Coincheck", "quote": "JPY", "date": self.get_datetime().isoformat()},
           )


   if __name__ == "__main__":
       # LumiBot reads TRADING_BROKER and the keys from your .env file.
       strategy = CoincheckAITrader(quote_asset=Asset("JPY", asset_type=Asset.AssetType.CRYPTO))
       strategy.run_live()

The agent needs a model key such as ``OPENAI_API_KEY`` in your environment. See the :doc:`AI agents quickstart <agents_quickstart>` for models, tools and memory.

Coincheck tips
--------------

* Coincheck needs only two credentials: the Access key (``COINCHECK_API_KEY``) and the Secret Access key (``COINCHECK_API_SECRET``). There is no passphrase.
* Coincheck lets you limit each key to IP addresses you choose. Add your server's IP so a leaked key cannot be used from somewhere else.
* If a key fails with a missing permission error, edit it and check the permission boxes again. Coincheck says a key with the wrong boxes cannot connect.

Frequently asked questions
--------------------------

**Can I build a Coincheck trading bot in Python?**

Yes. Install LumiBot (``pip install lumibot``), set your Coincheck keys and use the ``coincheck`` CCXT exchange id as shown above.

**Does Coincheck have a testnet?**

No testnet is set up for Coincheck in LumiBot. Start with a small amount, and in a code config set ``"sandbox": False``.

**Which API permissions does a Coincheck bot need?**

Check the boxes for the order functions (new order, unsettled order list, cancel order, order transactions) and for account balance. Leave the send crypto and withdraw boxes off. A bot never needs to move money out of your account.

**Can an AI agent trade on Coincheck by itself?**

Yes. The agentic example above gives one agent permission to trade. You control what it may trade and how much through its prompt.

**Can I trade Coincheck perpetual futures with LumiBot?**

CCXT does not list perpetual swaps for Coincheck, so use spot markets.

**Is LumiBot free?**

Yes. LumiBot is open source on GitHub at https://github.com/Lumiwealth/lumibot. You pay only your exchange's trading fees and, for AI agents, your model provider.
