What is HashKey Global?
-----------------------

HashKey Global is a crypto exchange. Its API covers spot trading and perpetual futures such as BTCUSDT-PERPETUAL.

Sign up for HashKey Global
--------------------------

#. Create a HashKey Global account on the website.
#. Finish identity verification (KYC) with a passport or government ID that does not expire within three months.
#. Turn on two-factor authentication (2FA). For practice, you can also ask HashKey for a sandbox account by emailing global-api@hashkey.com.

`Open a HashKey Global account <https://global.hashkey.com/>`_

Create a HashKey Global API key
-------------------------------

#. Log in on the HashKey Global website.
#. Open Settings (top right), then API Management.
#. Click Create API.
#. Enter a name for the key, pick the permission and set an IP access restriction for your bot's machine.
#. Copy the Access Key and Secret Key and store them safely.

**Which permissions to turn on:** Choose READ/WRITE so the bot can place and cancel orders. READ-ONLY is only for looking up orders and trades. Leave withdrawals off. A bot never needs to move money out of your account.

.. warning::

   Never turn on withdrawals for a HashKey Global trading bot key. Bind the key to your server's IP address when HashKey Global lets you, keep the secret out of your code and out of Git, and delete the key if it ever leaks.

Connect HashKey Global to LumiBot
---------------------------------

The simplest way: put these lines in a ``.env`` file next to your strategy. LumiBot loads the file, sees ``TRADING_BROKER=hashkey`` and connects to HashKey Global for you, so your strategy needs no broker code.

.. code-block:: bash

   TRADING_BROKER=hashkey
   HASHKEY_API_KEY=your_apiKey
   HASHKEY_API_SECRET=your_secret
   HASHKEY_SANDBOX=true   # testnet; remove this line for your live account

LumiBot reads exactly the fields CCXT needs for HashKey Global (``apiKey``, ``secret``). If one is missing, LumiBot stops at start-up and names the variable you still need.

You can also build the broker in code. This is handy when one script talks to more than one exchange, or when you need extra CCXT options. The keys in the config are CCXT's own credential names for HashKey Global:

.. code-block:: python

   import os

   HASHKEY_CONFIG = {
       "exchange_id": "hashkey",
       "apiKey": os.environ.get("HASHKEY_API_KEY"),
       "secret": os.environ.get("HASHKEY_API_SECRET"),
       "sandbox": True,  # testnet first; set False for your live account
   }

   from lumibot.brokers import Ccxt

   broker = Ccxt(HASHKEY_CONFIG)
   # then: MyStrategy(broker=broker, ...)

Either way, LumiBot turns on CCXT's built-in rate limiting for you.

Practice on the HashKey Global testnet
--------------------------------------

HashKey Global runs a public sandbox at https://global.sim.hashkeydev.com with its API at https://api-glb.sim.hashkeydev.com. Get a sandbox account by emailing global-api@hashkey.com, then make sandbox keys there. Set ``HASHKEY_SANDBOX=true`` (or ``"sandbox": True`` in a code config) to use it.

CCXT sends sandbox requests to: https://api-glb.sim.hashkeydev.com. Testnet and live accounts use different keys.

Algorithmic trading example: a simple HashKey Global bot
--------------------------------------------------------

This bot buys about 50 USDT of BTC on HashKey Global once and then holds it. It is a starting point to check that your keys, balances and orders work. If the exchange's minimum order is larger, raise the amount.

.. code-block:: python

   from lumibot.entities import Asset
   from lumibot.strategies import Strategy


   class HashkeyBuyOnce(Strategy):
       """Buy a small amount of BTC once, then hold it."""

       def initialize(self):
           self.sleeptime = "1H"
           self.set_market("24/7")  # crypto trades all day, every day

       def on_trading_iteration(self):
           coin = Asset("BTC", asset_type=Asset.AssetType.CRYPTO)
           if self.get_position(coin) is not None:
               return  # already holding BTC
           price = self.get_last_price(coin, quote=self.quote_asset)
           if price:
               quantity = round(50 / price, 6)  # about 50 USDT worth
               order = self.create_order(coin, quantity, "buy", quote=self.quote_asset)
               self.submit_order(order)


   if __name__ == "__main__":
       # LumiBot reads TRADING_BROKER and the keys from your .env file.
       strategy = HashkeyBuyOnce(quote_asset=Asset("USDT", asset_type=Asset.AssetType.CRYPTO))
       strategy.run_live()

Agentic trading example: an AI agent that trades on HashKey Global
------------------------------------------------------------------

Agentic trading means an AI agent reads the market and decides what to do. In this example one LumiBot agent looks at prices and your HashKey Global account, then places the orders itself. There is no Python logic in between: you set the rules in plain English in the prompt, such as what it may trade and how big each order can be. This follows the same pattern as LumiBot's AI trading team examples.

.. code-block:: python

   from lumibot.entities import Asset
   from lumibot.strategies import Strategy


   class HashkeyAITrader(Strategy):
       """One AI agent researches the market and places the trades itself."""

       def initialize(self):
           self.sleeptime = "4H"
           self.set_market("24/7")
           self.agents.create(
               name="trader",
               model="openai/gpt-6-luna",
               reasoning_effort="high",
               allow_trading=True,
               system_prompt=(
                   "You manage a small crypto account on HashKey Global. "
                   "You may trade BTC and ETH against USDT (asset_type 'crypto', quote_symbol 'USDT'), or hold cash. "
                   "Before every order, call account_portfolio, account_positions and "
                   "market_last_price for that exact symbol in the same run. "
                   "Keep each order under 10% of the account value. "
                   "Explain each decision in one short paragraph."
               ),
           )

       def on_trading_iteration(self):
           self.agents["trader"].run(
               task_prompt="Review recent BTC/USDT and ETH/USDT prices and your current holdings, then decide whether to buy, sell or hold.",
               context={"exchange": "HashKey Global", "quote": "USDT", "date": self.get_datetime().isoformat()},
           )


   if __name__ == "__main__":
       # LumiBot reads TRADING_BROKER and the keys from your .env file.
       strategy = HashkeyAITrader(quote_asset=Asset("USDT", asset_type=Asset.AssetType.CRYPTO))
       strategy.run_live()

The agent needs a model key such as ``OPENAI_API_KEY`` in your environment. See the :doc:`AI agents quickstart <agents_quickstart>` for models, tools and memory.

Perpetual futures example on HashKey Global
-------------------------------------------

HashKey Global also lists perpetual swaps. This bot opens one small long position in ``BTC/USDT:USDT`` worth about 50 USDT and then holds it. LumiBot treats a perpetual as ``asset_type="crypto_future"`` and sizes it in contracts, the same model as LumiBot's Bitunix futures broker. Contract symbols can differ by exchange, so check the symbol in ``self.broker.api.markets`` before going live. In hedge mode, add ``position_side="long"`` to ``create_order``.

.. code-block:: python

   from lumibot.entities import Asset
   from lumibot.strategies import Strategy


   class HashkeyOpenOneLong(Strategy):
       """Open one small long BTC perpetual position, then hold it."""

       def initialize(self):
           self.sleeptime = "1H"
           self.set_market("24/7")  # crypto trades all day, every day

       def on_trading_iteration(self):
           # The full CCXT symbol keeps the settlement currency clear.
           contract = self.broker.get_asset("BTC/USDT:USDT")
           if self.get_position(contract) is not None:
               return  # already holding the position
           price = self.get_last_price(contract)
           if price:
               # Each contract covers contract.multiplier BTC; size the order to about 50 USDT.
               quantity = round(50 / (price * contract.multiplier), 6)
               order = self.create_order(contract, quantity, "buy")
               self.submit_order(order)


   if __name__ == "__main__":
       # LumiBot reads TRADING_BROKER and the keys from your .env file.
       strategy = HashkeyOpenOneLong(quote_asset=Asset("USDT", asset_type=Asset.AssetType.CRYPTO))
       strategy.run_live()

Fees and partner IDs on HashKey Global
--------------------------------------

You pay HashKey Global's normal trading fees. CCXT, the library underneath, normally tags HashKey Global orders with its own partner ID. LumiBot removes that tag. LumiBot may attach its own exchange partner ID instead. That costs you nothing extra. LumiBot never adds an extra builder fee unless one is turned on, and it logs a warning when one is.

HashKey Global tips
-------------------

* HashKey Global needs only two credentials: the Access Key (``HASHKEY_API_KEY``) and the Secret Key (``HASHKEY_API_SECRET``). There is no passphrase.
* In the sandbox, every 2FA, SMS and email code is 123456, which makes test setup quick.
* HashKey's own symbols run together, like ``BTCUSDT`` for spot and ``BTCUSDT-PERPETUAL`` for futures. In LumiBot use the CCXT forms ``BTC/USDT`` and ``BTC/USDT:USDT``.
* A key made on the main trading account works with the main account first. For example, cancel all orders on a main account key does not cancel orders in sub trading accounts.

Frequently asked questions
--------------------------

**Can I build a HashKey Global trading bot in Python?**

Yes. Install LumiBot (``pip install lumibot``), set your HashKey Global keys and use the ``hashkey`` CCXT exchange id as shown above.

**Does HashKey Global have a testnet?**

Yes. Set ``HASHKEY_SANDBOX=true`` and use keys from the HashKey Global testnet.

**Which API permissions does a HashKey Global bot need?**

Choose READ/WRITE so the bot can place and cancel orders. READ-ONLY is only for looking up orders and trades. Leave withdrawals off. A bot never needs to move money out of your account.

**Can an AI agent trade on HashKey Global by itself?**

Yes. The agentic example above gives one agent permission to trade. You control what it may trade and how much through its prompt.

**Can I trade HashKey Global perpetual futures with LumiBot?**

CCXT lists perpetual swaps for this exchange. Use the full contract symbol, such as ``BTC/USDT:USDT``.

**Is LumiBot free?**

Yes. LumiBot is open source on GitHub at https://github.com/Lumiwealth/lumibot. You pay only your exchange's trading fees and, for AI agents, your model provider.
