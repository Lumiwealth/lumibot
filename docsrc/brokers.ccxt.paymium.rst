What is Paymium?
----------------

Paymium is a crypto exchange with a wallet, trading in euros (for example BTC/EUR) and a payment gateway. It offers REST and WebSocket APIs for market data and automated trading.

Sign up for Paymium
-------------------

#. Sign up with your email address and click the link Paymium emails you, then enter your details and the SMS code to confirm your phone.
#. Fill in the compliance form and finish identity verification (photo of your ID, a short face video and an e-signature), then upload a proof of address under Profile, Documents.
#. Wait for Paymium to review your documents (it says 24 to 48 working hours). Paymium has no testnet, so plan to test with a very small amount.

`Open a Paymium account <https://www.paymium.com/>`_

Create a Paymium API key
------------------------

#. Log in to your Paymium account. Paymium says only fully verified and approved accounts can use the authenticated API.
#. Open the developer tokens page at https://account.paymium.com/developers/tokens. This is where the Create an API key button on Paymium's API page goes.
#. Create a new API token.
#. Copy the token (your API key, shown in the list of active tokens) and its secret, and store them safely.

**Which permissions to turn on:** Paymium's API docs list these access scopes: basic (account and balances), activity (orders, deposits and withdrawals history), trade (create and cancel orders) and withdraw. A trading bot needs basic, activity and trade. Leave withdraw off. A bot never needs to move money out of your account.

.. warning::

   Never turn on withdrawals for a Paymium trading bot key. Bind the key to your server's IP address when Paymium lets you, keep the secret out of your code and out of Git, and delete the key if it ever leaks.

Connect Paymium to LumiBot
--------------------------

The simplest way: put these lines in a ``.env`` file next to your strategy. LumiBot loads the file, sees ``TRADING_BROKER=paymium`` and connects to Paymium for you, so your strategy needs no broker code.

.. code-block:: bash

   TRADING_BROKER=paymium
   PAYMIUM_API_KEY=your_apiKey
   PAYMIUM_API_SECRET=your_secret

LumiBot reads exactly the fields CCXT needs for Paymium (``apiKey``, ``secret``). If one is missing, LumiBot stops at start-up and names the variable you still need.

You can also build the broker in code. This is handy when one script talks to more than one exchange, or when you need extra CCXT options. The keys in the config are CCXT's own credential names for Paymium:

.. code-block:: python

   import os

   PAYMIUM_CONFIG = {
       "exchange_id": "paymium",
       "apiKey": os.environ.get("PAYMIUM_API_KEY"),
       "secret": os.environ.get("PAYMIUM_API_SECRET"),
       "sandbox": False,  # no sandbox for this exchange
   }

   from lumibot.brokers import Ccxt

   broker = Ccxt(PAYMIUM_CONFIG)
   # then: MyStrategy(broker=broker, ...)

Either way, LumiBot turns on CCXT's built-in rate limiting for you.

Testing on Paymium
------------------

Paymium has no sandbox, and CCXT lists no test URL for it, so test with a very small amount. With environment variables, leave ``PAYMIUM_SANDBOX`` unset. In a code config, set ``"sandbox": False``.

Algorithmic trading example: a simple Paymium bot
-------------------------------------------------

This bot buys about 45 EUR of BTC on Paymium once and then holds it. It is a starting point to check that your keys, balances and orders work. If the exchange's minimum order is larger, raise the amount.

.. code-block:: python

   from lumibot.entities import Asset
   from lumibot.strategies import Strategy


   class PaymiumBuyOnce(Strategy):
       """Buy a small amount of BTC once, then hold it."""

       def initialize(self):
           self.sleeptime = "1H"
           self.set_market("24/7")  # crypto trades all day, every day

       def on_trading_iteration(self):
           coin = Asset("BTC", asset_type=Asset.AssetType.CRYPTO)
           if self.get_position(coin) is not None:
               return  # already holding BTC
           price = self.get_last_price(coin, quote=self.quote_asset)
           if price:
               quantity = round(45 / price, 6)  # about 45 EUR worth
               order = self.create_order(coin, quantity, "buy", quote=self.quote_asset)
               self.submit_order(order)


   if __name__ == "__main__":
       # LumiBot reads TRADING_BROKER and the keys from your .env file.
       strategy = PaymiumBuyOnce(quote_asset=Asset("EUR", asset_type=Asset.AssetType.CRYPTO))
       strategy.run_live()

Agentic trading example: an AI agent that trades on Paymium
-----------------------------------------------------------

Agentic trading means an AI agent reads the market and decides what to do. In this example one LumiBot agent looks at prices and your Paymium account, then places the orders itself. There is no Python logic in between: you set the rules in plain English in the prompt, such as what it may trade and how big each order can be. This follows the same pattern as LumiBot's AI trading team examples.

.. code-block:: python

   from lumibot.entities import Asset
   from lumibot.strategies import Strategy


   class PaymiumAITrader(Strategy):
       """One AI agent researches the market and places the trades itself."""

       def initialize(self):
           self.sleeptime = "4H"
           self.set_market("24/7")
           self.agents.create(
               name="trader",
               model="openai/gpt-6-luna",
               reasoning_effort="high",
               allow_trading=True,
               system_prompt=(
                   "You manage a small crypto account on Paymium. "
                   "You may trade BTC and ETH against EUR (asset_type 'crypto', quote_symbol 'EUR'), or hold cash. "
                   "Before every order, call account_portfolio, account_positions and "
                   "market_last_price for that exact symbol in the same run. "
                   "Keep each order under 10% of the account value. "
                   "Explain each decision in one short paragraph."
               ),
           )

       def on_trading_iteration(self):
           self.agents["trader"].run(
               task_prompt="Review recent BTC/EUR and ETH/EUR prices and your current holdings, then decide whether to buy, sell or hold.",
               context={"exchange": "Paymium", "quote": "EUR", "date": self.get_datetime().isoformat()},
           )


   if __name__ == "__main__":
       # LumiBot reads TRADING_BROKER and the keys from your .env file.
       strategy = PaymiumAITrader(quote_asset=Asset("EUR", asset_type=Asset.AssetType.CRYPTO))
       strategy.run_live()

The agent needs a model key such as ``OPENAI_API_KEY`` in your environment. See the :doc:`AI agents quickstart <agents_quickstart>` for models, tools and memory.

Fees and partner IDs on Paymium
-------------------------------

You pay Paymium's normal trading fees. LumiBot may attach its own exchange partner ID. That costs you nothing extra. LumiBot never adds an extra builder fee unless one is turned on, and it logs a warning when one is.

Paymium tips
------------

* Paymium trades in euros. The main market in CCXT is ``BTC/EUR``, so use ``EUR`` as your quote asset.
* Paymium's API docs say every signed request needs a nonce that is larger than the one before. Giving each bot its own token keeps two programs from sending nonces out of order.
* CCXT waits about 2 seconds between Paymium requests to respect its rate limits, so expect slower updates than on larger exchanges.

Frequently asked questions
--------------------------

**Can I build a Paymium trading bot in Python?**

Yes. Install LumiBot (``pip install lumibot``), set your Paymium keys and use the ``paymium`` CCXT exchange id as shown above.

**Does Paymium have a testnet?**

No testnet is set up for Paymium in LumiBot. Start with a small amount, and in a code config set ``"sandbox": False``.

**Which API permissions does a Paymium bot need?**

Paymium's API docs list these access scopes: basic (account and balances), activity (orders, deposits and withdrawals history), trade (create and cancel orders) and withdraw. A trading bot needs basic, activity and trade. Leave withdraw off. A bot never needs to move money out of your account.

**Can an AI agent trade on Paymium by itself?**

Yes. The agentic example above gives one agent permission to trade. You control what it may trade and how much through its prompt.

**Can I trade Paymium perpetual futures with LumiBot?**

CCXT does not list perpetual swaps for Paymium, so use spot markets.

**Is LumiBot free?**

Yes. LumiBot is open source on GitHub at https://github.com/Lumiwealth/lumibot. You pay only your exchange's trading fees and, for AI agents, your model provider.
