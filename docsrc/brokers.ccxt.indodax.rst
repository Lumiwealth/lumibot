What is INDODAX?
----------------

INDODAX is a crypto exchange with spot markets priced in Indonesian rupiah (IDR) and some in USDT. Its Trade API lets you read your account, place and cancel spot orders, and (only if you allow it) withdraw.

Sign up for INDODAX
-------------------

#. Create an INDODAX account on the website and finish the identity verification INDODAX asks for.
#. Set up your SMS PIN or Auth PIN (authenticator). INDODAX asks for one of them when you activate a Trade API key.
#. INDODAX has no testnet, so plan to test with a very small amount.

`Open a INDODAX account <https://indodax.com/>`_

Create a INDODAX API key
------------------------

#. Log in on the INDODAX website (the Trade API is not in the mobile app), open the Menu and choose Trade API, or go to https://indodax.com/trade_api.
#. Pick the API version. CCXT, and so LumiBot, uses the original Trade API at indodax.com/tapi, so choose Trade API V1.
#. Fill in a label and choose the permissions (see below).
#. Read the Terms and Conditions, tick I agree, and enter your SMS PIN or Auth PIN.
#. Click Activate Trade API, then click the confirmation link INDODAX sends to your email.
#. Save the API Key and Secret Key that appear. INDODAX shows the Secret Key only once; if you lose it, you must make a new key.

**Which permissions to turn on:** Turn on View (Enable Reading) and Trade (Enable Spot Trading). View lets the bot read balances and orders, and Trade lets it create and cancel orders. Leave Deposit & Withdraw off. A trading bot never needs to move money out of your account.

.. warning::

   Never turn on withdrawals for a INDODAX trading bot key. Bind the key to your server's IP address when INDODAX lets you, keep the secret out of your code and out of Git, and delete the key if it ever leaks.

Connect INDODAX to LumiBot
--------------------------

The simplest way: put these lines in a ``.env`` file next to your strategy. LumiBot loads the file, sees ``TRADING_BROKER=indodax`` and connects to INDODAX for you, so your strategy needs no broker code.

.. code-block:: bash

   TRADING_BROKER=indodax
   INDODAX_API_KEY=your_apiKey
   INDODAX_API_SECRET=your_secret

LumiBot reads exactly the fields CCXT needs for INDODAX (``apiKey``, ``secret``). If one is missing, LumiBot stops at start-up and names the variable you still need.

You can also build the broker in code. This is handy when one script talks to more than one exchange, or when you need extra CCXT options. The keys in the config are CCXT's own credential names for INDODAX:

.. code-block:: python

   import os

   INDODAX_CONFIG = {
       "exchange_id": "indodax",
       "apiKey": os.environ.get("INDODAX_API_KEY"),
       "secret": os.environ.get("INDODAX_API_SECRET"),
       "sandbox": False,  # no sandbox for this exchange
   }

   from lumibot.brokers import Ccxt

   broker = Ccxt(INDODAX_CONFIG)
   # then: MyStrategy(broker=broker, ...)

Either way, LumiBot turns on CCXT's built-in rate limiting for you.

Testing on INDODAX
------------------

INDODAX has no sandbox, and CCXT lists no test URL for it, so test with a very small amount. With environment variables, leave ``INDODAX_SANDBOX`` unset. In a code config, set ``"sandbox": False``.

Algorithmic trading example: a simple INDODAX bot
-------------------------------------------------

This bot buys about 800000 IDR of BTC on INDODAX once and then holds it. It is a starting point to check that your keys, balances and orders work. If the exchange's minimum order is larger, raise the amount.

.. code-block:: python

   from lumibot.entities import Asset
   from lumibot.strategies import Strategy


   class IndodaxBuyOnce(Strategy):
       """Buy a small amount of BTC once, then hold it."""

       def initialize(self):
           self.sleeptime = "1H"
           self.set_market("24/7")  # crypto trades all day, every day

       def on_trading_iteration(self):
           coin = Asset("BTC", asset_type=Asset.AssetType.CRYPTO)
           if self.get_position(coin) is not None:
               return  # already holding BTC
           price = self.get_last_price(coin, quote=self.quote_asset)
           if price:
               quantity = round(800000 / price, 6)  # about 800000 IDR worth
               order = self.create_order(coin, quantity, "buy", quote=self.quote_asset)
               self.submit_order(order)


   if __name__ == "__main__":
       # LumiBot reads TRADING_BROKER and the keys from your .env file.
       strategy = IndodaxBuyOnce(quote_asset=Asset("IDR", asset_type=Asset.AssetType.CRYPTO))
       strategy.run_live()

Agentic trading example: an AI agent that trades on INDODAX
-----------------------------------------------------------

Agentic trading means an AI agent reads the market and decides what to do. In this example one LumiBot agent looks at prices and your INDODAX account, then places the orders itself. There is no Python logic in between: you set the rules in plain English in the prompt, such as what it may trade and how big each order can be. This follows the same pattern as LumiBot's AI trading team examples.

.. code-block:: python

   from lumibot.entities import Asset
   from lumibot.strategies import Strategy


   class IndodaxAITrader(Strategy):
       """One AI agent researches the market and places the trades itself."""

       def initialize(self):
           self.sleeptime = "4H"
           self.set_market("24/7")
           self.agents.create(
               name="trader",
               model="openai/gpt-6-luna",
               reasoning_effort="high",
               allow_trading=True,
               system_prompt=(
                   "You manage a small crypto account on INDODAX. "
                   "You may trade BTC and ETH against IDR (asset_type 'crypto', quote_symbol 'IDR'), or hold cash. "
                   "Before every order, call account_portfolio, account_positions and "
                   "market_last_price for that exact symbol in the same run. "
                   "Keep each order under 10% of the account value. "
                   "Explain each decision in one short paragraph."
               ),
           )

       def on_trading_iteration(self):
           self.agents["trader"].run(
               task_prompt="Review recent BTC/IDR and ETH/IDR prices and your current holdings, then decide whether to buy, sell or hold.",
               context={"exchange": "INDODAX", "quote": "IDR", "date": self.get_datetime().isoformat()},
           )


   if __name__ == "__main__":
       # LumiBot reads TRADING_BROKER and the keys from your .env file.
       strategy = IndodaxAITrader(quote_asset=Asset("IDR", asset_type=Asset.AssetType.CRYPTO))
       strategy.run_live()

The agent needs a model key such as ``OPENAI_API_KEY`` in your environment. See the :doc:`AI agents quickstart <agents_quickstart>` for models, tools and memory.

INDODAX tips
------------

* Most INDODAX markets are priced in rupiah, so use ``IDR`` as your quote asset (for example ``BTC/IDR``). INDODAX also lists some USDT pairs such as ``BTC/USDT``.
* IP Permission is only required when a key has withdrawal access. A read and trade key can be made without an IP list. If you do add withdrawal access, the IP list then applies to every request made with that key.
* The INDODAX trade endpoint allows about 20 requests per second per account and pair. Going over blocks trading on that pair for 5 seconds, so keep your bot's order rate modest.
* INDODAX's official API docs are on GitHub at https://github.com/btcid/indodax-official-api-docs.

Frequently asked questions
--------------------------

**Can I build a INDODAX trading bot in Python?**

Yes. Install LumiBot (``pip install lumibot``), set your INDODAX keys and use the ``indodax`` CCXT exchange id as shown above.

**Does INDODAX have a testnet?**

No testnet is set up for INDODAX in LumiBot. Start with a small amount, and in a code config set ``"sandbox": False``.

**Which API permissions does a INDODAX bot need?**

Turn on View (Enable Reading) and Trade (Enable Spot Trading). View lets the bot read balances and orders, and Trade lets it create and cancel orders. Leave Deposit & Withdraw off. A trading bot never needs to move money out of your account.

**Can an AI agent trade on INDODAX by itself?**

Yes. The agentic example above gives one agent permission to trade. You control what it may trade and how much through its prompt.

**Can I trade INDODAX perpetual futures with LumiBot?**

CCXT does not list perpetual swaps for INDODAX, so use spot markets.

**Is LumiBot free?**

Yes. LumiBot is open source on GitHub at https://github.com/Lumiwealth/lumibot. You pay only your exchange's trading fees and, for AI agents, your model provider.
