What is BingX?
--------------

BingX is a crypto exchange that offers spot trading, perpetual futures (USDT, USDC and coin margined), copy trading and trading bots. BingX's API covers spot and perpetual futures.

Sign up for BingX
-----------------

#. Sign up on bingx.com or in the BingX app with an email address or phone number.
#. Finish identity verification: open your profile icon, then Identity Verification, and upload photos of an ID document plus a selfie holding it. BingX says advanced verification takes 2 to 10 minutes.
#. Set up two-factor authentication (Google Authenticator or SMS). You need it to create an API key.

`Open a BingX account <https://bingx.com>`_

Create a BingX API key
----------------------

#. Log in on the website, open your profile icon and go to API Management (https://bingx.com/en/accounts/api).
#. Click Create API and give the key a clear name, for example the name of your bot.
#. Choose the permissions (see below).
#. Add your bot's IP address. One key can hold up to 20 IP addresses, separated by commas.
#. Finish the 2FA check, then copy the API Key and Secret Key. BingX shows the secret only once.

**Which permissions to turn on:** Turn on Read plus Spot Trading, or Perpetual Futures Trading if your bot trades perpetuals. Leave Withdraw off. A bot never needs to move money out of your account.

.. warning::

   Never turn on withdrawals for a BingX trading bot key. Bind the key to your server's IP address when BingX lets you, keep the secret out of your code and out of Git, and delete the key if it ever leaks.

Connect BingX to LumiBot
------------------------

The simplest way: put these lines in a ``.env`` file next to your strategy. LumiBot loads the file, sees ``TRADING_BROKER=bingx`` and connects to BingX for you, so your strategy needs no broker code.

.. code-block:: bash

   TRADING_BROKER=bingx
   BINGX_API_KEY=your_apiKey
   BINGX_API_SECRET=your_secret
   BINGX_SANDBOX=true   # testnet; remove this line for your live account

LumiBot reads exactly the fields CCXT needs for BingX (``apiKey``, ``secret``). If one is missing, LumiBot stops at start-up and names the variable you still need.

You can also build the broker in code. This is handy when one script talks to more than one exchange, or when you need extra CCXT options. The keys in the config are CCXT's own credential names for BingX:

.. code-block:: python

   import os

   BINGX_CONFIG = {
       "exchange_id": "bingx",
       "apiKey": os.environ.get("BINGX_API_KEY"),
       "secret": os.environ.get("BINGX_API_SECRET"),
       "sandbox": True,  # testnet first; set False for your live account
   }

   from lumibot.brokers import Ccxt

   broker = Ccxt(BINGX_CONFIG)
   # then: MyStrategy(broker=broker, ...)

Either way, LumiBot turns on CCXT's built-in rate limiting for you.

Practice on the BingX testnet
-----------------------------

BingX has no separate testnet site. CCXT's sandbox uses BingX's demo trading API at https://open-api-vst.bingx.com, which trades with VST (virtual USDT) in the demo trading account and works for perpetual futures. Set ``BINGX_SANDBOX=true`` (or ``"sandbox": True`` in a code config) to use it. Demo trading does not cover spot, so test spot with a very small real amount.

CCXT sends sandbox requests to: https://open-api-vst.bingx.com/openApi. Testnet and live accounts use different keys.

Algorithmic trading example: a simple BingX bot
-----------------------------------------------

This bot buys about 50 USDT of BTC on BingX once and then holds it. It is a starting point to check that your keys, balances and orders work. If the exchange's minimum order is larger, raise the amount.

.. code-block:: python

   from lumibot.entities import Asset
   from lumibot.strategies import Strategy


   class BingxBuyOnce(Strategy):
       """Buy a small amount of BTC once, then hold it."""

       def initialize(self):
           self.sleeptime = "1H"
           self.set_market("24/7")  # crypto trades all day, every day

       def on_trading_iteration(self):
           coin = Asset("BTC", asset_type=Asset.AssetType.CRYPTO)
           if self.get_position(coin) is not None:
               return  # already holding BTC
           price = self.get_last_price(coin, quote=self.quote_asset)
           if price:
               quantity = round(50 / price, 6)  # about 50 USDT worth
               order = self.create_order(coin, quantity, "buy", quote=self.quote_asset)
               self.submit_order(order)


   if __name__ == "__main__":
       # LumiBot reads TRADING_BROKER and the keys from your .env file.
       strategy = BingxBuyOnce(quote_asset=Asset("USDT", asset_type=Asset.AssetType.CRYPTO))
       strategy.run_live()

Agentic trading example: an AI agent that trades on BingX
---------------------------------------------------------

Agentic trading means an AI agent reads the market and decides what to do. In this example one LumiBot agent looks at prices and your BingX account, then places the orders itself. There is no Python logic in between: you set the rules in plain English in the prompt, such as what it may trade and how big each order can be. This follows the same pattern as LumiBot's AI trading team examples.

.. code-block:: python

   from lumibot.entities import Asset
   from lumibot.strategies import Strategy


   class BingxAITrader(Strategy):
       """One AI agent researches the market and places the trades itself."""

       def initialize(self):
           self.sleeptime = "4H"
           self.set_market("24/7")
           self.agents.create(
               name="trader",
               model="openai/gpt-6-luna",
               reasoning_effort="high",
               allow_trading=True,
               system_prompt=(
                   "You manage a small crypto account on BingX. "
                   "You may trade BTC and ETH against USDT (asset_type 'crypto', quote_symbol 'USDT'), or hold cash. "
                   "Before every order, call account_portfolio, account_positions and "
                   "market_last_price for that exact symbol in the same run. "
                   "Keep each order under 10% of the account value. "
                   "Explain each decision in one short paragraph."
               ),
           )

       def on_trading_iteration(self):
           self.agents["trader"].run(
               task_prompt="Review recent BTC/USDT and ETH/USDT prices and your current holdings, then decide whether to buy, sell or hold.",
               context={"exchange": "BingX", "quote": "USDT", "date": self.get_datetime().isoformat()},
           )


   if __name__ == "__main__":
       # LumiBot reads TRADING_BROKER and the keys from your .env file.
       strategy = BingxAITrader(quote_asset=Asset("USDT", asset_type=Asset.AssetType.CRYPTO))
       strategy.run_live()

The agent needs a model key such as ``OPENAI_API_KEY`` in your environment. See the :doc:`AI agents quickstart <agents_quickstart>` for models, tools and memory.

Perpetual futures example on BingX
----------------------------------

BingX also lists perpetual swaps. This bot opens one small long position in ``BTC/USDT:USDT`` worth about 50 USDT and then holds it. LumiBot treats a perpetual as ``asset_type="crypto_future"`` and sizes it in contracts, the same model as LumiBot's Bitunix futures broker. Contract symbols can differ by exchange, so check the symbol in ``self.broker.api.markets`` before going live. In hedge mode, add ``position_side="long"`` to ``create_order``.

.. code-block:: python

   from lumibot.entities import Asset
   from lumibot.strategies import Strategy


   class BingxOpenOneLong(Strategy):
       """Open one small long BTC perpetual position, then hold it."""

       def initialize(self):
           self.sleeptime = "1H"
           self.set_market("24/7")  # crypto trades all day, every day

       def on_trading_iteration(self):
           # The full CCXT symbol keeps the settlement currency clear.
           contract = self.broker.get_asset("BTC/USDT:USDT")
           if self.get_position(contract) is not None:
               return  # already holding the position
           price = self.get_last_price(contract)
           if price:
               # Each contract covers contract.multiplier BTC; size the order to about 50 USDT.
               quantity = round(50 / (price * contract.multiplier), 6)
               order = self.create_order(contract, quantity, "buy")
               self.submit_order(order)


   if __name__ == "__main__":
       # LumiBot reads TRADING_BROKER and the keys from your .env file.
       strategy = BingxOpenOneLong(quote_asset=Asset("USDT", asset_type=Asset.AssetType.CRYPTO))
       strategy.run_live()

Fees and partner IDs on BingX
-----------------------------

You pay BingX's normal trading fees. CCXT, the library underneath, normally tags BingX orders with its own partner ID. LumiBot removes that tag. LumiBot may attach its own exchange partner ID instead. That costs you nothing extra. LumiBot never adds an extra builder fee unless one is turned on, and it logs a warning when one is.

BingX tips
----------

* Bind your key to an IP address. BingX deletes keys that have trading, transfer or sub-account permissions, no IP address and no API calls for 14 days in a row. Keys with an IP address, or read-only keys, do not expire.
* Each main account and each sub-account can keep up to 20 active API keys. A separate sub-account per bot keeps bot trades apart from manual trades.
* BingX's API only covers Spot and Perpetual Futures. Standard Futures and copy trading are not reachable through it.
* BingX writes symbols like ``BTC-USDT``. In LumiBot and CCXT use ``BTC/USDT`` for spot and ``BTC/USDT:USDT`` for the USDT perpetual.

Frequently asked questions
--------------------------

**Can I build a BingX trading bot in Python?**

Yes. Install LumiBot (``pip install lumibot``), set your BingX keys and use the ``bingx`` CCXT exchange id as shown above.

**Does BingX have a testnet?**

Yes. Set ``BINGX_SANDBOX=true`` and use keys from the BingX testnet.

**Which API permissions does a BingX bot need?**

Turn on Read plus Spot Trading, or Perpetual Futures Trading if your bot trades perpetuals. Leave Withdraw off. A bot never needs to move money out of your account.

**Can an AI agent trade on BingX by itself?**

Yes. The agentic example above gives one agent permission to trade. You control what it may trade and how much through its prompt.

**Can I trade BingX perpetual futures with LumiBot?**

CCXT lists perpetual swaps for this exchange. Use the full contract symbol, such as ``BTC/USDT:USDT``.

**Is LumiBot free?**

Yes. LumiBot is open source on GitHub at https://github.com/Lumiwealth/lumibot. You pay only your exchange's trading fees and, for AI agents, your model provider.
