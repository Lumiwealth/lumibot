# LumiBot AI Trading

[English](README.md) · [中文](README.zh-CN.md) · [Español](README.es.md) · [Français](README.fr.md) · [Deutsch](README.de.md) · [日本語](README.ja.md) · [한국어](README.ko.md) · [Português](README.pt.md) · **Русский**

**Создавайте торговых ИИ-агентов, проверяйте их на истории и торгуйте той же стратегией.**

LumiBot: бесплатный Python-фреймворк с открытым исходным кодом для торговых ботов. Пишите правила на Python, поручайте решения ИИ-агентам или сочетайте оба подхода. Проверяйте стратегию на исторических данных, изучайте решения и сделки, затем подключайте брокера для симуляции или реальной торговли.

Это краткое изложение английского README и главной страницы документации. Полный код находится в [английском README](README.md) и [документации](https://lumibot.lumiwealth.com/).

## Почему LumiBot

- **Встроенные торговые ИИ-агенты:** исследуют данные, рассуждают и выставляют заявки по вашим инструкциям.
- **Сначала бэктест, затем торговля:** проверяйте решения ИИ и правила Python на истории с графиками, сделками и журналами.
- **Одна стратегия для бэктеста и торговли:** сохраняйте класс стратегии, меняя источник данных и конфигурацию запуска с брокером.
- **Разные классы активов:** акции, опционы, фьючерсы, валюты, криптовалюты и рынки прогнозов в зависимости от [поддерживаемого брокера](https://lumibot.lumiwealth.com/brokers.all.html).
- **Решение доходит до брокера.** Просматривайте заявки, исполнения и записи решений. [Как устроено исполнение](https://lumibot.lumiwealth.com/execution_gap.html).

## Начало работы

Нужен Python 3.10 или новее. Запустите пример бэктеста на бесплатных дневных данных:

```bash
pip install lumibot
lumibot demo
```

Для ИИ-примеров нужны учётные данные модели; вызовы могут быть платными. Для симуляции или реальной торговли нужны счёт и учётные данные брокера. См. [ИИ-пример](README.md#run-your-first-ai-backtest), [настройку CLI](https://lumibot.lumiwealth.com/cli.html) и [режимы запуска](https://lumibot.lumiwealth.com/strategy_run_modes.html). Бэктест не гарантирует будущие результаты.
