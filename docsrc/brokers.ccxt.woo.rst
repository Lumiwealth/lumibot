What is WOO X?
--------------

WOO X is a crypto exchange with spot and futures markets. It also offers social (copy) trading and earn products.

Sign up for WOO X
-----------------

#. Click the sign-up button on woox.io, enter your email and a password, then enter the code WOO X emails you within 10 minutes.
#. Complete identity verification (KYC) from the Account page with Level up.
#. Bind two-factor authentication (2FA). WOO X needs it before you can create an API key.

`Open a WOO X account <https://woox.io/>`_

Create a WOO X API key
----------------------

#. Log in to WOO X and open the Subaccount and API tab on the account page.
#. Click Create API.
#. Enter a description for the key, for example the name of your bot.
#. Choose the permissions (see below) and add your bot's IP address as a trusted IP.
#. Enter your 2FA code to confirm, then save the API key and secret. The secret is never shown again; if you lose it, delete the key and make a new one.

**Which permissions to turn on:** Turn on Read and Enable Trading. Leave Enable Withdrawals off. WOO X itself advises against withdrawal permission on keys used for automated trading.

.. warning::

   Never turn on withdrawals for a WOO X trading bot key. Bind the key to your server's IP address when WOO X lets you, keep the secret out of your code and out of Git, and delete the key if it ever leaks.

Connect WOO X to LumiBot
------------------------

The simplest way: put these lines in a ``.env`` file next to your strategy. LumiBot loads the file, sees ``TRADING_BROKER=woo`` and connects to WOO X for you, so your strategy needs no broker code.

.. code-block:: bash

   TRADING_BROKER=woo
   WOO_API_KEY=your_apiKey
   WOO_API_SECRET=your_secret
   WOO_SANDBOX=true   # testnet; remove this line for your live account

LumiBot reads exactly the fields CCXT needs for WOO X (``apiKey``, ``secret``). If one is missing, LumiBot stops at start-up and names the variable you still need.

You can also build the broker in code. This is handy when one script talks to more than one exchange, or when you need extra CCXT options. The keys in the config are CCXT's own credential names for WOO X:

.. code-block:: python

   import os

   WOO_CONFIG = {
       "exchange_id": "woo",
       "apiKey": os.environ.get("WOO_API_KEY"),
       "secret": os.environ.get("WOO_API_SECRET"),
       "sandbox": True,  # testnet first; set False for your live account
   }

   from lumibot.brokers import Ccxt

   broker = Ccxt(WOO_CONFIG)
   # then: MyStrategy(broker=broker, ...)

Either way, LumiBot turns on CCXT's built-in rate limiting for you.

Practice on the WOO X testnet
-----------------------------

WOO X documents a testnet (staging) site at https://staging.woox.io with its REST API at https://api.staging.woox.io. Set ``WOO_SANDBOX=true`` (or ``"sandbox": True`` in a code config) to use it. WOO X presents the testnet as part of its institutional API setup, so you may need to ask WOO X support for access.

CCXT sends sandbox requests to: https://api-pub.staging.woox.io, https://api.staging.woox.io. Testnet and live accounts use different keys.

Algorithmic trading example: a simple WOO X bot
-----------------------------------------------

This bot buys about 50 USDT of BTC on WOO X once and then holds it. It is a starting point to check that your keys, balances and orders work. If the exchange's minimum order is larger, raise the amount. WOO X accepts only limit orders through CCXT, so the example places a limit order just above the last price.

.. code-block:: python

   from lumibot.entities import Asset
   from lumibot.strategies import Strategy


   class WooBuyOnce(Strategy):
       """Buy a small amount of BTC once, then hold it."""

       def initialize(self):
           self.sleeptime = "1H"
           self.set_market("24/7")  # crypto trades all day, every day

       def on_trading_iteration(self):
           coin = Asset("BTC", asset_type=Asset.AssetType.CRYPTO)
           if self.get_position(coin) is not None:
               return  # already holding BTC
           price = self.get_last_price(coin, quote=self.quote_asset)
           if price:
               quantity = round(50 / price, 6)  # about 50 USDT worth
               # This exchange takes only limit orders through CCXT.
               order = self.create_order(coin, quantity, "buy", limit_price=price * 1.002, quote=self.quote_asset)
               self.submit_order(order)


   if __name__ == "__main__":
       # LumiBot reads TRADING_BROKER and the keys from your .env file.
       strategy = WooBuyOnce(quote_asset=Asset("USDT", asset_type=Asset.AssetType.CRYPTO))
       strategy.run_live()

Agentic trading example: an AI agent that trades on WOO X
---------------------------------------------------------

Agentic trading means an AI agent reads the market and decides what to do. In this example one LumiBot agent looks at prices and your WOO X account, then places the orders itself. There is no Python logic in between: you set the rules in plain English in the prompt, such as what it may trade and how big each order can be. This follows the same pattern as LumiBot's AI trading team examples.

.. code-block:: python

   from lumibot.entities import Asset
   from lumibot.strategies import Strategy


   class WooAITrader(Strategy):
       """One AI agent researches the market and places the trades itself."""

       def initialize(self):
           self.sleeptime = "4H"
           self.set_market("24/7")
           self.agents.create(
               name="trader",
               model="openai/gpt-6-luna",
               reasoning_effort="high",
               allow_trading=True,
               system_prompt=(
                   "You manage a small crypto account on WOO X. "
                   "You may trade BTC and ETH against USDT (asset_type 'crypto', quote_symbol 'USDT'), or hold cash. "
                   "Before every order, call account_portfolio, account_positions and "
                   "market_last_price for that exact symbol in the same run. "
                   "Keep each order under 10% of the account value. "
                   "Explain each decision in one short paragraph."
               ),
           )

       def on_trading_iteration(self):
           self.agents["trader"].run(
               task_prompt="Review recent BTC/USDT and ETH/USDT prices and your current holdings, then decide whether to buy, sell or hold.",
               context={"exchange": "WOO X", "quote": "USDT", "date": self.get_datetime().isoformat()},
           )


   if __name__ == "__main__":
       # LumiBot reads TRADING_BROKER and the keys from your .env file.
       strategy = WooAITrader(quote_asset=Asset("USDT", asset_type=Asset.AssetType.CRYPTO))
       strategy.run_live()

The agent needs a model key such as ``OPENAI_API_KEY`` in your environment. See the :doc:`AI agents quickstart <agents_quickstart>` for models, tools and memory.

Perpetual futures example on WOO X
----------------------------------

WOO X also lists perpetual swaps. This bot opens one small long position in ``BTC/USDT:USDT`` worth about 50 USDT and then holds it. LumiBot treats a perpetual as ``asset_type="crypto_future"`` and sizes it in contracts, the same model as LumiBot's Bitunix futures broker. Contract symbols can differ by exchange, so check the symbol in ``self.broker.api.markets`` before going live. In hedge mode, add ``position_side="long"`` to ``create_order``. WOO X accepts only limit orders through CCXT, so the example places a limit order just above the last price.

.. code-block:: python

   from lumibot.entities import Asset
   from lumibot.strategies import Strategy


   class WooOpenOneLong(Strategy):
       """Open one small long BTC perpetual position, then hold it."""

       def initialize(self):
           self.sleeptime = "1H"
           self.set_market("24/7")  # crypto trades all day, every day

       def on_trading_iteration(self):
           # The full CCXT symbol keeps the settlement currency clear.
           contract = self.broker.get_asset("BTC/USDT:USDT")
           if self.get_position(contract) is not None:
               return  # already holding the position
           price = self.get_last_price(contract)
           if price:
               # Each contract covers contract.multiplier BTC; size the order to about 50 USDT.
               quantity = round(50 / (price * contract.multiplier), 6)
               # This exchange takes only limit orders through CCXT.
               order = self.create_order(contract, quantity, "buy", limit_price=price * 1.002)
               self.submit_order(order)


   if __name__ == "__main__":
       # LumiBot reads TRADING_BROKER and the keys from your .env file.
       strategy = WooOpenOneLong(quote_asset=Asset("USDT", asset_type=Asset.AssetType.CRYPTO))
       strategy.run_live()

Fees and partner IDs on WOO X
-----------------------------

You pay WOO X's normal trading fees. CCXT, the library underneath, tags WOO X orders with its own partner ID and adds it again while signing each request, so LumiBot cannot remove it yet. A partner ID does not change what you pay. LumiBot may attach its own exchange partner ID instead. That costs you nothing extra. LumiBot never adds an extra builder fee unless one is turned on, and it logs a warning when one is.

WOO X tips
----------

* WOO X subaccounts can have their own API keys. A separate subaccount per bot keeps bot trades apart from manual trades.
* WOO X moved its API from ``api.woo.org`` to ``api.woox.io``. If an old setup points at api.woo.org, update it to the new domain.
* Perpetual futures use the full CCXT form, for example ``BTC/USDT:USDT``. Spot is plain ``BTC/USDT``.
* CCXT also has a ``woofipro`` id. That is WOOFi Pro, a separate on-chain exchange, not WOO X. Use ``woo`` for WOO X accounts.

Frequently asked questions
--------------------------

**Can I build a WOO X trading bot in Python?**

Yes. Install LumiBot (``pip install lumibot``), set your WOO X keys and use the ``woo`` CCXT exchange id as shown above.

**Does WOO X have a testnet?**

Yes. Set ``WOO_SANDBOX=true`` and use keys from the WOO X testnet.

**Which API permissions does a WOO X bot need?**

Turn on Read and Enable Trading. Leave Enable Withdrawals off. WOO X itself advises against withdrawal permission on keys used for automated trading.

**Can an AI agent trade on WOO X by itself?**

Yes. The agentic example above gives one agent permission to trade. You control what it may trade and how much through its prompt.

**Can I trade WOO X perpetual futures with LumiBot?**

CCXT lists perpetual swaps for this exchange. Use the full contract symbol, such as ``BTC/USDT:USDT``.

**Is LumiBot free?**

Yes. LumiBot is open source on GitHub at https://github.com/Lumiwealth/lumibot. You pay only your exchange's trading fees and, for AI agents, your model provider.
