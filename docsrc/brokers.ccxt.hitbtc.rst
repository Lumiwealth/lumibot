What is HitBTC?
---------------

HitBTC is a crypto exchange with spot trading, margin trading (isolated and cross) and futures, including perpetual contracts. It offers REST and WebSocket APIs for automated trading.

Sign up for HitBTC
------------------

#. Create a HitBTC account and open the link in the confirmation email.
#. Turn on two-factor authentication: in Settings, open the Security tab, click Add 2FA App, save the backup code and scan the QR code with an authenticator app.
#. For practice, HitBTC's API docs list a separate Demo Environment (Sandbox) at https://api.demo.hitbtc.com.

`Open a HitBTC account <https://hitbtc.com/>`_

Create a HitBTC API key
-----------------------

#. Log in and open the API settings page in your account.
#. Click New API key. The new key starts with no access rights.
#. Copy the secret key right away. HitBTC hides it once you leave or reload the page.
#. Tick the access rights the bot needs (see below).
#. Confirm the change by email and with your 2FA code. HitBTC asks for both when you grant order or withdrawal rights.

**Which permissions to turn on:** Turn on Orderbook, History, Trading balance (to read balances, orders and trades) and Place/cancel orders (to trade). Leave the withdrawal right off, and skip Allow all. HitBTC notes that API actions such as withdrawals need only the API and secret keys, with no extra 2FA check.

.. warning::

   Never turn on withdrawals for a HitBTC trading bot key. Bind the key to your server's IP address when HitBTC lets you, keep the secret out of your code and out of Git, and delete the key if it ever leaks.

Connect HitBTC to LumiBot
-------------------------

The simplest way: put these lines in a ``.env`` file next to your strategy. LumiBot loads the file, sees ``TRADING_BROKER=hitbtc`` and connects to HitBTC for you, so your strategy needs no broker code.

.. code-block:: bash

   TRADING_BROKER=hitbtc
   HITBTC_API_KEY=your_apiKey
   HITBTC_API_SECRET=your_secret
   HITBTC_SANDBOX=true   # testnet; remove this line for your live account

LumiBot reads exactly the fields CCXT needs for HitBTC (``apiKey``, ``secret``). If one is missing, LumiBot stops at start-up and names the variable you still need.

You can also build the broker in code. This is handy when one script talks to more than one exchange, or when you need extra CCXT options. The keys in the config are CCXT's own credential names for HitBTC:

.. code-block:: python

   import os

   HITBTC_CONFIG = {
       "exchange_id": "hitbtc",
       "apiKey": os.environ.get("HITBTC_API_KEY"),
       "secret": os.environ.get("HITBTC_API_SECRET"),
       "sandbox": True,  # testnet first; set False for your live account
   }

   from lumibot.brokers import Ccxt

   broker = Ccxt(HITBTC_CONFIG)
   # then: MyStrategy(broker=broker, ...)

Either way, LumiBot turns on CCXT's built-in rate limiting for you.

Algorithmic trading example: a simple HitBTC bot
------------------------------------------------

This bot buys about 50 USDT of BTC on HitBTC once and then holds it. It is a starting point to check that your keys, balances and orders work. If the exchange's minimum order is larger, raise the amount.

.. code-block:: python

   from lumibot.entities import Asset
   from lumibot.strategies import Strategy


   class HitbtcBuyOnce(Strategy):
       """Buy a small amount of BTC once, then hold it."""

       def initialize(self):
           self.sleeptime = "1H"
           self.set_market("24/7")  # crypto trades all day, every day

       def on_trading_iteration(self):
           coin = Asset("BTC", asset_type=Asset.AssetType.CRYPTO)
           if self.get_position(coin) is not None:
               return  # already holding BTC
           price = self.get_last_price(coin, quote=self.quote_asset)
           if price:
               quantity = round(50 / price, 6)  # about 50 USDT worth
               order = self.create_order(coin, quantity, "buy", quote=self.quote_asset)
               self.submit_order(order)


   if __name__ == "__main__":
       # LumiBot reads TRADING_BROKER and the keys from your .env file.
       strategy = HitbtcBuyOnce(quote_asset=Asset("USDT", asset_type=Asset.AssetType.CRYPTO))
       strategy.run_live()

Agentic trading example: an AI agent that trades on HitBTC
----------------------------------------------------------

Agentic trading means an AI agent reads the market and decides what to do. In this example one LumiBot agent looks at prices and your HitBTC account, then places the orders itself. There is no Python logic in between: you set the rules in plain English in the prompt, such as what it may trade and how big each order can be. This follows the same pattern as LumiBot's AI trading team examples.

.. code-block:: python

   from lumibot.entities import Asset
   from lumibot.strategies import Strategy


   class HitbtcAITrader(Strategy):
       """One AI agent researches the market and places the trades itself."""

       def initialize(self):
           self.sleeptime = "4H"
           self.set_market("24/7")
           self.agents.create(
               name="trader",
               model="openai/gpt-6-luna",
               reasoning_effort="high",
               allow_trading=True,
               system_prompt=(
                   "You manage a small crypto account on HitBTC. "
                   "You may trade BTC and ETH against USDT (asset_type 'crypto', quote_symbol 'USDT'), or hold cash. "
                   "Before every order, call account_portfolio, account_positions and "
                   "market_last_price for that exact symbol in the same run. "
                   "Keep each order under 10% of the account value. "
                   "Explain each decision in one short paragraph."
               ),
           )

       def on_trading_iteration(self):
           self.agents["trader"].run(
               task_prompt="Review recent BTC/USDT and ETH/USDT prices and your current holdings, then decide whether to buy, sell or hold.",
               context={"exchange": "HitBTC", "quote": "USDT", "date": self.get_datetime().isoformat()},
           )


   if __name__ == "__main__":
       # LumiBot reads TRADING_BROKER and the keys from your .env file.
       strategy = HitbtcAITrader(quote_asset=Asset("USDT", asset_type=Asset.AssetType.CRYPTO))
       strategy.run_live()

The agent needs a model key such as ``OPENAI_API_KEY`` in your environment. See the :doc:`AI agents quickstart <agents_quickstart>` for models, tools and memory.

Perpetual futures example on HitBTC
-----------------------------------

HitBTC also lists perpetual swaps. This bot opens one small long position in ``BTC/USDT:USDT`` worth about 50 USDT and then holds it. LumiBot treats a perpetual as ``asset_type="crypto_future"`` and sizes it in contracts, the same model as LumiBot's Bitunix futures broker. Contract symbols can differ by exchange, so check the symbol in ``self.broker.api.markets`` before going live. In hedge mode, add ``position_side="long"`` to ``create_order``.

.. code-block:: python

   from lumibot.entities import Asset
   from lumibot.strategies import Strategy


   class HitbtcOpenOneLong(Strategy):
       """Open one small long BTC perpetual position, then hold it."""

       def initialize(self):
           self.sleeptime = "1H"
           self.set_market("24/7")  # crypto trades all day, every day

       def on_trading_iteration(self):
           # The full CCXT symbol keeps the settlement currency clear.
           contract = self.broker.get_asset("BTC/USDT:USDT")
           if self.get_position(contract) is not None:
               return  # already holding the position
           price = self.get_last_price(contract)
           if price:
               # Each contract covers contract.multiplier BTC; size the order to about 50 USDT.
               quantity = round(50 / (price * contract.multiplier), 6)
               order = self.create_order(contract, quantity, "buy")
               self.submit_order(order)


   if __name__ == "__main__":
       # LumiBot reads TRADING_BROKER and the keys from your .env file.
       strategy = HitbtcOpenOneLong(quote_asset=Asset("USDT", asset_type=Asset.AssetType.CRYPTO))
       strategy.run_live()

Fees and partner IDs on HitBTC
------------------------------

You pay HitBTC's normal trading fees. LumiBot may attach its own exchange partner ID. That costs you nothing extra. LumiBot never adds an extra builder fee unless one is turned on, and it logs a warning when one is.

HitBTC tips
-----------

* You can make several API keys with different access rights. A separate key per bot keeps them apart and makes it easy to remove one.
* HitBTC's own symbols look like ``BTCUSDT`` for spot and ``BTCUSDT_PERP`` for perpetuals. In LumiBot use the CCXT form: ``BTC/USDT`` for spot and ``BTC/USDT:USDT`` for the perpetual.
* HitBTC supports sub-accounts with their own access settings, managed through the Subaccounts section of the API.
* When you set up 2FA, HitBTC shows a backup code. Write it down and store it safely before you continue.

Frequently asked questions
--------------------------

**Can I build a HitBTC trading bot in Python?**

Yes. Install LumiBot (``pip install lumibot``), set your HitBTC keys and use the ``hitbtc`` CCXT exchange id as shown above.

**Does HitBTC have a testnet?**

Yes. Set ``HITBTC_SANDBOX=true`` and use keys from the HitBTC testnet.

**Which API permissions does a HitBTC bot need?**

Turn on Orderbook, History, Trading balance (to read balances, orders and trades) and Place/cancel orders (to trade). Leave the withdrawal right off, and skip Allow all. HitBTC notes that API actions such as withdrawals need only the API and secret keys, with no extra 2FA check.

**Can an AI agent trade on HitBTC by itself?**

Yes. The agentic example above gives one agent permission to trade. You control what it may trade and how much through its prompt.

**Can I trade HitBTC perpetual futures with LumiBot?**

CCXT lists perpetual swaps for this exchange. Use the full contract symbol, such as ``BTC/USDT:USDT``.

**Is LumiBot free?**

Yes. LumiBot is open source on GitHub at https://github.com/Lumiwealth/lumibot. You pay only your exchange's trading fees and, for AI agents, your model provider.
