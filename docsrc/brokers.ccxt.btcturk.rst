What is BTCTurk?
----------------

BtcTurk | Kripto is a crypto exchange with spot markets priced mostly in Turkish lira (TRY), plus USDT pairs. Its API covers market data, trading and account management.

Sign up for BTCTurk
-------------------

#. Sign up in the BtcTurk | Kripto app with your email, mobile number and a password, then enter the codes sent to your email and phone.
#. Finish identity verification: scan your ID card, do the face check, fill in your profile and complete the short video call.
#. Set up two-step verification, for example an authenticator app, to protect your account.

`Open a BTCTurk account <https://kripto.btcturk.com/>`_

Create a BTCTurk API key
------------------------

#. Log in on the BtcTurk | Kripto website. API keys can only be made on the website, not in the app.
#. Go to Account, then API Access (https://kripto.btcturk.com/en/account/api-access).
#. Click Create API Key (API Key Oluştur).
#. Choose the permissions (see below) and, if you like, limit the key to your bot's IP address.
#. Save the public key and private key in a safe place. If a key is ever shared by mistake, delete it at once and make a new one.

**Which permissions to turn on:** Turn on Total Funds (Toplam Varlık) to read balances, Trade (Al-Sat) to place, check and cancel orders, and Account (Hesap) to read your trade history. WebSocket is only needed for live private streams. BtcTurk's API permission list has no withdrawal permission, so leave anything to do with withdrawals off and give the key only what the bot needs.

.. warning::

   Never turn on withdrawals for a BTCTurk trading bot key. Bind the key to your server's IP address when BTCTurk lets you, keep the secret out of your code and out of Git, and delete the key if it ever leaks.

Connect BTCTurk to LumiBot
--------------------------

The simplest way: put these lines in a ``.env`` file next to your strategy. LumiBot loads the file, sees ``TRADING_BROKER=btcturk`` and connects to BTCTurk for you, so your strategy needs no broker code.

.. code-block:: bash

   TRADING_BROKER=btcturk
   BTCTURK_API_KEY=your_apiKey
   BTCTURK_API_SECRET=your_secret

LumiBot reads exactly the fields CCXT needs for BTCTurk (``apiKey``, ``secret``). If one is missing, LumiBot stops at start-up and names the variable you still need.

You can also build the broker in code. This is handy when one script talks to more than one exchange, or when you need extra CCXT options. The keys in the config are CCXT's own credential names for BTCTurk:

.. code-block:: python

   import os

   BTCTURK_CONFIG = {
       "exchange_id": "btcturk",
       "apiKey": os.environ.get("BTCTURK_API_KEY"),
       "secret": os.environ.get("BTCTURK_API_SECRET"),
       "sandbox": False,  # live connection
   }

   from lumibot.brokers import Ccxt

   broker = Ccxt(BTCTURK_CONFIG)
   # then: MyStrategy(broker=broker, ...)

Either way, LumiBot turns on CCXT's built-in rate limiting for you.

Testing on BTCTurk
------------------

BtcTurk has no sandbox, and CCXT lists no test URL for it, so test with a very small amount. With environment variables, leave ``BTCTURK_SANDBOX`` unset. In a code config, always set ``"sandbox": False``.

Algorithmic trading example: a simple BTCTurk bot
-------------------------------------------------

This bot buys about 2500 TRY of BTC on BTCTurk once and then holds it. It is a starting point to check that your keys, balances and orders work. If the exchange's minimum order is larger, raise the amount. BTCTurk accepts only limit orders through CCXT, so the example places a limit order just above the last price.

.. code-block:: python

   from lumibot.entities import Asset
   from lumibot.strategies import Strategy


   class BtcturkBuyOnce(Strategy):
       """Buy a small amount of BTC once, then hold it."""

       def initialize(self):
           self.sleeptime = "1H"
           self.set_market("24/7")  # crypto trades all day, every day

       def on_trading_iteration(self):
           coin = Asset("BTC", asset_type=Asset.AssetType.CRYPTO)
           if self.get_position(coin) is not None:
               return  # already holding BTC
           price = self.get_last_price(coin, quote=self.quote_asset)
           if price:
               quantity = round(2500 / price, 6)  # about 2500 TRY worth
               # This exchange takes only limit orders through CCXT.
               order = self.create_order(coin, quantity, "buy", limit_price=price * 1.002, quote=self.quote_asset)
               self.submit_order(order)


   if __name__ == "__main__":
       # LumiBot reads TRADING_BROKER and the keys from your .env file.
       strategy = BtcturkBuyOnce(quote_asset=Asset("TRY", asset_type=Asset.AssetType.CRYPTO))
       strategy.run_live()

Agentic trading example: an AI agent that trades on BTCTurk
-----------------------------------------------------------

Agentic trading means an AI agent reads the market and decides what to do. In this example one LumiBot agent looks at prices and your BTCTurk account, then places the orders itself. There is no Python logic in between: you set the rules in plain English in the prompt, such as what it may trade and how big each order can be. This follows the same pattern as LumiBot's AI trading team examples.

.. code-block:: python

   from lumibot.entities import Asset
   from lumibot.strategies import Strategy


   class BtcturkAITrader(Strategy):
       """One AI agent researches the market and places the trades itself."""

       def initialize(self):
           self.sleeptime = "4H"
           self.set_market("24/7")
           self.agents.create(
               name="trader",
               model="openai/gpt-6-luna",
               reasoning_effort="high",
               allow_trading=True,
               system_prompt=(
                   "You manage a small crypto account on BTCTurk. "
                   "You may trade BTC and ETH against TRY (asset_type 'crypto', quote_symbol 'TRY'), or hold cash. "
                   "Before every order, call account_portfolio, account_positions and "
                   "market_last_price for that exact symbol in the same run. "
                   "Keep each order under 10% of the account value. "
                   "Explain each decision in one short paragraph."
               ),
           )

       def on_trading_iteration(self):
           self.agents["trader"].run(
               task_prompt="Review recent BTC/TRY and ETH/TRY prices and your current holdings, then decide whether to buy, sell or hold.",
               context={"exchange": "BTCTurk", "quote": "TRY", "date": self.get_datetime().isoformat()},
           )


   if __name__ == "__main__":
       # LumiBot reads TRADING_BROKER and the keys from your .env file.
       strategy = BtcturkAITrader(quote_asset=Asset("TRY", asset_type=Asset.AssetType.CRYPTO))
       strategy.run_live()

The agent needs a model key such as ``OPENAI_API_KEY`` in your environment. See the :doc:`AI agents quickstart <agents_quickstart>` for models, tools and memory.

Fees and partner IDs on BTCTurk
-------------------------------

You pay BTCTurk's normal trading fees. LumiBot may attach its own exchange partner ID. That costs you nothing extra. LumiBot never adds an extra builder fee unless one is turned on, and it logs a warning when one is.

BTCTurk tips
------------

* BtcTurk writes pairs without a slash, like ``BTCTRY``. In LumiBot and CCXT use ``BTC/TRY`` (or ``BTC/USDT``).
* BtcTurk checks the request time against its server clock in milliseconds (UTC). Keep your bot machine's clock in sync, or signed requests will fail.
* BtcTurk warns that too many failed sign-in requests can get your IP address blocked. Fix key errors before retrying in a loop.
* You can turn a key off for a while or delete it from the API Access page.

Frequently asked questions
--------------------------

**Can I build a BTCTurk trading bot in Python?**

Yes. Install LumiBot (``pip install lumibot``), set your BTCTurk keys and use the ``btcturk`` CCXT exchange id as shown above.

**Does BTCTurk have a testnet?**

No testnet is set up for BTCTurk in LumiBot. Start with a small amount, and in a code config set ``"sandbox": False``.

**Which API permissions does a BTCTurk bot need?**

Turn on Total Funds (Toplam Varlık) to read balances, Trade (Al-Sat) to place, check and cancel orders, and Account (Hesap) to read your trade history. WebSocket is only needed for live private streams. BtcTurk's API permission list has no withdrawal permission, so leave anything to do with withdrawals off and give the key only what the bot needs.

**Can an AI agent trade on BTCTurk by itself?**

Yes. The agentic example above gives one agent permission to trade. You control what it may trade and how much through its prompt.

**Can I trade BTCTurk perpetual futures with LumiBot?**

CCXT does not list perpetual swaps for BTCTurk, so use spot markets.

**Is LumiBot free?**

Yes. LumiBot is open source on GitHub at https://github.com/Lumiwealth/lumibot. You pay only your exchange's trading fees and, for AI agents, your model provider.
