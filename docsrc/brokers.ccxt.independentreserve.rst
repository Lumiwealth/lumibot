What is Independent Reserve?
----------------------------

Independent Reserve is a crypto exchange that has operated since 2013. You can buy and sell major coins such as Bitcoin and Ethereum with AUD, NZD, SGD or USD.

Sign up for Independent Reserve
-------------------------------

#. Create an account with a username, email and password, and choose a personal account. Enter the code Independent Reserve emails you.
#. Finish identity verification: your details, a phone code, a photo ID, a selfie check and proof of address. Allow about 24 hours for review.
#. Turn on two-factor authentication during sign-up. It is optional, but you should use it.

`Open a Independent Reserve account <https://www.independentreserve.com/>`_

Create a Independent Reserve API key
------------------------------------

#. Log in, click the profile icon in the top right and choose Settings.
#. Open the API keys tab and click Generate API key.
#. Pick the access type (see below).
#. Enter a description and your password, and add your bot's IP address to the whitelist.
#. Click Generate and confirm with the SMS code. Copy the API key and API secret.

**Which permissions to turn on:** Choose the Trade role. Independent Reserve also offers Read Only, Full Access and Restricted Withdrawals, and it asks you to pick the lowest level you need. Do not pick Full Access or Restricted Withdrawals: a bot never needs to move money out.

.. warning::

   Never turn on withdrawals for a Independent Reserve trading bot key. Bind the key to your server's IP address when Independent Reserve lets you, keep the secret out of your code and out of Git, and delete the key if it ever leaks.

Connect Independent Reserve to LumiBot
--------------------------------------

The simplest way: put these lines in a ``.env`` file next to your strategy. LumiBot loads the file, sees ``TRADING_BROKER=independentreserve`` and connects to Independent Reserve for you, so your strategy needs no broker code.

.. code-block:: bash

   TRADING_BROKER=independentreserve
   INDEPENDENTRESERVE_API_KEY=your_apiKey
   INDEPENDENTRESERVE_API_SECRET=your_secret

LumiBot reads exactly the fields CCXT needs for Independent Reserve (``apiKey``, ``secret``). If one is missing, LumiBot stops at start-up and names the variable you still need.

You can also build the broker in code. This is handy when one script talks to more than one exchange, or when you need extra CCXT options. The keys in the config are CCXT's own credential names for Independent Reserve:

.. code-block:: python

   import os

   INDEPENDENTRESERVE_CONFIG = {
       "exchange_id": "independentreserve",
       "apiKey": os.environ.get("INDEPENDENTRESERVE_API_KEY"),
       "secret": os.environ.get("INDEPENDENTRESERVE_API_SECRET"),
       "sandbox": False,  # no sandbox for this exchange
   }

   from lumibot.brokers import Ccxt

   broker = Ccxt(INDEPENDENTRESERVE_CONFIG)
   # then: MyStrategy(broker=broker, ...)

Either way, LumiBot turns on CCXT's built-in rate limiting for you.

Testing on Independent Reserve
------------------------------

Independent Reserve has no sandbox, so test with a very small amount. With environment variables, leave ``INDEPENDENTRESERVE_SANDBOX`` unset. In a code config, set ``"sandbox": False``.

Algorithmic trading example: a simple Independent Reserve bot
-------------------------------------------------------------

This bot buys about 70 AUD of BTC on Independent Reserve once and then holds it. It is a starting point to check that your keys, balances and orders work. If the exchange's minimum order is larger, raise the amount.

.. code-block:: python

   from lumibot.entities import Asset
   from lumibot.strategies import Strategy


   class IndependentreserveBuyOnce(Strategy):
       """Buy a small amount of BTC once, then hold it."""

       def initialize(self):
           self.sleeptime = "1H"
           self.set_market("24/7")  # crypto trades all day, every day

       def on_trading_iteration(self):
           coin = Asset("BTC", asset_type=Asset.AssetType.CRYPTO)
           if self.get_position(coin) is not None:
               return  # already holding BTC
           price = self.get_last_price(coin, quote=self.quote_asset)
           if price:
               quantity = round(70 / price, 6)  # about 70 AUD worth
               order = self.create_order(coin, quantity, "buy", quote=self.quote_asset)
               self.submit_order(order)


   if __name__ == "__main__":
       # LumiBot reads TRADING_BROKER and the keys from your .env file.
       strategy = IndependentreserveBuyOnce(quote_asset=Asset("AUD", asset_type=Asset.AssetType.CRYPTO))
       strategy.run_live()

Agentic trading example: an AI agent that trades on Independent Reserve
-----------------------------------------------------------------------

Agentic trading means an AI agent reads the market and decides what to do. In this example one LumiBot agent looks at prices and your Independent Reserve account, then places the orders itself. There is no Python logic in between: you set the rules in plain English in the prompt, such as what it may trade and how big each order can be. This follows the same pattern as LumiBot's AI trading team examples.

.. code-block:: python

   from lumibot.entities import Asset
   from lumibot.strategies import Strategy


   class IndependentreserveAITrader(Strategy):
       """One AI agent researches the market and places the trades itself."""

       def initialize(self):
           self.sleeptime = "4H"
           self.set_market("24/7")
           self.agents.create(
               name="trader",
               model="openai/gpt-6-luna",
               reasoning_effort="high",
               allow_trading=True,
               system_prompt=(
                   "You manage a small crypto account on Independent Reserve. "
                   "You may trade BTC and ETH against AUD (asset_type 'crypto', quote_symbol 'AUD'), or hold cash. "
                   "Before every order, call account_portfolio, account_positions and "
                   "market_last_price for that exact symbol in the same run. "
                   "Keep each order under 10% of the account value. "
                   "Explain each decision in one short paragraph."
               ),
           )

       def on_trading_iteration(self):
           self.agents["trader"].run(
               task_prompt="Review recent BTC/AUD and ETH/AUD prices and your current holdings, then decide whether to buy, sell or hold.",
               context={"exchange": "Independent Reserve", "quote": "AUD", "date": self.get_datetime().isoformat()},
           )


   if __name__ == "__main__":
       # LumiBot reads TRADING_BROKER and the keys from your .env file.
       strategy = IndependentreserveAITrader(quote_asset=Asset("AUD", asset_type=Asset.AssetType.CRYPTO))
       strategy.run_live()

The agent needs a model key such as ``OPENAI_API_KEY`` in your environment. See the :doc:`AI agents quickstart <agents_quickstart>` for models, tools and memory.

Independent Reserve tips
------------------------

* Whitelist your bot's IP address. Independent Reserve rejects a whitelisted key used from any other IP.
* Keys made without an IP whitelist are turned off automatically if they go unused for 6 months.
* BTC trades against AUD, USD, NZD and SGD, for example ``BTC/AUD`` or ``BTC/USD``.

Frequently asked questions
--------------------------

**Can I build a Independent Reserve trading bot in Python?**

Yes. Install LumiBot (``pip install lumibot``), set your Independent Reserve keys and use the ``independentreserve`` CCXT exchange id as shown above.

**Does Independent Reserve have a testnet?**

No testnet is set up for Independent Reserve in LumiBot. Start with a small amount, and in a code config set ``"sandbox": False``.

**Which API permissions does a Independent Reserve bot need?**

Choose the Trade role. Independent Reserve also offers Read Only, Full Access and Restricted Withdrawals, and it asks you to pick the lowest level you need. Do not pick Full Access or Restricted Withdrawals: a bot never needs to move money out.

**Can an AI agent trade on Independent Reserve by itself?**

Yes. The agentic example above gives one agent permission to trade. You control what it may trade and how much through its prompt.

**Can I trade Independent Reserve perpetual futures with LumiBot?**

CCXT does not list perpetual swaps for Independent Reserve, so use spot markets.

**Is LumiBot free?**

Yes. LumiBot is open source on GitHub at https://github.com/Lumiwealth/lumibot. You pay only your exchange's trading fees and, for AI agents, your model provider.
