What is Bequant?
----------------

Bequant Global is a crypto exchange built for professional traders. It offers spot trading, margin trading and perpetual futures, with access through FIX, WebSocket and REST APIs.

Sign up for Bequant
-------------------

#. Click Register on the Bequant home page, choose a username and password, then add your legal name and phone number and click Finish Registration.
#. Confirm your email address with the link Bequant sends you, then finish account verification.
#. Turn on two-factor authentication under Settings, then the Security tab.

`Open a Bequant account <https://bequant.io/>`_

Create a Bequant API key
------------------------

#. Log in and open the API settings page.
#. Click New API key. Bequant creates a public API key and a secret key with no access rights yet.
#. Copy the secret key right away. Bequant hides it once you leave the page, and a lost secret means you must make a new key.
#. Tick the access rights the bot needs (see below). Bequant asks you to confirm by email and 2FA code when you add order rights.
#. Use the ON/OFF switch to turn a key off when you are not using it, or the trash icon to delete it.

**Which permissions to turn on:** Turn on Order book, History, Trading balance (to read your balance and orders) and Place/cancel orders (to trade). Leave Withdraw cryptocurrencies off, and do not use Allow all. Bequant warns that actions sent through the API need no 2FA code or email check, so the key alone is enough to act.

.. warning::

   Never turn on withdrawals for a Bequant trading bot key. Bind the key to your server's IP address when Bequant lets you, keep the secret out of your code and out of Git, and delete the key if it ever leaks.

Connect Bequant to LumiBot
--------------------------

The simplest way: put these lines in a ``.env`` file next to your strategy. LumiBot loads the file, sees ``TRADING_BROKER=bequant`` and connects to Bequant for you, so your strategy needs no broker code.

.. code-block:: bash

   TRADING_BROKER=bequant
   BEQUANT_API_KEY=your_apiKey
   BEQUANT_API_SECRET=your_secret

LumiBot reads exactly the fields CCXT needs for Bequant (``apiKey``, ``secret``). If one is missing, LumiBot stops at start-up and names the variable you still need.

You can also build the broker in code. This is handy when one script talks to more than one exchange, or when you need extra CCXT options. The keys in the config are CCXT's own credential names for Bequant:

.. code-block:: python

   import os

   BEQUANT_CONFIG = {
       "exchange_id": "bequant",
       "apiKey": os.environ.get("BEQUANT_API_KEY"),
       "secret": os.environ.get("BEQUANT_API_SECRET"),
       "sandbox": False,  # no sandbox for this exchange
   }

   from lumibot.brokers import Ccxt

   broker = Ccxt(BEQUANT_CONFIG)
   # then: MyStrategy(broker=broker, ...)

Either way, LumiBot turns on CCXT's built-in rate limiting for you.

Testing on Bequant
------------------

Bequant's own API docs and help center describe no sandbox or demo site. CCXT's test URL for Bequant points to a HitBTC demo server, not a Bequant site, so do not rely on it. Test with a very small amount, leave ``BEQUANT_SANDBOX`` unset, and in a code config set ``"sandbox": False``.

Algorithmic trading example: a simple Bequant bot
-------------------------------------------------

This bot buys about 50 USDT of BTC on Bequant once and then holds it. It is a starting point to check that your keys, balances and orders work. If the exchange's minimum order is larger, raise the amount.

.. code-block:: python

   from lumibot.entities import Asset
   from lumibot.strategies import Strategy


   class BequantBuyOnce(Strategy):
       """Buy a small amount of BTC once, then hold it."""

       def initialize(self):
           self.sleeptime = "1H"
           self.set_market("24/7")  # crypto trades all day, every day

       def on_trading_iteration(self):
           coin = Asset("BTC", asset_type=Asset.AssetType.CRYPTO)
           if self.get_position(coin) is not None:
               return  # already holding BTC
           price = self.get_last_price(coin, quote=self.quote_asset)
           if price:
               quantity = round(50 / price, 6)  # about 50 USDT worth
               order = self.create_order(coin, quantity, "buy", quote=self.quote_asset)
               self.submit_order(order)


   if __name__ == "__main__":
       # LumiBot reads TRADING_BROKER and the keys from your .env file.
       strategy = BequantBuyOnce(quote_asset=Asset("USDT", asset_type=Asset.AssetType.CRYPTO))
       strategy.run_live()

Agentic trading example: an AI agent that trades on Bequant
-----------------------------------------------------------

Agentic trading means an AI agent reads the market and decides what to do. In this example one LumiBot agent looks at prices and your Bequant account, then places the orders itself. There is no Python logic in between: you set the rules in plain English in the prompt, such as what it may trade and how big each order can be. This follows the same pattern as LumiBot's AI trading team examples.

.. code-block:: python

   from lumibot.entities import Asset
   from lumibot.strategies import Strategy


   class BequantAITrader(Strategy):
       """One AI agent researches the market and places the trades itself."""

       def initialize(self):
           self.sleeptime = "4H"
           self.set_market("24/7")
           self.agents.create(
               name="trader",
               model="openai/gpt-6-luna",
               reasoning_effort="high",
               allow_trading=True,
               system_prompt=(
                   "You manage a small crypto account on Bequant. "
                   "You may trade BTC and ETH against USDT (asset_type 'crypto', quote_symbol 'USDT'), or hold cash. "
                   "Before every order, call account_portfolio, account_positions and "
                   "market_last_price for that exact symbol in the same run. "
                   "Keep each order under 10% of the account value. "
                   "Explain each decision in one short paragraph."
               ),
           )

       def on_trading_iteration(self):
           self.agents["trader"].run(
               task_prompt="Review recent BTC/USDT and ETH/USDT prices and your current holdings, then decide whether to buy, sell or hold.",
               context={"exchange": "Bequant", "quote": "USDT", "date": self.get_datetime().isoformat()},
           )


   if __name__ == "__main__":
       # LumiBot reads TRADING_BROKER and the keys from your .env file.
       strategy = BequantAITrader(quote_asset=Asset("USDT", asset_type=Asset.AssetType.CRYPTO))
       strategy.run_live()

The agent needs a model key such as ``OPENAI_API_KEY`` in your environment. See the :doc:`AI agents quickstart <agents_quickstart>` for models, tools and memory.

Bequant tips
------------

* Bequant keeps a separate wallet balance and spot (trading) balance. Move funds to your spot balance before the bot trades. The Payment information right is only needed if your code moves funds between them.
* A verified account can create sub-accounts from the Sub-Accounts tab, and each sub-account has its own API keys. A separate sub-account per bot keeps bot trades apart from manual trades.
* Bequant lists markets in many quotes, including USDT, USD, EUR and GBP. In LumiBot use the CCXT form, for example ``BTC/USDT``.

Frequently asked questions
--------------------------

**Can I build a Bequant trading bot in Python?**

Yes. Install LumiBot (``pip install lumibot``), set your Bequant keys and use the ``bequant`` CCXT exchange id as shown above.

**Does Bequant have a testnet?**

No testnet is set up for Bequant in LumiBot. Start with a small amount, and in a code config set ``"sandbox": False``.

**Which API permissions does a Bequant bot need?**

Turn on Order book, History, Trading balance (to read your balance and orders) and Place/cancel orders (to trade). Leave Withdraw cryptocurrencies off, and do not use Allow all. Bequant warns that actions sent through the API need no 2FA code or email check, so the key alone is enough to act.

**Can an AI agent trade on Bequant by itself?**

Yes. The agentic example above gives one agent permission to trade. You control what it may trade and how much through its prompt.

**Can I trade Bequant perpetual futures with LumiBot?**

CCXT does not list perpetual swaps for Bequant, so use spot markets.

**Is LumiBot free?**

Yes. LumiBot is open source on GitHub at https://github.com/Lumiwealth/lumibot. You pay only your exchange's trading fees and, for AI agents, your model provider.
