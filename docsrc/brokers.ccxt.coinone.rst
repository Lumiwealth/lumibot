What is CoinOne?
----------------

Coinone is a crypto exchange with spot markets priced in Korean won (KRW). Its Open API gives market data, balances, order history and trading.

Sign up for CoinOne
-------------------

#. Sign up in the Coinone app with identity verification (Kakao Bank or phone verification).
#. Finish the remaining checks Coinone asks for: ID photo, personal details and linking your own bank account.
#. Add extra channel authentication (Kakao or Naver simple authentication) to protect your account.

`Open a CoinOne account <https://coinone.co.kr/>`_

Create a CoinOne API key
------------------------

#. Log in on the Coinone website, scroll to the footer and click Open API.
#. Open Integrated API Management (통합 API 관리) and go to the Personal API (개인용 API) section.
#. Click Issue New Key (새로운 키 발급).
#. Choose the permissions (see below) and enter the public IPv4 address of your bot. Coinone requires at least one IP and allows up to 5 per key.
#. Save the Access Token and Secret Key in a safe place. If you lose them you must issue a new key.

**Which permissions to turn on:** Turn on balance inquiry (잔고 조회), order inquiry (주문 조회) and order management (주문 관리), which lets the key place and cancel buy and sell orders. Leave withdrawal (출금 권한) off. A bot never needs to move money out of your account.

.. warning::

   Never turn on withdrawals for a CoinOne trading bot key. Bind the key to your server's IP address when CoinOne lets you, keep the secret out of your code and out of Git, and delete the key if it ever leaks.

Connect CoinOne to LumiBot
--------------------------

The simplest way: put these lines in a ``.env`` file next to your strategy. LumiBot loads the file, sees ``TRADING_BROKER=coinone`` and connects to CoinOne for you, so your strategy needs no broker code.

.. code-block:: bash

   TRADING_BROKER=coinone
   COINONE_API_KEY=your_apiKey
   COINONE_API_SECRET=your_secret

LumiBot reads exactly the fields CCXT needs for CoinOne (``apiKey``, ``secret``). If one is missing, LumiBot stops at start-up and names the variable you still need.

You can also build the broker in code. This is handy when one script talks to more than one exchange, or when you need extra CCXT options. The keys in the config are CCXT's own credential names for CoinOne:

.. code-block:: python

   import os

   COINONE_CONFIG = {
       "exchange_id": "coinone",
       "apiKey": os.environ.get("COINONE_API_KEY"),
       "secret": os.environ.get("COINONE_API_SECRET"),
       "sandbox": False,  # no sandbox for this exchange
   }

   from lumibot.brokers import Ccxt

   broker = Ccxt(COINONE_CONFIG)
   # then: MyStrategy(broker=broker, ...)

Either way, LumiBot turns on CCXT's built-in rate limiting for you.

Testing on CoinOne
------------------

Coinone has no sandbox, and CCXT lists no test URL for it, so test with a very small amount. With environment variables, leave ``COINONE_SANDBOX`` unset. In a code config, always set ``"sandbox": False``.

Algorithmic trading example: a simple CoinOne bot
-------------------------------------------------

This bot buys about 70000 KRW of BTC on CoinOne once and then holds it. It is a starting point to check that your keys, balances and orders work. If the exchange's minimum order is larger, raise the amount. CoinOne accepts only limit orders through CCXT, so the example places a limit order just above the last price.

.. code-block:: python

   from lumibot.entities import Asset
   from lumibot.strategies import Strategy


   class CoinoneBuyOnce(Strategy):
       """Buy a small amount of BTC once, then hold it."""

       def initialize(self):
           self.sleeptime = "1H"
           self.set_market("24/7")  # crypto trades all day, every day

       def on_trading_iteration(self):
           coin = Asset("BTC", asset_type=Asset.AssetType.CRYPTO)
           if self.get_position(coin) is not None:
               return  # already holding BTC
           price = self.get_last_price(coin, quote=self.quote_asset)
           if price:
               quantity = round(70000 / price, 6)  # about 70000 KRW worth
               # This exchange takes only limit orders through CCXT.
               order = self.create_order(coin, quantity, "buy", limit_price=price * 1.002, quote=self.quote_asset)
               self.submit_order(order)


   if __name__ == "__main__":
       # LumiBot reads TRADING_BROKER and the keys from your .env file.
       strategy = CoinoneBuyOnce(quote_asset=Asset("KRW", asset_type=Asset.AssetType.CRYPTO))
       strategy.run_live()

Agentic trading example: an AI agent that trades on CoinOne
-----------------------------------------------------------

Agentic trading means an AI agent reads the market and decides what to do. In this example one LumiBot agent looks at prices and your CoinOne account, then places the orders itself. There is no Python logic in between: you set the rules in plain English in the prompt, such as what it may trade and how big each order can be. This follows the same pattern as LumiBot's AI trading team examples.

.. code-block:: python

   from lumibot.entities import Asset
   from lumibot.strategies import Strategy


   class CoinoneAITrader(Strategy):
       """One AI agent researches the market and places the trades itself."""

       def initialize(self):
           self.sleeptime = "4H"
           self.set_market("24/7")
           self.agents.create(
               name="trader",
               model="openai/gpt-6-luna",
               reasoning_effort="high",
               allow_trading=True,
               system_prompt=(
                   "You manage a small crypto account on CoinOne. "
                   "You may trade BTC and ETH against KRW (asset_type 'crypto', quote_symbol 'KRW'), or hold cash. "
                   "Before every order, call account_portfolio, account_positions and "
                   "market_last_price for that exact symbol in the same run. "
                   "Keep each order under 10% of the account value. "
                   "Explain each decision in one short paragraph."
               ),
           )

       def on_trading_iteration(self):
           self.agents["trader"].run(
               task_prompt="Review recent BTC/KRW and ETH/KRW prices and your current holdings, then decide whether to buy, sell or hold.",
               context={"exchange": "CoinOne", "quote": "KRW", "date": self.get_datetime().isoformat()},
           )


   if __name__ == "__main__":
       # LumiBot reads TRADING_BROKER and the keys from your .env file.
       strategy = CoinoneAITrader(quote_asset=Asset("KRW", asset_type=Asset.AssetType.CRYPTO))
       strategy.run_live()

The agent needs a model key such as ``OPENAI_API_KEY`` in your environment. See the :doc:`AI agents quickstart <agents_quickstart>` for models, tools and memory.

Fees and partner IDs on CoinOne
-------------------------------

You pay CoinOne's normal trading fees. LumiBot may attach its own exchange partner ID. That costs you nothing extra. LumiBot never adds an extra builder fee unless one is turned on, and it logs a warning when one is.

CoinOne tips
------------

* Coinone API keys expire one year after you create them. Check the expiry date on the API management page and make a new key before it runs out.
* Coinone calls the API key an Access Token. Put the Access Token in the API key field and the Secret Key in the secret field.
* Use a fixed IP address for your bot. Coinone blocks calls from IPs that are not on the key's list, so a changing home IP can break your bot.
* CCXT's Coinone support has no market orders (only limit orders), so use limit orders with this exchange.

Frequently asked questions
--------------------------

**Can I build a CoinOne trading bot in Python?**

Yes. Install LumiBot (``pip install lumibot``), set your CoinOne keys and use the ``coinone`` CCXT exchange id as shown above.

**Does CoinOne have a testnet?**

No testnet is set up for CoinOne in LumiBot. Start with a small amount, and in a code config set ``"sandbox": False``.

**Which API permissions does a CoinOne bot need?**

Turn on balance inquiry (잔고 조회), order inquiry (주문 조회) and order management (주문 관리), which lets the key place and cancel buy and sell orders. Leave withdrawal (출금 권한) off. A bot never needs to move money out of your account.

**Can an AI agent trade on CoinOne by itself?**

Yes. The agentic example above gives one agent permission to trade. You control what it may trade and how much through its prompt.

**Can I trade CoinOne perpetual futures with LumiBot?**

CCXT does not list perpetual swaps for CoinOne, so use spot markets.

**Is LumiBot free?**

Yes. LumiBot is open source on GitHub at https://github.com/Lumiwealth/lumibot. You pay only your exchange's trading fees and, for AI agents, your model provider.
