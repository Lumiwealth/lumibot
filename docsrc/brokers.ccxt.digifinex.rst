What is DigiFinex?
------------------

DigiFinex is a trading platform for crypto assets such as Bitcoin and Ethereum. Its API covers spot and margin trading, plus perpetual swaps through a separate swap API.

Sign up for DigiFinex
---------------------

#. Open https://www.digifinex.com and click Sign Up. Enter your email address or phone number and click Create Account.
#. Enter the verification code DigiFinex sends you and click Activate Account.
#. Turn on Google two-factor authentication (User Profile, then 2Factor Authentication). DigiFinex requires 2FA before you can create an API key.

`Open a DigiFinex account <https://www.digifinex.com/>`_

Create a DigiFinex API key
--------------------------

#. Log in at https://www.digifinex.com, move your mouse to the head icon in the top right corner and choose User Center.
#. Scroll down to API Setting and click Create API.
#. Fill in Name your API and click Send Code to get a code by email.
#. Enter the email code and your 2FA code, then click Confirm.
#. Copy the Api Key and Api Secret right away. DigiFinex shows them only once. If you click away first, you must make a new key.
#. Bind your bot's IP address to the key for safety. DigiFinex lets you bind up to 4 IP addresses to each key.

**Which permissions to turn on:** DigiFinex's guide does not list the permission names. Its API docs say each key has a permission setting, so check that the key is allowed to trade. Leave withdrawals off if you see that option. A trading bot never needs to move money out of your account.

.. warning::

   Never turn on withdrawals for a DigiFinex trading bot key. Bind the key to your server's IP address when DigiFinex lets you, keep the secret out of your code and out of Git, and delete the key if it ever leaks.

Connect DigiFinex to LumiBot
----------------------------

The simplest way: put these lines in a ``.env`` file next to your strategy. LumiBot loads the file, sees ``TRADING_BROKER=digifinex`` and connects to DigiFinex for you, so your strategy needs no broker code.

.. code-block:: bash

   TRADING_BROKER=digifinex
   DIGIFINEX_API_KEY=your_apiKey
   DIGIFINEX_API_SECRET=your_secret

LumiBot reads exactly the fields CCXT needs for DigiFinex (``apiKey``, ``secret``). If one is missing, LumiBot stops at start-up and names the variable you still need.

You can also build the broker in code. This is handy when one script talks to more than one exchange, or when you need extra CCXT options. The keys in the config are CCXT's own credential names for DigiFinex:

.. code-block:: python

   import os

   DIGIFINEX_CONFIG = {
       "exchange_id": "digifinex",
       "apiKey": os.environ.get("DIGIFINEX_API_KEY"),
       "secret": os.environ.get("DIGIFINEX_API_SECRET"),
       "sandbox": False,  # live connection
   }

   from lumibot.brokers import Ccxt

   broker = Ccxt(DIGIFINEX_CONFIG)
   # then: MyStrategy(broker=broker, ...)

Either way, LumiBot turns on CCXT's built-in rate limiting for you.

Testing on DigiFinex
--------------------

DigiFinex has no sandbox. Test with a very small amount, leave ``DIGIFINEX_SANDBOX`` unset, and in a code config set ``"sandbox": False``.

Algorithmic trading example: a simple DigiFinex bot
---------------------------------------------------

This bot buys about 50 USDT of BTC on DigiFinex once and then holds it. It is a starting point to check that your keys, balances and orders work. If the exchange's minimum order is larger, raise the amount. DigiFinex accepts only limit orders through CCXT, so the example places a limit order just above the last price.

.. code-block:: python

   from lumibot.entities import Asset
   from lumibot.strategies import Strategy


   class DigifinexBuyOnce(Strategy):
       """Buy a small amount of BTC once, then hold it."""

       def initialize(self):
           self.sleeptime = "1H"
           self.set_market("24/7")  # crypto trades all day, every day

       def on_trading_iteration(self):
           coin = Asset("BTC", asset_type=Asset.AssetType.CRYPTO)
           if self.get_position(coin) is not None:
               return  # already holding BTC
           price = self.get_last_price(coin, quote=self.quote_asset)
           if price:
               quantity = round(50 / price, 6)  # about 50 USDT worth
               # This exchange takes only limit orders through CCXT.
               order = self.create_order(coin, quantity, "buy", limit_price=price * 1.002, quote=self.quote_asset)
               self.submit_order(order)


   if __name__ == "__main__":
       # LumiBot reads TRADING_BROKER and the keys from your .env file.
       strategy = DigifinexBuyOnce(quote_asset=Asset("USDT", asset_type=Asset.AssetType.CRYPTO))
       strategy.run_live()

Agentic trading example: an AI agent that trades on DigiFinex
-------------------------------------------------------------

Agentic trading means an AI agent reads the market and decides what to do. In this example one LumiBot agent looks at prices and your DigiFinex account, then places the orders itself. There is no Python logic in between: you set the rules in plain English in the prompt, such as what it may trade and how big each order can be. This follows the same pattern as LumiBot's AI trading team examples.

.. code-block:: python

   from lumibot.entities import Asset
   from lumibot.strategies import Strategy


   class DigifinexAITrader(Strategy):
       """One AI agent researches the market and places the trades itself."""

       def initialize(self):
           self.sleeptime = "4H"
           self.set_market("24/7")
           self.agents.create(
               name="trader",
               model="openai/gpt-6-luna",
               reasoning_effort="high",
               allow_trading=True,
               system_prompt=(
                   "You manage a small crypto account on DigiFinex. "
                   "You may trade BTC and ETH against USDT (asset_type 'crypto', quote_symbol 'USDT'), or hold cash. "
                   "Before every order, call account_portfolio, account_positions and "
                   "market_last_price for that exact symbol in the same run. "
                   "Keep each order under 10% of the account value. "
                   "Explain each decision in one short paragraph."
               ),
           )

       def on_trading_iteration(self):
           self.agents["trader"].run(
               task_prompt="Review recent BTC/USDT and ETH/USDT prices and your current holdings, then decide whether to buy, sell or hold.",
               context={"exchange": "DigiFinex", "quote": "USDT", "date": self.get_datetime().isoformat()},
           )


   if __name__ == "__main__":
       # LumiBot reads TRADING_BROKER and the keys from your .env file.
       strategy = DigifinexAITrader(quote_asset=Asset("USDT", asset_type=Asset.AssetType.CRYPTO))
       strategy.run_live()

The agent needs a model key such as ``OPENAI_API_KEY`` in your environment. See the :doc:`AI agents quickstart <agents_quickstart>` for models, tools and memory.

Perpetual futures example on DigiFinex
--------------------------------------

DigiFinex also lists perpetual swaps. This bot opens one small long position in ``BTC/USDT:USDT`` worth about 50 USDT and then holds it. LumiBot treats a perpetual as ``asset_type="crypto_future"`` and sizes it in contracts, the same model as LumiBot's Bitunix futures broker. Contract symbols can differ by exchange, so check the symbol in ``self.broker.api.markets`` before going live. In hedge mode, add ``position_side="long"`` to ``create_order``. DigiFinex accepts only limit orders through CCXT, so the example places a limit order just above the last price.

.. code-block:: python

   from lumibot.entities import Asset
   from lumibot.strategies import Strategy


   class DigifinexOpenOneLong(Strategy):
       """Open one small long BTC perpetual position, then hold it."""

       def initialize(self):
           self.sleeptime = "1H"
           self.set_market("24/7")  # crypto trades all day, every day

       def on_trading_iteration(self):
           # The full CCXT symbol keeps the settlement currency clear.
           contract = self.broker.get_asset("BTC/USDT:USDT")
           if self.get_position(contract) is not None:
               return  # already holding the position
           price = self.get_last_price(contract)
           if price:
               # Each contract covers contract.multiplier BTC; size the order to about 50 USDT.
               quantity = round(50 / (price * contract.multiplier), 6)
               # This exchange takes only limit orders through CCXT.
               order = self.create_order(contract, quantity, "buy", limit_price=price * 1.002)
               self.submit_order(order)


   if __name__ == "__main__":
       # LumiBot reads TRADING_BROKER and the keys from your .env file.
       strategy = DigifinexOpenOneLong(quote_asset=Asset("USDT", asset_type=Asset.AssetType.CRYPTO))
       strategy.run_live()

Fees and partner IDs on DigiFinex
---------------------------------

You pay DigiFinex's normal trading fees. LumiBot may attach its own exchange partner ID. That costs you nothing extra. LumiBot never adds an extra builder fee unless one is turned on, and it logs a warning when one is.

DigiFinex tips
--------------

* Each DigiFinex user can create up to 5 API keys, and each key can be bound to up to 4 IP addresses.
* DigiFinex uses two API bases: ``https://openapi.digifinex.com/v3`` for spot and margin, and ``https://openapi.digifinex.com/swap/v2`` for perpetual swaps. CCXT handles both under the ``digifinex`` id.
* DigiFinex supports sub-accounts. A normal account can make 1 sub-account, and the limit grows with VIP level. A sub-account per bot keeps bot trades apart from manual ones.
* If you get an ``IP address Unauthorized`` error, your bot's IP is not bound to the key.

Frequently asked questions
--------------------------

**Can I build a DigiFinex trading bot in Python?**

Yes. Install LumiBot (``pip install lumibot``), set your DigiFinex keys and use the ``digifinex`` CCXT exchange id as shown above.

**Does DigiFinex have a testnet?**

No testnet is set up for DigiFinex in LumiBot. Start with a small amount, and in a code config set ``"sandbox": False``.

**Which API permissions does a DigiFinex bot need?**

DigiFinex's guide does not list the permission names. Its API docs say each key has a permission setting, so check that the key is allowed to trade. Leave withdrawals off if you see that option. A trading bot never needs to move money out of your account.

**Can an AI agent trade on DigiFinex by itself?**

Yes. The agentic example above gives one agent permission to trade. You control what it may trade and how much through its prompt.

**Can I trade DigiFinex perpetual futures with LumiBot?**

CCXT lists perpetual swaps for this exchange. Use the full contract symbol, such as ``BTC/USDT:USDT``.

**Is LumiBot free?**

Yes. LumiBot is open source on GitHub at https://github.com/Lumiwealth/lumibot. You pay only your exchange's trading fees and, for AI agents, your model provider.
