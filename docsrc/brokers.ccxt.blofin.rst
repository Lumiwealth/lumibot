What is BloFin?
---------------

BloFin is a crypto exchange best known for futures trading. Its API covers more than 200 perpetual contracts, plus copy trading, and BloFin also lists spot trading.

Sign up for BloFin
------------------

#. Go to the BloFin home page and select Sign up. Use an email address, phone number, Google account or Apple ID.
#. Enter the six digit code BloFin sends you within 5 minutes to finish creating the account.
#. Finish identity verification (open your avatar, then Identification) so your account gets higher limits.

`Open a BloFin account <https://blofin.com/en/register>`_

Create a BloFin API key
-----------------------

#. Log in on the BloFin website and open the APIs page (https://blofin.com/en/apis), then click Create an API Key.
#. Type a passphrase. You will need it every time the bot connects, so store it safely.
#. Choose the permissions (see below).
#. Link the IP address of the machine that runs your bot. Each key can have up to 20 IP addresses.
#. Save the API key, secret key and passphrase in a safe place.

**Which permissions to turn on:** Turn on READ and TRADE. TRADE lets the bot place and cancel orders. Leave TRANSFER off, and leave withdrawals off. A bot never needs to move money out of your account.

.. warning::

   Never turn on withdrawals for a BloFin trading bot key. Bind the key to your server's IP address when BloFin lets you, keep the secret out of your code and out of Git, and delete the key if it ever leaks.

Connect BloFin to LumiBot
-------------------------

The simplest way: put these lines in a ``.env`` file next to your strategy. LumiBot loads the file, sees ``TRADING_BROKER=blofin`` and connects to BloFin for you, so your strategy needs no broker code.

.. code-block:: bash

   TRADING_BROKER=blofin
   BLOFIN_API_KEY=your_apiKey
   BLOFIN_API_PASSPHRASE=your_password
   BLOFIN_API_SECRET=your_secret
   BLOFIN_SANDBOX=true   # testnet; remove this line for your live account

LumiBot reads exactly the fields CCXT needs for BloFin (``apiKey``, ``password``, ``secret``). If one is missing, LumiBot stops at start-up and names the variable you still need.

You can also build the broker in code. This is handy when one script talks to more than one exchange, or when you need extra CCXT options. The keys in the config are CCXT's own credential names for BloFin:

.. code-block:: python

   import os

   BLOFIN_CONFIG = {
       "exchange_id": "blofin",
       "apiKey": os.environ.get("BLOFIN_API_KEY"),
       "password": os.environ.get("BLOFIN_API_PASSPHRASE"),
       "secret": os.environ.get("BLOFIN_API_SECRET"),
       "sandbox": True,  # testnet first; set False for your live account
   }

   from lumibot.brokers import Ccxt

   broker = Ccxt(BLOFIN_CONFIG)
   # then: MyStrategy(broker=broker, ...)

Either way, LumiBot turns on CCXT's built-in rate limiting for you.

Practice on the BloFin testnet
------------------------------

BloFin runs a demo trading environment with simulated funds. Its API lives at https://demo-trading-openapi.blofin.com. Set ``BLOFIN_SANDBOX=true`` (or ``"sandbox": True`` in a code config) to send LumiBot requests there.

CCXT sends sandbox requests to: https://demo-trading-openapi.blofin.com. Testnet and live accounts use different keys.

Algorithmic trading example: a simple BloFin bot
------------------------------------------------

CCXT lists no spot market for BloFin, so this example trades a perpetual contract. It opens one small long BTC position worth about 50 USDT and then holds it. It is a starting point to check that your keys, balances and orders work. If the exchange's minimum order is larger, raise the amount. If your account uses hedge mode, add ``position_side="long"`` to ``create_order``.

.. code-block:: python

   from lumibot.entities import Asset
   from lumibot.strategies import Strategy


   class BlofinOpenOneLong(Strategy):
       """Open one small long BTC perpetual position, then hold it."""

       def initialize(self):
           self.sleeptime = "1H"
           self.set_market("24/7")  # crypto trades all day, every day

       def on_trading_iteration(self):
           # The full CCXT symbol keeps the settlement currency clear.
           contract = self.broker.get_asset("BTC/USDT:USDT")
           if self.get_position(contract) is not None:
               return  # already holding the position
           price = self.get_last_price(contract)
           if price:
               # Each contract covers contract.multiplier BTC; size the order to about 50 USDT.
               quantity = round(50 / (price * contract.multiplier), 6)
               order = self.create_order(contract, quantity, "buy")
               self.submit_order(order)


   if __name__ == "__main__":
       # LumiBot reads TRADING_BROKER and the keys from your .env file.
       strategy = BlofinOpenOneLong(quote_asset=Asset("USDT", asset_type=Asset.AssetType.CRYPTO))
       strategy.run_live()

Agentic trading example: an AI agent that trades on BloFin
----------------------------------------------------------

Agentic trading means an AI agent reads the market and decides what to do. In this example one LumiBot agent looks at prices and your BloFin account, then places the orders itself. There is no Python logic in between: you set the rules in plain English in the prompt, such as what it may trade and how big each order can be. This follows the same pattern as LumiBot's AI trading team examples.

.. code-block:: python

   from lumibot.entities import Asset
   from lumibot.strategies import Strategy


   class BlofinAITrader(Strategy):
       """One AI agent researches the market and places the trades itself."""

       def initialize(self):
           self.sleeptime = "4H"
           self.set_market("24/7")
           self.agents.create(
               name="trader",
               model="openai/gpt-6-luna",
               reasoning_effort="high",
               allow_trading=True,
               system_prompt=(
                   "You manage a small crypto account on BloFin. "
                   "You may trade the BTC/USDT:USDT perpetual contract (asset_type 'crypto_future'), long or short, or stay flat. "
                   "Before every order, call account_portfolio, account_positions and "
                   "market_last_price for that exact symbol in the same run. "
                   "Keep each order under 10% of the account value. "
                   "Explain each decision in one short paragraph."
               ),
           )

       def on_trading_iteration(self):
           self.agents["trader"].run(
               task_prompt="Review recent BTC/USDT:USDT prices and your current position, then decide whether to buy, sell or hold.",
               context={"exchange": "BloFin", "quote": "USDT", "date": self.get_datetime().isoformat()},
           )


   if __name__ == "__main__":
       # LumiBot reads TRADING_BROKER and the keys from your .env file.
       strategy = BlofinAITrader(quote_asset=Asset("USDT", asset_type=Asset.AssetType.CRYPTO))
       strategy.run_live()

The agent needs a model key such as ``OPENAI_API_KEY`` in your environment. See the :doc:`AI agents quickstart <agents_quickstart>` for models, tools and memory.

BloFin tips
-----------

* BloFin needs three credentials: the API key, the secret key and the passphrase you typed. Put the passphrase in ``BLOFIN_API_PASSPHRASE`` (``"password"`` in a code config).
* API keys that are not bound to an IP address expire after 90 days. Bind your bot's IP address so the key keeps working.
* BloFin's own symbols use a dash, like ``BTC-USDT``. In LumiBot use the CCXT form ``BTC/USDT:USDT`` for the USDT perpetual.
* Sub-accounts keep their own settings, separate from the main account. Common sub-accounts cannot withdraw.

Frequently asked questions
--------------------------

**Can I build a BloFin trading bot in Python?**

Yes. Install LumiBot (``pip install lumibot``), set your BloFin keys and use the ``blofin`` CCXT exchange id as shown above.

**Does BloFin have a testnet?**

Yes. Set ``BLOFIN_SANDBOX=true`` and use keys from the BloFin testnet.

**Which API permissions does a BloFin bot need?**

Turn on READ and TRADE. TRADE lets the bot place and cancel orders. Leave TRANSFER off, and leave withdrawals off. A bot never needs to move money out of your account.

**Can an AI agent trade on BloFin by itself?**

Yes. The agentic example above gives one agent permission to trade. You control what it may trade and how much through its prompt.

**Can I trade BloFin perpetual futures with LumiBot?**

CCXT lists perpetual swaps for this exchange. Use the full contract symbol, such as ``BTC/USDT:USDT``.

**Is LumiBot free?**

Yes. LumiBot is open source on GitHub at https://github.com/Lumiwealth/lumibot. You pay only your exchange's trading fees and, for AI agents, your model provider.
