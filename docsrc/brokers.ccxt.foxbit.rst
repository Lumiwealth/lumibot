What is Foxbit?
---------------

Foxbit is a crypto exchange where you can buy, sell and trade the coins it lists, with prices in reais (BRL).

Sign up for Foxbit
------------------

#. Go to https://app.foxbit.com.br/ (or the Foxbit app), click Cadastre-se and enter your email and a strong password.
#. Click Verificar E-mail in the message Foxbit sends, choose a personal account, and fill in your personal details and address.
#. Turn on two-factor authentication (2FA). Foxbit requires it before you can add an API key.

`Open a Foxbit account <https://app.foxbit.com.br/>`_

Create a Foxbit API key
-----------------------

#. Log in on the desktop site and click Configurações da conta (account settings) in the top right.
#. Click API Key, then click Próximo (next).
#. Choose the permissions, give the key a name and click Criar API Key.
#. Enter your 2FA code if asked.
#. Save the key and secret right away. Foxbit will not show the secret again after you close the window.

**Which permissions to turn on:** Turn on read and trade. Foxbit's API docs list read, trade, deposit and withdrawal, and order endpoints need trade. Leave withdrawal off. Foxbit also requires an IP list for any key with withdrawals.

.. warning::

   Never turn on withdrawals for a Foxbit trading bot key. Bind the key to your server's IP address when Foxbit lets you, keep the secret out of your code and out of Git, and delete the key if it ever leaks.

Connect Foxbit to LumiBot
-------------------------

The simplest way: put these lines in a ``.env`` file next to your strategy. LumiBot loads the file, sees ``TRADING_BROKER=foxbit`` and connects to Foxbit for you, so your strategy needs no broker code.

.. code-block:: bash

   TRADING_BROKER=foxbit
   FOXBIT_API_KEY=your_apiKey
   FOXBIT_API_SECRET=your_secret

LumiBot reads exactly the fields CCXT needs for Foxbit (``apiKey``, ``secret``). If one is missing, LumiBot stops at start-up and names the variable you still need.

You can also build the broker in code. This is handy when one script talks to more than one exchange, or when you need extra CCXT options. The keys in the config are CCXT's own credential names for Foxbit:

.. code-block:: python

   import os

   FOXBIT_CONFIG = {
       "exchange_id": "foxbit",
       "apiKey": os.environ.get("FOXBIT_API_KEY"),
       "secret": os.environ.get("FOXBIT_API_SECRET"),
       "sandbox": False,  # no sandbox for this exchange
   }

   from lumibot.brokers import Ccxt

   broker = Ccxt(FOXBIT_CONFIG)
   # then: MyStrategy(broker=broker, ...)

Either way, LumiBot turns on CCXT's built-in rate limiting for you.

Testing on Foxbit
-----------------

Foxbit has no sandbox, and its API docs say requests run against the real environment. Test with a very small amount. With environment variables, leave ``FOXBIT_SANDBOX`` unset. In a code config, set ``"sandbox": False``.

Algorithmic trading example: a simple Foxbit bot
------------------------------------------------

This bot buys about 250 BRL of BTC on Foxbit once and then holds it. It is a starting point to check that your keys, balances and orders work. If the exchange's minimum order is larger, raise the amount.

.. code-block:: python

   from lumibot.entities import Asset
   from lumibot.strategies import Strategy


   class FoxbitBuyOnce(Strategy):
       """Buy a small amount of BTC once, then hold it."""

       def initialize(self):
           self.sleeptime = "1H"
           self.set_market("24/7")  # crypto trades all day, every day

       def on_trading_iteration(self):
           coin = Asset("BTC", asset_type=Asset.AssetType.CRYPTO)
           if self.get_position(coin) is not None:
               return  # already holding BTC
           price = self.get_last_price(coin, quote=self.quote_asset)
           if price:
               quantity = round(250 / price, 6)  # about 250 BRL worth
               order = self.create_order(coin, quantity, "buy", quote=self.quote_asset)
               self.submit_order(order)


   if __name__ == "__main__":
       # LumiBot reads TRADING_BROKER and the keys from your .env file.
       strategy = FoxbitBuyOnce(quote_asset=Asset("BRL", asset_type=Asset.AssetType.CRYPTO))
       strategy.run_live()

Agentic trading example: an AI agent that trades on Foxbit
----------------------------------------------------------

Agentic trading means an AI agent reads the market and decides what to do. In this example one LumiBot agent looks at prices and your Foxbit account, then places the orders itself. There is no Python logic in between: you set the rules in plain English in the prompt, such as what it may trade and how big each order can be. This follows the same pattern as LumiBot's AI trading team examples.

.. code-block:: python

   from lumibot.entities import Asset
   from lumibot.strategies import Strategy


   class FoxbitAITrader(Strategy):
       """One AI agent researches the market and places the trades itself."""

       def initialize(self):
           self.sleeptime = "4H"
           self.set_market("24/7")
           self.agents.create(
               name="trader",
               model="openai/gpt-6-luna",
               reasoning_effort="high",
               allow_trading=True,
               system_prompt=(
                   "You manage a small crypto account on Foxbit. "
                   "You may trade BTC and ETH against BRL (asset_type 'crypto', quote_symbol 'BRL'), or hold cash. "
                   "Before every order, call account_portfolio, account_positions and "
                   "market_last_price for that exact symbol in the same run. "
                   "Keep each order under 10% of the account value. "
                   "Explain each decision in one short paragraph."
               ),
           )

       def on_trading_iteration(self):
           self.agents["trader"].run(
               task_prompt="Review recent BTC/BRL and ETH/BRL prices and your current holdings, then decide whether to buy, sell or hold.",
               context={"exchange": "Foxbit", "quote": "BRL", "date": self.get_datetime().isoformat()},
           )


   if __name__ == "__main__":
       # LumiBot reads TRADING_BROKER and the keys from your .env file.
       strategy = FoxbitAITrader(quote_asset=Asset("BRL", asset_type=Asset.AssetType.CRYPTO))
       strategy.run_live()

The agent needs a model key such as ``OPENAI_API_KEY`` in your environment. See the :doc:`AI agents quickstart <agents_quickstart>` for models, tools and memory.

Foxbit tips
-----------

* Foxbit offers two kinds of keys: one Foxbit generates (key plus secret) and one where you upload your own Ed25519 public key. CCXT signs with a secret, so create the standard key Foxbit generates.
* Foxbit writes markets without a separator, like ``btcbrl``. In LumiBot and CCXT use ``BTC/BRL``.
* If you lose the key details, delete the key and make a new one.

Frequently asked questions
--------------------------

**Can I build a Foxbit trading bot in Python?**

Yes. Install LumiBot (``pip install lumibot``), set your Foxbit keys and use the ``foxbit`` CCXT exchange id as shown above.

**Does Foxbit have a testnet?**

No testnet is set up for Foxbit in LumiBot. Start with a small amount, and in a code config set ``"sandbox": False``.

**Which API permissions does a Foxbit bot need?**

Turn on read and trade. Foxbit's API docs list read, trade, deposit and withdrawal, and order endpoints need trade. Leave withdrawal off. Foxbit also requires an IP list for any key with withdrawals.

**Can an AI agent trade on Foxbit by itself?**

Yes. The agentic example above gives one agent permission to trade. You control what it may trade and how much through its prompt.

**Can I trade Foxbit perpetual futures with LumiBot?**

CCXT does not list perpetual swaps for Foxbit, so use spot markets.

**Is LumiBot free?**

Yes. LumiBot is open source on GitHub at https://github.com/Lumiwealth/lumibot. You pay only your exchange's trading fees and, for AI agents, your model provider.
