Brokers
===================================

There are several different brokers that you can use to trade with Lumibot, and we're adding more as we speak! Learn more about how they work and how to set them up here.

If you do not want to manage broker credentials, deployment secrets, scheduled runs, logs, alerts, and account monitoring yourself, `BotSpot <https://botspot.trade/sales?showLogin=1&utm_source=documentation&utm_medium=brokers&utm_campaign=lumibot&utm_content=broker_setup_text&prompt=I%20want%20to%20connect%20a%20broker%20and%20run%20a%20Lumibot%20strategy%20on%20BotSpot.%20Please%20help%20me%20set%20up%20broker%20connections%2C%20monitoring%2C%20and%20paper%20or%20live%20deployment.>`_ can handle supported broker connections through the website and run the same Lumibot strategy with monitoring, audit logs, alerts, and kill-switch controls.
