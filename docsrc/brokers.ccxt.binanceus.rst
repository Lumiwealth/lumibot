What is Binance US?
-------------------

Binance.US is a crypto exchange for buying, selling and trading more than 200 cryptocurrencies. It offers spot trading with advanced trading tools, plus convert, OTC and staking.

Sign up for Binance US
----------------------

#. Create a Binance.US account with your email and a password (Google Sign-In also works), then enter the code Binance.US emails you.
#. Turn on SMS two-factor authentication. Binance.US requires it to finish sign-up; you can switch to an authenticator app later.
#. Complete Basic Verification. Binance.US says you must finish it before you can open API Management.

`Open a Binance US account <https://www.binance.us/register>`_

Create a Binance US API key
---------------------------

#. Log in to Binance.US in a web browser.
#. Hover over your email or profile icon in the top menu and choose API Management (https://www.binance.us/settings/api-management).
#. Pick the Exchange API key type and enter a clear label so you can find the key later.
#. Click Create and finish two-factor authentication. Binance.US may ask for both your 2FA code and an email confirmation.
#. Copy the API key and secret right away. Binance.US shows the secret only once.
#. Click Edit restrictions to set permissions (see below) and add your bot's IP address.

**Which permissions to turn on:** New keys start with Enable Reading only. Also turn on Enable Spot Trading so your bot can place orders. Leave Enable Withdrawals off. A bot never needs to move money out of your account.

.. warning::

   Never turn on withdrawals for a Binance US trading bot key. Bind the key to your server's IP address when Binance US lets you, keep the secret out of your code and out of Git, and delete the key if it ever leaks.

Connect Binance US to LumiBot
-----------------------------

The simplest way: put these lines in a ``.env`` file next to your strategy. LumiBot loads the file, sees ``TRADING_BROKER=binanceus`` and connects to Binance US for you, so your strategy needs no broker code.

.. code-block:: bash

   TRADING_BROKER=binanceus
   BINANCEUS_API_KEY=your_apiKey
   BINANCEUS_API_SECRET=your_secret

LumiBot reads exactly the fields CCXT needs for Binance US (``apiKey``, ``secret``). If one is missing, LumiBot stops at start-up and names the variable you still need.

You can also build the broker in code. This is handy when one script talks to more than one exchange, or when you need extra CCXT options. The keys in the config are CCXT's own credential names for Binance US:

.. code-block:: python

   import os

   BINANCEUS_CONFIG = {
       "exchange_id": "binanceus",
       "apiKey": os.environ.get("BINANCEUS_API_KEY"),
       "secret": os.environ.get("BINANCEUS_API_SECRET"),
       "sandbox": False,  # live connection
   }

   from lumibot.brokers import Ccxt

   broker = Ccxt(BINANCEUS_CONFIG)
   # then: MyStrategy(broker=broker, ...)

Either way, LumiBot turns on CCXT's built-in rate limiting for you.

Testing on Binance US
---------------------

Binance.US has no sandbox. Its API docs do not offer a test site, and the test URLs CCXT lists for this id belong to the separate Binance testnet, where Binance.US keys do not work. Test with a very small amount. With environment variables, leave ``BINANCEUS_SANDBOX`` unset. In a code config, always set ``"sandbox": False``.

Algorithmic trading example: a simple Binance US bot
----------------------------------------------------

This bot buys about 50 USD of BTC on Binance US once and then holds it. It is a starting point to check that your keys, balances and orders work. If the exchange's minimum order is larger, raise the amount. Binance US accepts only limit orders through CCXT, so the example places a limit order just above the last price.

.. code-block:: python

   from lumibot.entities import Asset
   from lumibot.strategies import Strategy


   class BinanceusBuyOnce(Strategy):
       """Buy a small amount of BTC once, then hold it."""

       def initialize(self):
           self.sleeptime = "1H"
           self.set_market("24/7")  # crypto trades all day, every day

       def on_trading_iteration(self):
           coin = Asset("BTC", asset_type=Asset.AssetType.CRYPTO)
           if self.get_position(coin) is not None:
               return  # already holding BTC
           price = self.get_last_price(coin, quote=self.quote_asset)
           if price:
               quantity = round(50 / price, 6)  # about 50 USD worth
               # This exchange takes only limit orders through CCXT.
               order = self.create_order(coin, quantity, "buy", limit_price=price * 1.002, quote=self.quote_asset)
               self.submit_order(order)


   if __name__ == "__main__":
       # LumiBot reads TRADING_BROKER and the keys from your .env file.
       strategy = BinanceusBuyOnce(quote_asset=Asset("USD", asset_type=Asset.AssetType.CRYPTO))
       strategy.run_live()

Agentic trading example: an AI agent that trades on Binance US
--------------------------------------------------------------

Agentic trading means an AI agent reads the market and decides what to do. In this example one LumiBot agent looks at prices and your Binance US account, then places the orders itself. There is no Python logic in between: you set the rules in plain English in the prompt, such as what it may trade and how big each order can be. This follows the same pattern as LumiBot's AI trading team examples.

.. code-block:: python

   from lumibot.entities import Asset
   from lumibot.strategies import Strategy


   class BinanceusAITrader(Strategy):
       """One AI agent researches the market and places the trades itself."""

       def initialize(self):
           self.sleeptime = "4H"
           self.set_market("24/7")
           self.agents.create(
               name="trader",
               model="openai/gpt-6-luna",
               reasoning_effort="high",
               allow_trading=True,
               system_prompt=(
                   "You manage a small crypto account on Binance US. "
                   "You may trade BTC and ETH against USD (asset_type 'crypto', quote_symbol 'USD'), or hold cash. "
                   "Before every order, call account_portfolio, account_positions and "
                   "market_last_price for that exact symbol in the same run. "
                   "Keep each order under 10% of the account value. "
                   "Explain each decision in one short paragraph."
               ),
           )

       def on_trading_iteration(self):
           self.agents["trader"].run(
               task_prompt="Review recent BTC/USD and ETH/USD prices and your current holdings, then decide whether to buy, sell or hold.",
               context={"exchange": "Binance US", "quote": "USD", "date": self.get_datetime().isoformat()},
           )


   if __name__ == "__main__":
       # LumiBot reads TRADING_BROKER and the keys from your .env file.
       strategy = BinanceusAITrader(quote_asset=Asset("USD", asset_type=Asset.AssetType.CRYPTO))
       strategy.run_live()

The agent needs a model key such as ``OPENAI_API_KEY`` in your environment. See the :doc:`AI agents quickstart <agents_quickstart>` for models, tools and memory.

Fees and partner IDs on Binance US
----------------------------------

You pay Binance US's normal trading fees. LumiBot may attach its own exchange partner ID. That costs you nothing extra. LumiBot never adds an extra builder fee unless one is turned on, and it logs a warning when one is.

Binance US tips
---------------

* Add an IP restriction to your key. Binance.US resets keys to read-only if they go unused for 90 days and have no IP whitelist.
* Binance.US is a different exchange from Binance. Use the CCXT id ``binanceus`` with Binance.US keys, not ``binance``.
* Binance.US also lists BTC against USDT and USDC, so you can use ``BTC/USDT`` or ``BTC/USDC`` if your cash is held in a stablecoin.
* Binance.US recommends deleting old keys and making new ones about every 90 days, and deleting keys you no longer use.

Frequently asked questions
--------------------------

**Can I build a Binance US trading bot in Python?**

Yes. Install LumiBot (``pip install lumibot``), set your Binance US keys and use the ``binanceus`` CCXT exchange id as shown above.

**Does Binance US have a testnet?**

No testnet is set up for Binance US in LumiBot. Start with a small amount, and in a code config set ``"sandbox": False``.

**Which API permissions does a Binance US bot need?**

New keys start with Enable Reading only. Also turn on Enable Spot Trading so your bot can place orders. Leave Enable Withdrawals off. A bot never needs to move money out of your account.

**Can an AI agent trade on Binance US by itself?**

Yes. The agentic example above gives one agent permission to trade. You control what it may trade and how much through its prompt.

**Can I trade Binance US perpetual futures with LumiBot?**

CCXT does not list perpetual swaps for Binance US, so use spot markets.

**Is LumiBot free?**

Yes. LumiBot is open source on GitHub at https://github.com/Lumiwealth/lumibot. You pay only your exchange's trading fees and, for AI agents, your model provider.
