What is BitMart?
----------------

BitMart is a crypto exchange that offers spot trading, margin trading and futures (USDⓈ-M and COIN-M contracts). It also has a REST API and WebSocket feeds for automated trading.

Sign up for BitMart
-------------------

#. Create a BitMart account at https://www.bitmart.com/register/en.
#. Finish identity verification (KYC). BitMart says full access to spot and futures trading needs the KYC 2 level.
#. Turn on two-factor authentication under Security (phone and Google Authenticator).

`Open a BitMart account <https://www.bitmart.com/register/en>`_

Create a BitMart API key
------------------------

#. Log in on the BitMart website and click the Account tab.
#. Open API Management (https://www.bitmart.com/en-US/api-config).
#. Enter a Memo. This is any text you choose, and BitMart uses it when it checks each request.
#. Add your bot's IP address (optional, but BitMart recommends it) and pick the permissions below.
#. Create the key. BitMart shows the Secret Key only once, so copy and save it, then click Confirm.

**Which permissions to turn on:** New BitMart keys start as Read-Only. Add Spot-Trade for spot trading (and Future-Trade if your bot trades futures). Leave Withdraw off. A bot never needs to move money out of your account.

.. warning::

   Never turn on withdrawals for a BitMart trading bot key. Bind the key to your server's IP address when BitMart lets you, keep the secret out of your code and out of Git, and delete the key if it ever leaks.

Connect BitMart to LumiBot
--------------------------

The simplest way: put these lines in a ``.env`` file next to your strategy. LumiBot loads the file, sees ``TRADING_BROKER=bitmart`` and connects to BitMart for you, so your strategy needs no broker code.

.. code-block:: bash

   TRADING_BROKER=bitmart
   BITMART_API_KEY=your_apiKey
   BITMART_API_SECRET=your_secret
   BITMART_UID=your_uid

LumiBot reads exactly the fields CCXT needs for BitMart (``apiKey``, ``secret``, ``uid``). If one is missing, LumiBot stops at start-up and names the variable you still need.

You can also build the broker in code. This is handy when one script talks to more than one exchange, or when you need extra CCXT options. The keys in the config are CCXT's own credential names for BitMart:

.. code-block:: python

   import os

   BITMART_CONFIG = {
       "exchange_id": "bitmart",
       "apiKey": os.environ.get("BITMART_API_KEY"),
       "secret": os.environ.get("BITMART_API_SECRET"),
       "uid": os.environ.get("BITMART_UID"),
       "sandbox": False,  # no sandbox for this exchange
   }

   from lumibot.brokers import Ccxt

   broker = Ccxt(BITMART_CONFIG)
   # then: MyStrategy(broker=broker, ...)

Either way, LumiBot turns on CCXT's built-in rate limiting for you.

Testing on BitMart
------------------

CCXT lists no test URL for BitMart, so LumiBot cannot use a BitMart sandbox. Test with a very small amount. With environment variables, leave ``BITMART_SANDBOX`` unset. In a code config, set ``"sandbox": False``.

Algorithmic trading example: a simple BitMart bot
-------------------------------------------------

This bot buys about 50 USDT of BTC on BitMart once and then holds it. It is a starting point to check that your keys, balances and orders work. If the exchange's minimum order is larger, raise the amount.

.. code-block:: python

   from lumibot.entities import Asset
   from lumibot.strategies import Strategy


   class BitmartBuyOnce(Strategy):
       """Buy a small amount of BTC once, then hold it."""

       def initialize(self):
           self.sleeptime = "1H"
           self.set_market("24/7")  # crypto trades all day, every day

       def on_trading_iteration(self):
           coin = Asset("BTC", asset_type=Asset.AssetType.CRYPTO)
           if self.get_position(coin) is not None:
               return  # already holding BTC
           price = self.get_last_price(coin, quote=self.quote_asset)
           if price:
               quantity = round(50 / price, 6)  # about 50 USDT worth
               order = self.create_order(coin, quantity, "buy", quote=self.quote_asset)
               self.submit_order(order)


   if __name__ == "__main__":
       # LumiBot reads TRADING_BROKER and the keys from your .env file.
       strategy = BitmartBuyOnce(quote_asset=Asset("USDT", asset_type=Asset.AssetType.CRYPTO))
       strategy.run_live()

Agentic trading example: an AI agent that trades on BitMart
-----------------------------------------------------------

Agentic trading means an AI agent reads the market and decides what to do. In this example one LumiBot agent looks at prices and your BitMart account, then places the orders itself. There is no Python logic in between: you set the rules in plain English in the prompt, such as what it may trade and how big each order can be. This follows the same pattern as LumiBot's AI trading team examples.

.. code-block:: python

   from lumibot.entities import Asset
   from lumibot.strategies import Strategy


   class BitmartAITrader(Strategy):
       """One AI agent researches the market and places the trades itself."""

       def initialize(self):
           self.sleeptime = "4H"
           self.set_market("24/7")
           self.agents.create(
               name="trader",
               model="openai/gpt-6-luna",
               reasoning_effort="high",
               allow_trading=True,
               system_prompt=(
                   "You manage a small crypto account on BitMart. "
                   "You may trade BTC and ETH against USDT (asset_type 'crypto', quote_symbol 'USDT'), or hold cash. "
                   "Before every order, call account_portfolio, account_positions and "
                   "market_last_price for that exact symbol in the same run. "
                   "Keep each order under 10% of the account value. "
                   "Explain each decision in one short paragraph."
               ),
           )

       def on_trading_iteration(self):
           self.agents["trader"].run(
               task_prompt="Review recent BTC/USDT and ETH/USDT prices and your current holdings, then decide whether to buy, sell or hold.",
               context={"exchange": "BitMart", "quote": "USDT", "date": self.get_datetime().isoformat()},
           )


   if __name__ == "__main__":
       # LumiBot reads TRADING_BROKER and the keys from your .env file.
       strategy = BitmartAITrader(quote_asset=Asset("USDT", asset_type=Asset.AssetType.CRYPTO))
       strategy.run_live()

The agent needs a model key such as ``OPENAI_API_KEY`` in your environment. See the :doc:`AI agents quickstart <agents_quickstart>` for models, tools and memory.

BitMart tips
------------

* BitMart needs three values: the API key (Access Key), the Secret Key and the Memo. Put the Memo in ``BITMART_UID`` (CCXT's ``uid`` field). BitMart's own FAQ says the ccxt ``uid`` must be the API memo, not your BitMart user ID. A wrong memo gives the error ``Header X-BM-SIGN is wrong``.
* If you set an IP whitelist, BitMart rejects requests from any other IP that use that key.
* If a key leaks, BitMart says to delete it right away and create a new one. A lost Secret Key cannot be shown again, so you would need a new key.
* Sub-account API endpoints need Institution Verification. Sub-account keys also start as Read-only.

Frequently asked questions
--------------------------

**Can I build a BitMart trading bot in Python?**

Yes. Install LumiBot (``pip install lumibot``), set your BitMart keys and use the ``bitmart`` CCXT exchange id as shown above.

**Does BitMart have a testnet?**

No testnet is set up for BitMart in LumiBot. Start with a small amount, and in a code config set ``"sandbox": False``.

**Which API permissions does a BitMart bot need?**

New BitMart keys start as Read-Only. Add Spot-Trade for spot trading (and Future-Trade if your bot trades futures). Leave Withdraw off. A bot never needs to move money out of your account.

**Can an AI agent trade on BitMart by itself?**

Yes. The agentic example above gives one agent permission to trade. You control what it may trade and how much through its prompt.

**Can I trade BitMart perpetual futures with LumiBot?**

CCXT lists perpetual swaps for this exchange. Use the full contract symbol, such as ``BTC/USDT:USDT``.

**Is LumiBot free?**

Yes. LumiBot is open source on GitHub at https://github.com/Lumiwealth/lumibot. You pay only your exchange's trading fees and, for AI agents, your model provider.
