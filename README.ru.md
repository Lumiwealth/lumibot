# LumiBot AI Trading

**ИИ-агенты, которые действительно отправляют заявку.** Двенадцать интеграций с брокерами, настоящие бэктесты, а также акции, опционы, фьючерсы, валюты, криптовалюты и рынки предсказаний. Большинство проектов ИИ-трейдинга останавливаются на рекомендации. LumiBot отправляет заявку.

## Шестьдесят секунд

```bash
pip install lumibot
lumibot demo
```

Эта команда запускает настоящий бэктест на бесплатных дневных данных и формирует отчёт о результатах. Без ключа API, без брокерского счёта и без настройки.

Дальше сделайте его своим:

```bash
lumibot init my-bot --template ai
lumibot backtest my-bot --days 90
lumibot run my-bot --paper
```

`lumibot init` пишет ровно тот Python, который вы написали бы вручную. Командная строка ничего не скрывает, и у вас остаётся редактируемый файл.

**Предпочитаете классические стратегии?** Используйте `--template python`. Пишите собственные правила, индикаторы и логику заявок в обычном подклассе `Strategy`, без модели ИИ и без ключа API модели.

## Почему LumiBot

- **Правила на Python, ИИ-агенты или и то и другое.** Один знакомый жизненный цикл `Strategy`.
- **Бэктест до подключения брокера.** Исторические симуляции со сделками и результатами.
- **Одна стратегия для разных брокеров.** Логика стратегии отделена от настроек брокера.
- **Начните с работающих примеров.** Акции, макро, опционы или «купи и держи».
