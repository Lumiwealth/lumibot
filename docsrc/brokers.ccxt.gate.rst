What is Gate?
-------------

Gate is a large crypto exchange that covers more than 5,400 crypto assets. Its API v4 supports spot, margin, perpetual and delivery futures, and options trading.

Sign up for Gate
----------------

#. Create a Gate account on the website and finish account verification.
#. Set up your fund password and two-factor authentication. Gate asks for both before you can create an API key.
#. For practice, Gate also offers testnet API keys (see the testnet note below). Testnet keys only work on the testnet, and real keys do not work there.

`Open a Gate account <https://www.gate.com/>`_

Create a Gate API key
---------------------

#. Log in on the Gate website, hover over the profile icon at the top and click API Management.
#. Click Create API Key and choose API v4 Key as the key type (API v2 keys are spot only).
#. Enter a remark to name the key and bind the IP address of the machine that runs your bot.
#. Choose the account type (Classic Account, Margin Trading or Testnet), set the permissions and pick the currency pairs, then click Submit.
#. Read the risk reminder, click I accept, enter your fund password and two-factor code, and click Confirm.
#. Copy the key and secret and store them safely.

**Which permissions to turn on:** Choose Read and Write for the markets your bot trades, for example spot read/write, and futures read/write only if you trade futures. One API v4 key can hold several of these permissions. Leave withdrawals off. Gate API keys can withdraw if you allow it, and a bot never needs to move money out of your account.

.. warning::

   Never turn on withdrawals for a Gate trading bot key. Bind the key to your server's IP address when Gate lets you, keep the secret out of your code and out of Git, and delete the key if it ever leaks.

Connect Gate to LumiBot
-----------------------

The simplest way: put these lines in a ``.env`` file next to your strategy. LumiBot loads the file, sees ``TRADING_BROKER=gate`` and connects to Gate for you, so your strategy needs no broker code.

.. code-block:: bash

   TRADING_BROKER=gate
   GATE_API_KEY=your_apiKey
   GATE_API_SECRET=your_secret
   GATE_SANDBOX=true   # testnet; remove this line for your live account

LumiBot reads exactly the fields CCXT needs for Gate (``apiKey``, ``secret``). If one is missing, LumiBot stops at start-up and names the variable you still need.

You can also build the broker in code. This is handy when one script talks to more than one exchange, or when you need extra CCXT options. The keys in the config are CCXT's own credential names for Gate:

.. code-block:: python

   import os

   GATE_CONFIG = {
       "exchange_id": "gate",
       "apiKey": os.environ.get("GATE_API_KEY"),
       "secret": os.environ.get("GATE_API_SECRET"),
       "sandbox": True,  # testnet first; set False for your live account
   }

   from lumibot.brokers import Ccxt

   broker = Ccxt(GATE_CONFIG)
   # then: MyStrategy(broker=broker, ...)

Either way, LumiBot turns on CCXT's built-in rate limiting for you.

Practice on the Gate testnet
----------------------------

Gate runs a testnet. Create a separate key with the Testnet account type in API Management (futures testnet keys are made under their own TestNet tab). The testnet API lives at https://api-testnet.gateapi.io/api/v4. Set ``GATE_SANDBOX=true`` (or ``"sandbox": True`` in a code config) to use it.

CCXT sends sandbox requests to: https://api-testnet.gateapi.io/api/v4. Testnet and live accounts use different keys.

Algorithmic trading example: a simple Gate bot
----------------------------------------------

This bot buys about 50 USDT of BTC on Gate once and then holds it. It is a starting point to check that your keys, balances and orders work. If the exchange's minimum order is larger, raise the amount.

.. code-block:: python

   from lumibot.entities import Asset
   from lumibot.strategies import Strategy


   class GateBuyOnce(Strategy):
       """Buy a small amount of BTC once, then hold it."""

       def initialize(self):
           self.sleeptime = "1H"
           self.set_market("24/7")  # crypto trades all day, every day

       def on_trading_iteration(self):
           coin = Asset("BTC", asset_type=Asset.AssetType.CRYPTO)
           if self.get_position(coin) is not None:
               return  # already holding BTC
           price = self.get_last_price(coin, quote=self.quote_asset)
           if price:
               quantity = round(50 / price, 6)  # about 50 USDT worth
               order = self.create_order(coin, quantity, "buy", quote=self.quote_asset)
               self.submit_order(order)


   if __name__ == "__main__":
       # LumiBot reads TRADING_BROKER and the keys from your .env file.
       strategy = GateBuyOnce(quote_asset=Asset("USDT", asset_type=Asset.AssetType.CRYPTO))
       strategy.run_live()

Agentic trading example: an AI agent that trades on Gate
--------------------------------------------------------

Agentic trading means an AI agent reads the market and decides what to do. In this example one LumiBot agent looks at prices and your Gate account, then places the orders itself. There is no Python logic in between: you set the rules in plain English in the prompt, such as what it may trade and how big each order can be. This follows the same pattern as LumiBot's AI trading team examples.

.. code-block:: python

   from lumibot.entities import Asset
   from lumibot.strategies import Strategy


   class GateAITrader(Strategy):
       """One AI agent researches the market and places the trades itself."""

       def initialize(self):
           self.sleeptime = "4H"
           self.set_market("24/7")
           self.agents.create(
               name="trader",
               model="openai/gpt-6-luna",
               reasoning_effort="high",
               allow_trading=True,
               system_prompt=(
                   "You manage a small crypto account on Gate. "
                   "You may trade BTC and ETH against USDT (asset_type 'crypto', quote_symbol 'USDT'), or hold cash. "
                   "Before every order, call account_portfolio, account_positions and "
                   "market_last_price for that exact symbol in the same run. "
                   "Keep each order under 10% of the account value. "
                   "Explain each decision in one short paragraph."
               ),
           )

       def on_trading_iteration(self):
           self.agents["trader"].run(
               task_prompt="Review recent BTC/USDT and ETH/USDT prices and your current holdings, then decide whether to buy, sell or hold.",
               context={"exchange": "Gate", "quote": "USDT", "date": self.get_datetime().isoformat()},
           )


   if __name__ == "__main__":
       # LumiBot reads TRADING_BROKER and the keys from your .env file.
       strategy = GateAITrader(quote_asset=Asset("USDT", asset_type=Asset.AssetType.CRYPTO))
       strategy.run_live()

The agent needs a model key such as ``OPENAI_API_KEY`` in your environment. See the :doc:`AI agents quickstart <agents_quickstart>` for models, tools and memory.

Gate tips
---------

* Bind an IP address to your key. Gate keys with no IP binding accept requests from any address and expire after 90 days.
* Gate API v4 keys can be limited to certain currency pairs when you create them. If you use this, include every pair your bot trades.
* Gate rate limits are counted for each main account and each sub-account separately, so a sub-account per bot also keeps one bot from slowing another.
* CCXT also has a separate ``gateeu`` id. For an account on gate.com, use ``gate``.

Frequently asked questions
--------------------------

**Can I build a Gate trading bot in Python?**

Yes. Install LumiBot (``pip install lumibot``), set your Gate keys and use the ``gate`` CCXT exchange id as shown above.

**Does Gate have a testnet?**

Yes. Set ``GATE_SANDBOX=true`` and use keys from the Gate testnet.

**Which API permissions does a Gate bot need?**

Choose Read and Write for the markets your bot trades, for example spot read/write, and futures read/write only if you trade futures. One API v4 key can hold several of these permissions. Leave withdrawals off. Gate API keys can withdraw if you allow it, and a bot never needs to move money out of your account.

**Can an AI agent trade on Gate by itself?**

Yes. The agentic example above gives one agent permission to trade. You control what it may trade and how much through its prompt.

**Can I trade Gate perpetual futures with LumiBot?**

CCXT lists perpetual swaps for this exchange. Use the full contract symbol, such as ``BTC/USDT:USDT``.

**Is LumiBot free?**

Yes. LumiBot is open source on GitHub at https://github.com/Lumiwealth/lumibot. You pay only your exchange's trading fees and, for AI agents, your model provider.
