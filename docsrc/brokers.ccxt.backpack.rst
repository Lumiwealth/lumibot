What is Backpack?
-----------------

Backpack is a crypto exchange and wallet. It offers spot trading and perpetual futures in one margin system, plus lending, borrowing and sub-accounts.

Sign up for Backpack
--------------------

#. Create a Backpack account with your email, or sign up with Google or Apple where Backpack offers it.
#. Finish identity verification (KYC). Backpack says most checks take a few minutes to a few hours, and a manual review can take 1 to 3 days.
#. Turn on two-factor authentication. Backpack has no testnet, so plan to test with a very small amount.

`Open a Backpack account <https://backpack.exchange/>`_

Create a Backpack API key
-------------------------

#. Log in to Backpack on the website. Backpack only lets you create API keys on the web, not in the app.
#. Go to Settings, then API Keys (https://backpack.exchange/settings/api-keys), and click New API Key.
#. Enter a name for the key and choose the sub-account the bot should trade in.
#. Leave the Public Key field blank. Backpack recommends this for most people.
#. Do not press the Read Only button, because a read-only key cannot place orders. Click Create.
#. Save the API key and API secret somewhere safe right away.

**Which permissions to turn on:** A normal Backpack key can read your account and trade. The Read Only button limits a key to view-only access, so leave it off for a trading bot. Leave withdrawals off: Backpack says API withdrawals need extra security setup with two-factor authentication, and a bot never needs to move money out of your account.

.. warning::

   Never turn on withdrawals for a Backpack trading bot key. Bind the key to your server's IP address when Backpack lets you, keep the secret out of your code and out of Git, and delete the key if it ever leaks.

Connect Backpack to LumiBot
---------------------------

The simplest way: put these lines in a ``.env`` file next to your strategy. LumiBot loads the file, sees ``TRADING_BROKER=backpack`` and connects to Backpack for you, so your strategy needs no broker code.

.. code-block:: bash

   TRADING_BROKER=backpack
   BACKPACK_API_KEY=your_apiKey
   BACKPACK_API_SECRET=your_secret

LumiBot reads exactly the fields CCXT needs for Backpack (``apiKey``, ``secret``). If one is missing, LumiBot stops at start-up and names the variable you still need.

You can also build the broker in code. This is handy when one script talks to more than one exchange, or when you need extra CCXT options. The keys in the config are CCXT's own credential names for Backpack:

.. code-block:: python

   import os

   BACKPACK_CONFIG = {
       "exchange_id": "backpack",
       "apiKey": os.environ.get("BACKPACK_API_KEY"),
       "secret": os.environ.get("BACKPACK_API_SECRET"),
       "sandbox": False,  # live connection
   }

   from lumibot.brokers import Ccxt

   broker = Ccxt(BACKPACK_CONFIG)
   # then: MyStrategy(broker=broker, ...)

Either way, LumiBot turns on CCXT's built-in rate limiting for you.

Testing on Backpack
-------------------

Backpack has no sandbox, and CCXT lists no test URL for it, so test with a very small amount. With environment variables, leave ``BACKPACK_SANDBOX`` unset. In a code config, set ``"sandbox": False``.

Algorithmic trading example: a simple Backpack bot
--------------------------------------------------

This bot buys about 50 USDC of BTC on Backpack once and then holds it. It is a starting point to check that your keys, balances and orders work. If the exchange's minimum order is larger, raise the amount.

.. code-block:: python

   from lumibot.entities import Asset
   from lumibot.strategies import Strategy


   class BackpackBuyOnce(Strategy):
       """Buy a small amount of BTC once, then hold it."""

       def initialize(self):
           self.sleeptime = "1H"
           self.set_market("24/7")  # crypto trades all day, every day

       def on_trading_iteration(self):
           coin = Asset("BTC", asset_type=Asset.AssetType.CRYPTO)
           if self.get_position(coin) is not None:
               return  # already holding BTC
           price = self.get_last_price(coin, quote=self.quote_asset)
           if price:
               quantity = round(50 / price, 6)  # about 50 USDC worth
               order = self.create_order(coin, quantity, "buy", quote=self.quote_asset)
               self.submit_order(order)


   if __name__ == "__main__":
       # LumiBot reads TRADING_BROKER and the keys from your .env file.
       strategy = BackpackBuyOnce(quote_asset=Asset("USDC", asset_type=Asset.AssetType.CRYPTO))
       strategy.run_live()

Agentic trading example: an AI agent that trades on Backpack
------------------------------------------------------------

Agentic trading means an AI agent reads the market and decides what to do. In this example one LumiBot agent looks at prices and your Backpack account, then places the orders itself. There is no Python logic in between: you set the rules in plain English in the prompt, such as what it may trade and how big each order can be. This follows the same pattern as LumiBot's AI trading team examples.

.. code-block:: python

   from lumibot.entities import Asset
   from lumibot.strategies import Strategy


   class BackpackAITrader(Strategy):
       """One AI agent researches the market and places the trades itself."""

       def initialize(self):
           self.sleeptime = "4H"
           self.set_market("24/7")
           self.agents.create(
               name="trader",
               model="openai/gpt-6-luna",
               reasoning_effort="high",
               allow_trading=True,
               system_prompt=(
                   "You manage a small crypto account on Backpack. "
                   "You may trade BTC and ETH against USDC (asset_type 'crypto', quote_symbol 'USDC'), or hold cash. "
                   "Before every order, call account_portfolio, account_positions and "
                   "market_last_price for that exact symbol in the same run. "
                   "Keep each order under 10% of the account value. "
                   "Explain each decision in one short paragraph."
               ),
           )

       def on_trading_iteration(self):
           self.agents["trader"].run(
               task_prompt="Review recent BTC/USDC and ETH/USDC prices and your current holdings, then decide whether to buy, sell or hold.",
               context={"exchange": "Backpack", "quote": "USDC", "date": self.get_datetime().isoformat()},
           )


   if __name__ == "__main__":
       # LumiBot reads TRADING_BROKER and the keys from your .env file.
       strategy = BackpackAITrader(quote_asset=Asset("USDC", asset_type=Asset.AssetType.CRYPTO))
       strategy.run_live()

The agent needs a model key such as ``OPENAI_API_KEY`` in your environment. See the :doc:`AI agents quickstart <agents_quickstart>` for models, tools and memory.

Perpetual futures example on Backpack
-------------------------------------

Backpack also lists perpetual swaps. This bot opens one small long position in ``BTC/USDC:USDC`` worth about 50 USDC and then holds it. LumiBot treats a perpetual as ``asset_type="crypto_future"`` and sizes it in contracts, the same model as LumiBot's Bitunix futures broker. Contract symbols can differ by exchange, so check the symbol in ``self.broker.api.markets`` before going live. In hedge mode, add ``position_side="long"`` to ``create_order``.

.. code-block:: python

   from lumibot.entities import Asset
   from lumibot.strategies import Strategy


   class BackpackOpenOneLong(Strategy):
       """Open one small long BTC perpetual position, then hold it."""

       def initialize(self):
           self.sleeptime = "1H"
           self.set_market("24/7")  # crypto trades all day, every day

       def on_trading_iteration(self):
           # The full CCXT symbol keeps the settlement currency clear.
           contract = self.broker.get_asset("BTC/USDC:USDC")
           if self.get_position(contract) is not None:
               return  # already holding the position
           price = self.get_last_price(contract)
           if price:
               # Each contract covers contract.multiplier BTC; size the order to about 50 USDC.
               quantity = round(50 / (price * contract.multiplier), 6)
               order = self.create_order(contract, quantity, "buy")
               self.submit_order(order)


   if __name__ == "__main__":
       # LumiBot reads TRADING_BROKER and the keys from your .env file.
       strategy = BackpackOpenOneLong(quote_asset=Asset("USDC", asset_type=Asset.AssetType.CRYPTO))
       strategy.run_live()

Fees and partner IDs on Backpack
--------------------------------

You pay Backpack's normal trading fees. CCXT, the library underneath, normally tags Backpack orders with its own partner ID. LumiBot removes that tag. LumiBot may attach its own exchange partner ID instead. That costs you nothing extra. LumiBot never adds an extra builder fee unless one is turned on, and it logs a warning when one is.

Backpack tips
-------------

* Backpack markets are priced in USDC, so use ``USDC`` as your quote asset (for example ``BTC/USDC``). Perpetuals use the CCXT form ``BTC/USDC:USDC``. Backpack's own API writes these as ``BTC_USDC`` and ``BTC_USDC_PERP``; CCXT converts them for you.
* Each API key belongs to one sub-account. Backpack sub-accounts each have their own margin, positions and risk settings, so a separate sub-account per bot keeps bot trades apart from manual trades.
* Backpack applies rate limits per sub-account: about 2,000 requests per minute on normal REST endpoints, and 30 per minute on historical data such as candles. Too many requests return HTTP 429.
* Backpack signs API requests with an ED25519 key pair, so its keys look different from most exchanges. Copy the API key and API secret exactly as Backpack shows them.

Frequently asked questions
--------------------------

**Can I build a Backpack trading bot in Python?**

Yes. Install LumiBot (``pip install lumibot``), set your Backpack keys and use the ``backpack`` CCXT exchange id as shown above.

**Does Backpack have a testnet?**

No testnet is set up for Backpack in LumiBot. Start with a small amount, and in a code config set ``"sandbox": False``.

**Which API permissions does a Backpack bot need?**

A normal Backpack key can read your account and trade. The Read Only button limits a key to view-only access, so leave it off for a trading bot. Leave withdrawals off: Backpack says API withdrawals need extra security setup with two-factor authentication, and a bot never needs to move money out of your account.

**Can an AI agent trade on Backpack by itself?**

Yes. The agentic example above gives one agent permission to trade. You control what it may trade and how much through its prompt.

**Can I trade Backpack perpetual futures with LumiBot?**

CCXT lists perpetual swaps for this exchange. Use the full contract symbol, such as ``BTC/USDT:USDT``.

**Is LumiBot free?**

Yes. LumiBot is open source on GitHub at https://github.com/Lumiwealth/lumibot. You pay only your exchange's trading fees and, for AI agents, your model provider.
