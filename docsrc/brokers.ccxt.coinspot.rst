What is CoinSpot?
-----------------

CoinSpot is a crypto exchange where you buy, sell and swap cryptocurrencies. Its markets are priced mostly in AUD, with some USDT markets, and LumiBot uses it for spot trading.

Sign up for CoinSpot
--------------------

#. Register on coinspot.com.au or in the CoinSpot app with your email address and a password, then confirm your email.
#. Verify your account: enter your personal details and upload an identity document.
#. Turn on app based 2FA: My Account menu, Security, Two-Factor Authentication (2FA), Enable Two Factor Authentication. CoinSpot needs it to create an API key.

`Open a CoinSpot account <https://www.coinspot.com.au>`_

Create a CoinSpot API key
-------------------------

#. Log in and open the My Account menu, then API (https://www.coinspot.com.au/my/api).
#. Select Generate New API Key and enter a name for the key.
#. Choose the API Key Type (see below), enter your 2FA token and select Create API Key.
#. Open the confirmation email and click the link in the same browser and device you are using.
#. Tap View Secret (One Time Only) and copy the secret. It disappears once you leave the API page.

**Which permissions to turn on:** CoinSpot has two key types: Read Only and Full Access. A trading bot needs Full Access, because a Read Only key cannot place orders. Coin withdrawals must be turned on separately in the API key options, so leave that option off. A bot never needs to move coins out of your account.

.. warning::

   Never turn on withdrawals for a CoinSpot trading bot key. Bind the key to your server's IP address when CoinSpot lets you, keep the secret out of your code and out of Git, and delete the key if it ever leaks.

Connect CoinSpot to LumiBot
---------------------------

The simplest way: put these lines in a ``.env`` file next to your strategy. LumiBot loads the file, sees ``TRADING_BROKER=coinspot`` and connects to CoinSpot for you, so your strategy needs no broker code.

.. code-block:: bash

   TRADING_BROKER=coinspot
   COINSPOT_API_KEY=your_apiKey
   COINSPOT_API_SECRET=your_secret

LumiBot reads exactly the fields CCXT needs for CoinSpot (``apiKey``, ``secret``). If one is missing, LumiBot stops at start-up and names the variable you still need.

You can also build the broker in code. This is handy when one script talks to more than one exchange, or when you need extra CCXT options. The keys in the config are CCXT's own credential names for CoinSpot:

.. code-block:: python

   import os

   COINSPOT_CONFIG = {
       "exchange_id": "coinspot",
       "apiKey": os.environ.get("COINSPOT_API_KEY"),
       "secret": os.environ.get("COINSPOT_API_SECRET"),
       "sandbox": False,  # no sandbox for this exchange
   }

   from lumibot.brokers import Ccxt

   broker = Ccxt(COINSPOT_CONFIG)
   # then: MyStrategy(broker=broker, ...)

Either way, LumiBot turns on CCXT's built-in rate limiting for you.

Testing on CoinSpot
-------------------

CoinSpot has no sandbox or testnet. Test with a very small amount on your real account, leave ``COINSPOT_SANDBOX`` unset, and in a code config set ``"sandbox": False``.

Algorithmic trading example: a simple CoinSpot bot
--------------------------------------------------

This bot buys about 75 AUD of BTC on CoinSpot once and then holds it. It is a starting point to check that your keys, balances and orders work. If the exchange's minimum order is larger, raise the amount. CoinSpot accepts only limit orders through CCXT, so the example places a limit order just above the last price.

.. code-block:: python

   from lumibot.entities import Asset
   from lumibot.strategies import Strategy


   class CoinspotBuyOnce(Strategy):
       """Buy a small amount of BTC once, then hold it."""

       def initialize(self):
           self.sleeptime = "1H"
           self.set_market("24/7")  # crypto trades all day, every day

       def on_trading_iteration(self):
           coin = Asset("BTC", asset_type=Asset.AssetType.CRYPTO)
           if self.get_position(coin) is not None:
               return  # already holding BTC
           price = self.get_last_price(coin, quote=self.quote_asset)
           if price:
               quantity = round(75 / price, 6)  # about 75 AUD worth
               # This exchange takes only limit orders through CCXT.
               order = self.create_order(coin, quantity, "buy", limit_price=price * 1.002, quote=self.quote_asset)
               self.submit_order(order)


   if __name__ == "__main__":
       # LumiBot reads TRADING_BROKER and the keys from your .env file.
       strategy = CoinspotBuyOnce(quote_asset=Asset("AUD", asset_type=Asset.AssetType.CRYPTO))
       strategy.run_live()

Agentic trading example: an AI agent that trades on CoinSpot
------------------------------------------------------------

Agentic trading means an AI agent reads the market and decides what to do. In this example one LumiBot agent looks at prices and your CoinSpot account, then places the orders itself. There is no Python logic in between: you set the rules in plain English in the prompt, such as what it may trade and how big each order can be. This follows the same pattern as LumiBot's AI trading team examples.

.. code-block:: python

   from lumibot.entities import Asset
   from lumibot.strategies import Strategy


   class CoinspotAITrader(Strategy):
       """One AI agent researches the market and places the trades itself."""

       def initialize(self):
           self.sleeptime = "4H"
           self.set_market("24/7")
           self.agents.create(
               name="trader",
               model="openai/gpt-6-luna",
               reasoning_effort="high",
               allow_trading=True,
               system_prompt=(
                   "You manage a small crypto account on CoinSpot. "
                   "You may trade BTC and ETH against AUD (asset_type 'crypto', quote_symbol 'AUD'), or hold cash. "
                   "Before every order, call account_portfolio, account_positions and "
                   "market_last_price for that exact symbol in the same run. "
                   "Keep each order under 10% of the account value. "
                   "Explain each decision in one short paragraph."
               ),
           )

       def on_trading_iteration(self):
           self.agents["trader"].run(
               task_prompt="Review recent BTC/AUD and ETH/AUD prices and your current holdings, then decide whether to buy, sell or hold.",
               context={"exchange": "CoinSpot", "quote": "AUD", "date": self.get_datetime().isoformat()},
           )


   if __name__ == "__main__":
       # LumiBot reads TRADING_BROKER and the keys from your .env file.
       strategy = CoinspotAITrader(quote_asset=Asset("AUD", asset_type=Asset.AssetType.CRYPTO))
       strategy.run_live()

The agent needs a model key such as ``OPENAI_API_KEY`` in your environment. See the :doc:`AI agents quickstart <agents_quickstart>` for models, tools and memory.

CoinSpot tips
-------------

* In CCXT, CoinSpot supports limit orders only (no market orders). Use limit orders in your strategy, for example ``BTC/AUD`` at a set price.
* CoinSpot allows 1000 API requests per minute.
* CoinSpot help pages warn to give third-party tools (such as tax software) a Read Only key, never Full Access. Make a separate Full Access key just for your bot.
* If you lose the secret, delete the key with Delete API Key and generate a new one.

Frequently asked questions
--------------------------

**Can I build a CoinSpot trading bot in Python?**

Yes. Install LumiBot (``pip install lumibot``), set your CoinSpot keys and use the ``coinspot`` CCXT exchange id as shown above.

**Does CoinSpot have a testnet?**

No testnet is set up for CoinSpot in LumiBot. Start with a small amount, and in a code config set ``"sandbox": False``.

**Which API permissions does a CoinSpot bot need?**

CoinSpot has two key types: Read Only and Full Access. A trading bot needs Full Access, because a Read Only key cannot place orders. Coin withdrawals must be turned on separately in the API key options, so leave that option off. A bot never needs to move coins out of your account.

**Can an AI agent trade on CoinSpot by itself?**

Yes. The agentic example above gives one agent permission to trade. You control what it may trade and how much through its prompt.

**Can I trade CoinSpot perpetual futures with LumiBot?**

CCXT does not list perpetual swaps for CoinSpot, so use spot markets.

**Is LumiBot free?**

Yes. LumiBot is open source on GitHub at https://github.com/Lumiwealth/lumibot. You pay only your exchange's trading fees and, for AI agents, your model provider.
