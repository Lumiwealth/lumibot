What is Binance?
----------------

Binance is one of the largest crypto exchanges. It offers spot trading, margin, futures and more, with hundreds of coins to trade.

Sign up for Binance
-------------------

#. Create a Binance account on the website or app.
#. Finish identity verification and turn on two-factor authentication (2FA). Binance requires both before you can make an API key, and also a first deposit of any amount to your Spot Wallet.
#. For practice, log in to the Binance Spot Test Network at https://testnet.binance.vision and make a separate test API key there. Test funds are not real and test keys only work on the test network.

`Open a Binance account <https://accounts.binance.com/en/register>`_

Create a Binance API key
------------------------

#. Log in and go to Profile, then API Management (https://www.binance.com/en/usercenter/settings/api-management).
#. Click Create API.
#. Pick System-generated (you get an API key and a Secret Key). Self-generated keys use Ed25519 or RSA and need your own key pair.
#. Enter a label for the key, then confirm with your 2FA device or passkey.
#. Click Edit restrictions, add your bot's IP address, and turn on the trading permission (see below).
#. Copy the API key and Secret Key and store them safely.

**Which permissions to turn on:** Turn on Enable Reading and Enable Spot & Margin Trading. Leave Enable Withdrawals off. Binance only lets a system-generated key trade if you add an IP address restriction. Without an IP list the key can only read.

.. warning::

   Never turn on withdrawals for a Binance trading bot key. Bind the key to your server's IP address when Binance lets you, keep the secret out of your code and out of Git, and delete the key if it ever leaks.

Connect Binance to LumiBot
--------------------------

The simplest way: put these lines in a ``.env`` file next to your strategy. LumiBot loads the file, sees ``TRADING_BROKER=binance`` and connects to Binance for you, so your strategy needs no broker code.

.. code-block:: bash

   TRADING_BROKER=binance
   BINANCE_API_KEY=your_apiKey
   BINANCE_API_SECRET=your_secret
   BINANCE_SANDBOX=true   # testnet; remove this line for your live account

LumiBot reads exactly the fields CCXT needs for Binance (``apiKey``, ``secret``). If one is missing, LumiBot stops at start-up and names the variable you still need.

You can also build the broker in code. This is handy when one script talks to more than one exchange, or when you need extra CCXT options. The keys in the config are CCXT's own credential names for Binance:

.. code-block:: python

   import os

   BINANCE_CONFIG = {
       "exchange_id": "binance",
       "apiKey": os.environ.get("BINANCE_API_KEY"),
       "secret": os.environ.get("BINANCE_API_SECRET"),
       "sandbox": True,  # testnet first; set False for your live account
   }

   from lumibot.brokers import Ccxt

   broker = Ccxt(BINANCE_CONFIG)
   # then: MyStrategy(broker=broker, ...)

Either way, LumiBot turns on CCXT's built-in rate limiting for you.

Practice on the Binance testnet
-------------------------------

Binance runs a Spot Test Network at https://testnet.binance.vision with its own keys and free test funds. It is reset about once a month. Set ``BINANCE_SANDBOX=true`` (or ``"sandbox": True`` in a code config) to use it.

CCXT sends sandbox requests to: https://testnet.binancefuture.com/dapi/v1, https://testnet.binancefuture.com/dapi/v2. Testnet and live accounts use different keys.

Algorithmic trading example: a simple Binance bot
-------------------------------------------------

This bot buys about 50 USDT of BTC on Binance once and then holds it. It is a starting point to check that your keys, balances and orders work. If the exchange's minimum order is larger, raise the amount.

.. code-block:: python

   from lumibot.entities import Asset
   from lumibot.strategies import Strategy


   class BinanceBuyOnce(Strategy):
       """Buy a small amount of BTC once, then hold it."""

       def initialize(self):
           self.sleeptime = "1H"
           self.set_market("24/7")  # crypto trades all day, every day

       def on_trading_iteration(self):
           coin = Asset("BTC", asset_type=Asset.AssetType.CRYPTO)
           if self.get_position(coin) is not None:
               return  # already holding BTC
           price = self.get_last_price(coin, quote=self.quote_asset)
           if price:
               quantity = round(50 / price, 6)  # about 50 USDT worth
               order = self.create_order(coin, quantity, "buy", quote=self.quote_asset)
               self.submit_order(order)


   if __name__ == "__main__":
       # LumiBot reads TRADING_BROKER and the keys from your .env file.
       strategy = BinanceBuyOnce(quote_asset=Asset("USDT", asset_type=Asset.AssetType.CRYPTO))
       strategy.run_live()

Agentic trading example: an AI agent that trades on Binance
-----------------------------------------------------------

Agentic trading means an AI agent reads the market and decides what to do. In this example one LumiBot agent looks at prices and your Binance account, then places the orders itself. There is no Python logic in between: you set the rules in plain English in the prompt, such as what it may trade and how big each order can be. This follows the same pattern as LumiBot's AI trading team examples.

.. code-block:: python

   from lumibot.entities import Asset
   from lumibot.strategies import Strategy


   class BinanceAITrader(Strategy):
       """One AI agent researches the market and places the trades itself."""

       def initialize(self):
           self.sleeptime = "4H"
           self.set_market("24/7")
           self.agents.create(
               name="trader",
               model="openai/gpt-6-luna",
               reasoning_effort="high",
               allow_trading=True,
               system_prompt=(
                   "You manage a small crypto account on Binance. "
                   "You may trade BTC and ETH against USDT (asset_type 'crypto', quote_symbol 'USDT'), or hold cash. "
                   "Before every order, call account_portfolio, account_positions and "
                   "market_last_price for that exact symbol in the same run. "
                   "Keep each order under 10% of the account value. "
                   "Explain each decision in one short paragraph."
               ),
           )

       def on_trading_iteration(self):
           self.agents["trader"].run(
               task_prompt="Review recent BTC/USDT and ETH/USDT prices and your current holdings, then decide whether to buy, sell or hold.",
               context={"exchange": "Binance", "quote": "USDT", "date": self.get_datetime().isoformat()},
           )


   if __name__ == "__main__":
       # LumiBot reads TRADING_BROKER and the keys from your .env file.
       strategy = BinanceAITrader(quote_asset=Asset("USDT", asset_type=Asset.AssetType.CRYPTO))
       strategy.run_live()

The agent needs a model key such as ``OPENAI_API_KEY`` in your environment. See the :doc:`AI agents quickstart <agents_quickstart>` for models, tools and memory.

Binance tips
------------

* Always add an IP whitelist. Binance says a key with no IP list keeps only read access, and trading permission without an IP list used to expire after 30 days.
* A key made before you opened your Futures account cannot get Futures permission. Open Futures first, then create the key, if you plan to trade futures.
* CCXT uses separate ids for some Binance products: ``binanceusdm`` for USDT-margined futures, ``binancecoinm`` for coin-margined futures and ``binanceus`` for the separate Binance.US exchange. Use ``binance`` for spot.
* The Spot Test Network only has the ``/api`` endpoints, not ``/sapi``, so wallet and sub-account calls do not work there.

Frequently asked questions
--------------------------

**Can I build a Binance trading bot in Python?**

Yes. Install LumiBot (``pip install lumibot``), set your Binance keys and use the ``binance`` CCXT exchange id as shown above.

**Does Binance have a testnet?**

Yes. Set ``BINANCE_SANDBOX=true`` and use keys from the Binance testnet.

**Which API permissions does a Binance bot need?**

Turn on Enable Reading and Enable Spot & Margin Trading. Leave Enable Withdrawals off. Binance only lets a system-generated key trade if you add an IP address restriction. Without an IP list the key can only read.

**Can an AI agent trade on Binance by itself?**

Yes. The agentic example above gives one agent permission to trade. You control what it may trade and how much through its prompt.

**Can I trade Binance perpetual futures with LumiBot?**

CCXT lists perpetual swaps for this exchange. Use the full contract symbol, such as ``BTC/USDT:USDT``.

**Is LumiBot free?**

Yes. LumiBot is open source on GitHub at https://github.com/Lumiwealth/lumibot. You pay only your exchange's trading fees and, for AI agents, your model provider.
