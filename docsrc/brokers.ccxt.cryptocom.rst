What is Crypto.com?
-------------------

Crypto.com Exchange is the trading platform from Crypto.com. It says you can trade 350+ assets, and its API covers spot and derivatives trading.

Sign up for Crypto.com
----------------------

#. Create a Crypto.com Exchange account and finish the sign-up checks it asks for.
#. Turn on two-factor authentication. You need the 2FA code to create an API key.
#. Crypto.com's test site (UAT) is invite only for institutional accounts, so most people test with a very small amount.

`Open a Crypto.com account <https://crypto.com/exchange>`_

Create a Crypto.com API key
---------------------------

#. Log in to the Crypto.com Exchange website.
#. Click your profile in the top right, then Manage Account, then API Management.
#. Choose Create a new API key, give it a label and enter your 2FA code.
#. Turn on Enable Trading and add the IP address of the machine that runs your bot.
#. Copy the secret key right away. Crypto.com shows it only when the key is created.

**Which permissions to turn on:** New keys start with Can Read only. Add Enable Trading. Leave Enable Withdrawal off. Crypto.com requires an IP whitelist as soon as you turn on trading or withdrawals.

.. warning::

   Never turn on withdrawals for a Crypto.com trading bot key. Bind the key to your server's IP address when Crypto.com lets you, keep the secret out of your code and out of Git, and delete the key if it ever leaks.

Connect Crypto.com to LumiBot
-----------------------------

The simplest way: put these lines in a ``.env`` file next to your strategy. LumiBot loads the file, sees ``TRADING_BROKER=cryptocom`` and connects to Crypto.com for you, so your strategy needs no broker code.

.. code-block:: bash

   TRADING_BROKER=cryptocom
   CRYPTOCOM_API_KEY=your_apiKey
   CRYPTOCOM_API_SECRET=your_secret
   CRYPTOCOM_SANDBOX=true   # testnet; remove this line for your live account

LumiBot reads exactly the fields CCXT needs for Crypto.com (``apiKey``, ``secret``). If one is missing, LumiBot stops at start-up and names the variable you still need.

You can also build the broker in code. This is handy when one script talks to more than one exchange, or when you need extra CCXT options. The keys in the config are CCXT's own credential names for Crypto.com:

.. code-block:: python

   import os

   CRYPTOCOM_CONFIG = {
       "exchange_id": "cryptocom",
       "apiKey": os.environ.get("CRYPTOCOM_API_KEY"),
       "secret": os.environ.get("CRYPTOCOM_API_SECRET"),
       "sandbox": True,  # testnet first; set False for your live account
   }

   from lumibot.brokers import Ccxt

   broker = Ccxt(CRYPTOCOM_CONFIG)
   # then: MyStrategy(broker=broker, ...)

Either way, LumiBot turns on CCXT's built-in rate limiting for you.

Practice on the Crypto.com testnet
----------------------------------

Crypto.com runs a UAT sandbox at https://uat-api.3ona.co/exchange/v1, but access is by invitation only for institutional accounts. If you have access, set ``CRYPTOCOM_SANDBOX=true`` (or ``"sandbox": True`` in a code config) to use it. Otherwise test with a very small amount and leave the sandbox off.

CCXT sends sandbox requests to: https://uat-api.3ona.co/exchange/v1, https://uat-api.3ona.co/v2. Testnet and live accounts use different keys.

Algorithmic trading example: a simple Crypto.com bot
----------------------------------------------------

This bot buys about 50 USD of BTC on Crypto.com once and then holds it. It is a starting point to check that your keys, balances and orders work. If the exchange's minimum order is larger, raise the amount.

.. code-block:: python

   from lumibot.entities import Asset
   from lumibot.strategies import Strategy


   class CryptocomBuyOnce(Strategy):
       """Buy a small amount of BTC once, then hold it."""

       def initialize(self):
           self.sleeptime = "1H"
           self.set_market("24/7")  # crypto trades all day, every day

       def on_trading_iteration(self):
           coin = Asset("BTC", asset_type=Asset.AssetType.CRYPTO)
           if self.get_position(coin) is not None:
               return  # already holding BTC
           price = self.get_last_price(coin, quote=self.quote_asset)
           if price:
               quantity = round(50 / price, 6)  # about 50 USD worth
               order = self.create_order(coin, quantity, "buy", quote=self.quote_asset)
               self.submit_order(order)


   if __name__ == "__main__":
       # LumiBot reads TRADING_BROKER and the keys from your .env file.
       strategy = CryptocomBuyOnce(quote_asset=Asset("USD", asset_type=Asset.AssetType.CRYPTO))
       strategy.run_live()

Agentic trading example: an AI agent that trades on Crypto.com
--------------------------------------------------------------

Agentic trading means an AI agent reads the market and decides what to do. In this example one LumiBot agent looks at prices and your Crypto.com account, then places the orders itself. There is no Python logic in between: you set the rules in plain English in the prompt, such as what it may trade and how big each order can be. This follows the same pattern as LumiBot's AI trading team examples.

.. code-block:: python

   from lumibot.entities import Asset
   from lumibot.strategies import Strategy


   class CryptocomAITrader(Strategy):
       """One AI agent researches the market and places the trades itself."""

       def initialize(self):
           self.sleeptime = "4H"
           self.set_market("24/7")
           self.agents.create(
               name="trader",
               model="openai/gpt-6-luna",
               reasoning_effort="high",
               allow_trading=True,
               system_prompt=(
                   "You manage a small crypto account on Crypto.com. "
                   "You may trade BTC and ETH against USD (asset_type 'crypto', quote_symbol 'USD'), or hold cash. "
                   "Before every order, call account_portfolio, account_positions and "
                   "market_last_price for that exact symbol in the same run. "
                   "Keep each order under 10% of the account value. "
                   "Explain each decision in one short paragraph."
               ),
           )

       def on_trading_iteration(self):
           self.agents["trader"].run(
               task_prompt="Review recent BTC/USD and ETH/USD prices and your current holdings, then decide whether to buy, sell or hold.",
               context={"exchange": "Crypto.com", "quote": "USD", "date": self.get_datetime().isoformat()},
           )


   if __name__ == "__main__":
       # LumiBot reads TRADING_BROKER and the keys from your .env file.
       strategy = CryptocomAITrader(quote_asset=Asset("USD", asset_type=Asset.AssetType.CRYPTO))
       strategy.run_live()

The agent needs a model key such as ``OPENAI_API_KEY`` in your environment. See the :doc:`AI agents quickstart <agents_quickstart>` for models, tools and memory.

Perpetual futures example on Crypto.com
---------------------------------------

Crypto.com also lists perpetual swaps. This bot opens one small long position in ``BTC/USD:USD`` worth about 50 USD and then holds it. LumiBot treats a perpetual as ``asset_type="crypto_future"`` and sizes it in contracts, the same model as LumiBot's Bitunix futures broker. Contract symbols can differ by exchange, so check the symbol in ``self.broker.api.markets`` before going live. In hedge mode, add ``position_side="long"`` to ``create_order``.

.. code-block:: python

   from lumibot.entities import Asset
   from lumibot.strategies import Strategy


   class CryptocomOpenOneLong(Strategy):
       """Open one small long BTC perpetual position, then hold it."""

       def initialize(self):
           self.sleeptime = "1H"
           self.set_market("24/7")  # crypto trades all day, every day

       def on_trading_iteration(self):
           # The full CCXT symbol keeps the settlement currency clear.
           contract = self.broker.get_asset("BTC/USD:USD")
           if self.get_position(contract) is not None:
               return  # already holding the position
           price = self.get_last_price(contract)
           if price:
               # Each contract covers contract.multiplier BTC; size the order to about 50 USD.
               quantity = round(50 / (price * contract.multiplier), 6)
               order = self.create_order(contract, quantity, "buy")
               self.submit_order(order)


   if __name__ == "__main__":
       # LumiBot reads TRADING_BROKER and the keys from your .env file.
       strategy = CryptocomOpenOneLong(quote_asset=Asset("USD", asset_type=Asset.AssetType.CRYPTO))
       strategy.run_live()

Fees and partner IDs on Crypto.com
----------------------------------

You pay Crypto.com's normal trading fees. CCXT, the library underneath, normally tags Crypto.com orders with its own partner ID. LumiBot removes that tag. LumiBot may attach its own exchange partner ID instead. That costs you nothing extra. LumiBot never adds an extra builder fee unless one is turned on, and it logs a warning when one is.

Crypto.com tips
---------------

* Use an Exchange API key. The Agent Key in the Crypto.com App is a different product for AI agents and is not the Exchange API key CCXT uses.
* If you lose the secret key, create a new API key. Crypto.com cannot show it again.
* Spot pairs look like ``BTC/USD``. Crypto.com perpetuals use the full CCXT form, for example ``BTC/USD:USD``.

Frequently asked questions
--------------------------

**Can I build a Crypto.com trading bot in Python?**

Yes. Install LumiBot (``pip install lumibot``), set your Crypto.com keys and use the ``cryptocom`` CCXT exchange id as shown above.

**Does Crypto.com have a testnet?**

Yes. Set ``CRYPTOCOM_SANDBOX=true`` and use keys from the Crypto.com testnet.

**Which API permissions does a Crypto.com bot need?**

New keys start with Can Read only. Add Enable Trading. Leave Enable Withdrawal off. Crypto.com requires an IP whitelist as soon as you turn on trading or withdrawals.

**Can an AI agent trade on Crypto.com by itself?**

Yes. The agentic example above gives one agent permission to trade. You control what it may trade and how much through its prompt.

**Can I trade Crypto.com perpetual futures with LumiBot?**

CCXT lists perpetual swaps for this exchange. Use the full contract symbol, such as ``BTC/USDT:USDT``.

**Is LumiBot free?**

Yes. LumiBot is open source on GitHub at https://github.com/Lumiwealth/lumibot. You pay only your exchange's trading fees and, for AI agents, your model provider.
