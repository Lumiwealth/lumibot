What is Poloniex?
-----------------

Poloniex is a crypto exchange. Its API covers spot trading and futures (perpetual contracts), and LumiBot uses the spot API.

Sign up for Poloniex
--------------------

#. Create a Poloniex account at https://www.poloniex.com/signup and confirm your email.
#. Finish any identity checks Poloniex asks for.
#. Turn on two-factor authentication (2FA). Poloniex asks for your 2FA code when you turn on the API and again when you create a key.

`Open a Poloniex account <https://www.poloniex.com/signup>`_

Create a Poloniex API key
-------------------------

#. Log in and open the spot API key page in your profile settings (https://www.poloniex.com/profile/settings/spot-api-key).
#. If the API is not on yet, click Enable API, enter your 2FA code and confirm with the email Poloniex sends. The email link expires in 15 minutes.
#. Click the button to create a new key and enter your 2FA code again.
#. Confirm the new key from the second email Poloniex sends.
#. Poloniex then shows your API key and secret. Copy both right away and keep them somewhere safe.

**Which permissions to turn on:** The key needs to read your account and trade. Leave withdrawals off. Poloniex turns withdrawals off by default because API withdrawals skip 2FA and email checks, and a bot never needs to move money out of your account.

.. warning::

   Never turn on withdrawals for a Poloniex trading bot key. Bind the key to your server's IP address when Poloniex lets you, keep the secret out of your code and out of Git, and delete the key if it ever leaks.

Connect Poloniex to LumiBot
---------------------------

The simplest way: put these lines in a ``.env`` file next to your strategy. LumiBot loads the file, sees ``TRADING_BROKER=poloniex`` and connects to Poloniex for you, so your strategy needs no broker code.

.. code-block:: bash

   TRADING_BROKER=poloniex
   POLONIEX_API_KEY=your_apiKey
   POLONIEX_API_SECRET=your_secret

LumiBot reads exactly the fields CCXT needs for Poloniex (``apiKey``, ``secret``). If one is missing, LumiBot stops at start-up and names the variable you still need.

You can also build the broker in code. This is handy when one script talks to more than one exchange, or when you need extra CCXT options. The keys in the config are CCXT's own credential names for Poloniex:

.. code-block:: python

   import os

   POLONIEX_CONFIG = {
       "exchange_id": "poloniex",
       "apiKey": os.environ.get("POLONIEX_API_KEY"),
       "secret": os.environ.get("POLONIEX_API_SECRET"),
       "sandbox": False,  # no sandbox for this exchange
   }

   from lumibot.brokers import Ccxt

   broker = Ccxt(POLONIEX_CONFIG)
   # then: MyStrategy(broker=broker, ...)

Either way, LumiBot turns on CCXT's built-in rate limiting for you.

Testing on Poloniex
-------------------

Poloniex's current API docs do not describe a sandbox. CCXT still lists an old test URL for Poloniex, but that host did not answer on 2026-10-23, so test with a very small amount instead. With environment variables, leave ``POLONIEX_SANDBOX`` unset. In a code config, set ``"sandbox": False``.

Algorithmic trading example: a simple Poloniex bot
--------------------------------------------------

This bot buys about 50 USDT of BTC on Poloniex once and then holds it. It is a starting point to check that your keys, balances and orders work. If the exchange's minimum order is larger, raise the amount.

.. code-block:: python

   from lumibot.entities import Asset
   from lumibot.strategies import Strategy


   class PoloniexBuyOnce(Strategy):
       """Buy a small amount of BTC once, then hold it."""

       def initialize(self):
           self.sleeptime = "1H"
           self.set_market("24/7")  # crypto trades all day, every day

       def on_trading_iteration(self):
           coin = Asset("BTC", asset_type=Asset.AssetType.CRYPTO)
           if self.get_position(coin) is not None:
               return  # already holding BTC
           price = self.get_last_price(coin, quote=self.quote_asset)
           if price:
               quantity = round(50 / price, 6)  # about 50 USDT worth
               order = self.create_order(coin, quantity, "buy", quote=self.quote_asset)
               self.submit_order(order)


   if __name__ == "__main__":
       # LumiBot reads TRADING_BROKER and the keys from your .env file.
       strategy = PoloniexBuyOnce(quote_asset=Asset("USDT", asset_type=Asset.AssetType.CRYPTO))
       strategy.run_live()

Agentic trading example: an AI agent that trades on Poloniex
------------------------------------------------------------

Agentic trading means an AI agent reads the market and decides what to do. In this example one LumiBot agent looks at prices and your Poloniex account, then places the orders itself. There is no Python logic in between: you set the rules in plain English in the prompt, such as what it may trade and how big each order can be. This follows the same pattern as LumiBot's AI trading team examples.

.. code-block:: python

   from lumibot.entities import Asset
   from lumibot.strategies import Strategy


   class PoloniexAITrader(Strategy):
       """One AI agent researches the market and places the trades itself."""

       def initialize(self):
           self.sleeptime = "4H"
           self.set_market("24/7")
           self.agents.create(
               name="trader",
               model="openai/gpt-6-luna",
               reasoning_effort="high",
               allow_trading=True,
               system_prompt=(
                   "You manage a small crypto account on Poloniex. "
                   "You may trade BTC and ETH against USDT (asset_type 'crypto', quote_symbol 'USDT'), or hold cash. "
                   "Before every order, call account_portfolio, account_positions and "
                   "market_last_price for that exact symbol in the same run. "
                   "Keep each order under 10% of the account value. "
                   "Explain each decision in one short paragraph."
               ),
           )

       def on_trading_iteration(self):
           self.agents["trader"].run(
               task_prompt="Review recent BTC/USDT and ETH/USDT prices and your current holdings, then decide whether to buy, sell or hold.",
               context={"exchange": "Poloniex", "quote": "USDT", "date": self.get_datetime().isoformat()},
           )


   if __name__ == "__main__":
       # LumiBot reads TRADING_BROKER and the keys from your .env file.
       strategy = PoloniexAITrader(quote_asset=Asset("USDT", asset_type=Asset.AssetType.CRYPTO))
       strategy.run_live()

The agent needs a model key such as ``OPENAI_API_KEY`` in your environment. See the :doc:`AI agents quickstart <agents_quickstart>` for models, tools and memory.

Perpetual futures example on Poloniex
-------------------------------------

Poloniex also lists perpetual swaps. This bot opens one small long position in ``BTC/USDT:USDT`` worth about 50 USDT and then holds it. LumiBot treats a perpetual as ``asset_type="crypto_future"`` and sizes it in contracts, the same model as LumiBot's Bitunix futures broker. Contract symbols can differ by exchange, so check the symbol in ``self.broker.api.markets`` before going live. In hedge mode, add ``position_side="long"`` to ``create_order``.

.. code-block:: python

   from lumibot.entities import Asset
   from lumibot.strategies import Strategy


   class PoloniexOpenOneLong(Strategy):
       """Open one small long BTC perpetual position, then hold it."""

       def initialize(self):
           self.sleeptime = "1H"
           self.set_market("24/7")  # crypto trades all day, every day

       def on_trading_iteration(self):
           # The full CCXT symbol keeps the settlement currency clear.
           contract = self.broker.get_asset("BTC/USDT:USDT")
           if self.get_position(contract) is not None:
               return  # already holding the position
           price = self.get_last_price(contract)
           if price:
               # Each contract covers contract.multiplier BTC; size the order to about 50 USDT.
               quantity = round(50 / (price * contract.multiplier), 6)
               order = self.create_order(contract, quantity, "buy")
               self.submit_order(order)


   if __name__ == "__main__":
       # LumiBot reads TRADING_BROKER and the keys from your .env file.
       strategy = PoloniexOpenOneLong(quote_asset=Asset("USDT", asset_type=Asset.AssetType.CRYPTO))
       strategy.run_live()

Fees and partner IDs on Poloniex
--------------------------------

You pay Poloniex's normal trading fees. LumiBot may attach its own exchange partner ID. That costs you nothing extra. LumiBot never adds an extra builder fee unless one is turned on, and it logs a warning when one is.

Poloniex tips
-------------

* Poloniex writes its own symbols as ``BTC_USDT``. In LumiBot and CCXT use the standard form, ``BTC/USDT``. CCXT also lists Poloniex perpetuals such as ``BTC/USDT:USDT``.
* IP access restriction is off by default. Poloniex says to turn it on only if your bot runs from a static IP address, because a changing IP would lock the key out.
* Spot and futures use different keys. Spot keys come from the spot API key page, and futures keys come from https://www.poloniex.com/profile/settings/futures-api-key.

Frequently asked questions
--------------------------

**Can I build a Poloniex trading bot in Python?**

Yes. Install LumiBot (``pip install lumibot``), set your Poloniex keys and use the ``poloniex`` CCXT exchange id as shown above.

**Does Poloniex have a testnet?**

No testnet is set up for Poloniex in LumiBot. Start with a small amount, and in a code config set ``"sandbox": False``.

**Which API permissions does a Poloniex bot need?**

The key needs to read your account and trade. Leave withdrawals off. Poloniex turns withdrawals off by default because API withdrawals skip 2FA and email checks, and a bot never needs to move money out of your account.

**Can an AI agent trade on Poloniex by itself?**

Yes. The agentic example above gives one agent permission to trade. You control what it may trade and how much through its prompt.

**Can I trade Poloniex perpetual futures with LumiBot?**

CCXT lists perpetual swaps for this exchange. Use the full contract symbol, such as ``BTC/USDT:USDT``.

**Is LumiBot free?**

Yes. LumiBot is open source on GitHub at https://github.com/Lumiwealth/lumibot. You pay only your exchange's trading fees and, for AI agents, your model provider.
