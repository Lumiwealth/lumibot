What is Cryptomus?
------------------

Cryptomus is a crypto payment gateway that also runs a spot exchange. Its personal (user) API lets you check trading wallet balances and create, list and cancel exchange orders.

Sign up for Cryptomus
---------------------

#. Create a Cryptomus personal account.
#. Bind two-factor authentication in Settings. Cryptomus asks you to do this before you generate a User API key.
#. Cryptomus has no testnet, so plan to test with a very small amount.

`Open a Cryptomus account <https://cryptomus.com/>`_

Create a Cryptomus API key
--------------------------

#. Log in and open the Settings section of your personal account.
#. Bind two-factor authentication if you have not done it yet.
#. Go to the User API key section and click Generate.
#. Copy the API key and store it safely.
#. Click your user icon to find your user UUID. Cryptomus signs every personal API request with this UUID plus the API key, so you need both.

**Which permissions to turn on:** Cryptomus's docs show no permission choices for the User API key, so treat it like a full-access key and keep it private. Do not use your payment or payout keys for trading: Cryptomus issues separate keys for accepting payments and making payouts, and a trading bot only needs the User API key.

.. warning::

   Never turn on withdrawals for a Cryptomus trading bot key. Bind the key to your server's IP address when Cryptomus lets you, keep the secret out of your code and out of Git, and delete the key if it ever leaks.

Connect Cryptomus to LumiBot
----------------------------

The simplest way: put these lines in a ``.env`` file next to your strategy. LumiBot loads the file, sees ``TRADING_BROKER=cryptomus`` and connects to Cryptomus for you, so your strategy needs no broker code.

.. code-block:: bash

   TRADING_BROKER=cryptomus
   CRYPTOMUS_API_SECRET=your_secret
   CRYPTOMUS_UID=your_uid

LumiBot reads exactly the fields CCXT needs for Cryptomus (``secret``, ``uid``). If one is missing, LumiBot stops at start-up and names the variable you still need.

You can also build the broker in code. This is handy when one script talks to more than one exchange, or when you need extra CCXT options. The keys in the config are CCXT's own credential names for Cryptomus:

.. code-block:: python

   import os

   CRYPTOMUS_CONFIG = {
       "exchange_id": "cryptomus",
       "secret": os.environ.get("CRYPTOMUS_API_SECRET"),
       "uid": os.environ.get("CRYPTOMUS_UID"),
       "sandbox": False,  # no sandbox for this exchange
   }

   from lumibot.brokers import Ccxt

   broker = Ccxt(CRYPTOMUS_CONFIG)
   # then: MyStrategy(broker=broker, ...)

Either way, LumiBot turns on CCXT's built-in rate limiting for you.

Testing on Cryptomus
--------------------

Cryptomus has no sandbox, and CCXT lists no test URL for it, so test with a very small amount. With environment variables, leave ``CRYPTOMUS_SANDBOX`` unset. In a code config, set ``"sandbox": False``.

Algorithmic trading example: a simple Cryptomus bot
---------------------------------------------------

This bot buys about 50 USDT of BTC on Cryptomus once and then holds it. It is a starting point to check that your keys, balances and orders work. If the exchange's minimum order is larger, raise the amount. Cryptomus accepts only limit orders through CCXT, so the example places a limit order just above the last price.

.. code-block:: python

   from lumibot.entities import Asset
   from lumibot.strategies import Strategy


   class CryptomusBuyOnce(Strategy):
       """Buy a small amount of BTC once, then hold it."""

       def initialize(self):
           self.sleeptime = "1H"
           self.set_market("24/7")  # crypto trades all day, every day

       def on_trading_iteration(self):
           coin = Asset("BTC", asset_type=Asset.AssetType.CRYPTO)
           if self.get_position(coin) is not None:
               return  # already holding BTC
           price = self.get_last_price(coin, quote=self.quote_asset)
           if price:
               quantity = round(50 / price, 6)  # about 50 USDT worth
               # This exchange takes only limit orders through CCXT.
               order = self.create_order(coin, quantity, "buy", limit_price=price * 1.002, quote=self.quote_asset)
               self.submit_order(order)


   if __name__ == "__main__":
       # LumiBot reads TRADING_BROKER and the keys from your .env file.
       strategy = CryptomusBuyOnce(quote_asset=Asset("USDT", asset_type=Asset.AssetType.CRYPTO))
       strategy.run_live()

Agentic trading example: an AI agent that trades on Cryptomus
-------------------------------------------------------------

Agentic trading means an AI agent reads the market and decides what to do. In this example one LumiBot agent looks at prices and your Cryptomus account, then places the orders itself. There is no Python logic in between: you set the rules in plain English in the prompt, such as what it may trade and how big each order can be. This follows the same pattern as LumiBot's AI trading team examples.

.. code-block:: python

   from lumibot.entities import Asset
   from lumibot.strategies import Strategy


   class CryptomusAITrader(Strategy):
       """One AI agent researches the market and places the trades itself."""

       def initialize(self):
           self.sleeptime = "4H"
           self.set_market("24/7")
           self.agents.create(
               name="trader",
               model="openai/gpt-6-luna",
               reasoning_effort="high",
               allow_trading=True,
               system_prompt=(
                   "You manage a small crypto account on Cryptomus. "
                   "You may trade BTC and ETH against USDT (asset_type 'crypto', quote_symbol 'USDT'), or hold cash. "
                   "Before every order, call account_portfolio, account_positions and "
                   "market_last_price for that exact symbol in the same run. "
                   "Keep each order under 10% of the account value. "
                   "Explain each decision in one short paragraph."
               ),
           )

       def on_trading_iteration(self):
           self.agents["trader"].run(
               task_prompt="Review recent BTC/USDT and ETH/USDT prices and your current holdings, then decide whether to buy, sell or hold.",
               context={"exchange": "Cryptomus", "quote": "USDT", "date": self.get_datetime().isoformat()},
           )


   if __name__ == "__main__":
       # LumiBot reads TRADING_BROKER and the keys from your .env file.
       strategy = CryptomusAITrader(quote_asset=Asset("USDT", asset_type=Asset.AssetType.CRYPTO))
       strategy.run_live()

The agent needs a model key such as ``OPENAI_API_KEY`` in your environment. See the :doc:`AI agents quickstart <agents_quickstart>` for models, tools and memory.

Fees and partner IDs on Cryptomus
---------------------------------

You pay Cryptomus's normal trading fees. LumiBot may attach its own exchange partner ID. That costs you nothing extra. LumiBot never adds an extra builder fee unless one is turned on, and it logs a warning when one is.

Cryptomus tips
--------------

* Cryptomus uses two credentials, not the usual key and secret pair. In CCXT terms, your User API key is the ``secret`` and your user UUID is the ``uid``. There is no separate ``apiKey`` value.
* CCXT supports limit orders on Cryptomus but not market orders, so have your strategy place limit orders.
* Cryptomus writes pairs like ``TRX_USDT`` in its own API. LumiBot and CCXT use the ``BTC/USDT`` form.

Frequently asked questions
--------------------------

**Can I build a Cryptomus trading bot in Python?**

Yes. Install LumiBot (``pip install lumibot``), set your Cryptomus keys and use the ``cryptomus`` CCXT exchange id as shown above.

**Does Cryptomus have a testnet?**

No testnet is set up for Cryptomus in LumiBot. Start with a small amount, and in a code config set ``"sandbox": False``.

**Which API permissions does a Cryptomus bot need?**

Cryptomus's docs show no permission choices for the User API key, so treat it like a full-access key and keep it private. Do not use your payment or payout keys for trading: Cryptomus issues separate keys for accepting payments and making payouts, and a trading bot only needs the User API key.

**Can an AI agent trade on Cryptomus by itself?**

Yes. The agentic example above gives one agent permission to trade. You control what it may trade and how much through its prompt.

**Can I trade Cryptomus perpetual futures with LumiBot?**

CCXT does not list perpetual swaps for Cryptomus, so use spot markets.

**Is LumiBot free?**

Yes. LumiBot is open source on GitHub at https://github.com/Lumiwealth/lumibot. You pay only your exchange's trading fees and, for AI agents, your model provider.
