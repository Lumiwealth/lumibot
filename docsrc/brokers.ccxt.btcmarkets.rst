What is BTC Markets?
--------------------

BTC Markets is a spot crypto exchange where users buy and sell crypto with each other. Its markets are priced in Australian dollars (AUD), and it also lists some USDT markets.

Sign up for BTC Markets
-----------------------

#. Sign up for a BTC Markets account on https://www.btcmarkets.net.
#. Finish account verification. BTC Markets says your account must be verified before you can deposit, trade or withdraw.
#. Turn on two-factor authentication (2FA) for your BTC Markets account, and BTC Markets also recommends it for your email.

`Open a BTC Markets account <https://www.btcmarkets.net/>`_

Create a BTC Markets API key
----------------------------

#. Log in to your BTC Markets account.
#. Open the Account section from the main menu, select API Key and click Add new API key.
#. Name the key and choose the access level for each function of the key.
#. Review the details, click Submit and enter your password or 2FA code.
#. Copy the secret key right away. BTC Markets shows it only once. Your public API key is shown after that.

**Which permissions to turn on:** BTC Markets sets access per function when you create the key. Give the trading functions Read & Write access so the bot can place and cancel orders, and give account functions read access so it can see balances. Leave anything that moves funds out (withdrawals or transfers) off. BTC Markets warns that Read & Write lets anyone with the secret key use every ability of that function.

.. warning::

   Never turn on withdrawals for a BTC Markets trading bot key. Bind the key to your server's IP address when BTC Markets lets you, keep the secret out of your code and out of Git, and delete the key if it ever leaks.

Connect BTC Markets to LumiBot
------------------------------

The simplest way: put these lines in a ``.env`` file next to your strategy. LumiBot loads the file, sees ``TRADING_BROKER=btcmarkets`` and connects to BTC Markets for you, so your strategy needs no broker code.

.. code-block:: bash

   TRADING_BROKER=btcmarkets
   BTCMARKETS_API_KEY=your_apiKey
   BTCMARKETS_API_SECRET=your_secret

LumiBot reads exactly the fields CCXT needs for BTC Markets (``apiKey``, ``secret``). If one is missing, LumiBot stops at start-up and names the variable you still need.

You can also build the broker in code. This is handy when one script talks to more than one exchange, or when you need extra CCXT options. The keys in the config are CCXT's own credential names for BTC Markets:

.. code-block:: python

   import os

   BTCMARKETS_CONFIG = {
       "exchange_id": "btcmarkets",
       "apiKey": os.environ.get("BTCMARKETS_API_KEY"),
       "secret": os.environ.get("BTCMARKETS_API_SECRET"),
       "sandbox": False,  # no sandbox for this exchange
   }

   from lumibot.brokers import Ccxt

   broker = Ccxt(BTCMARKETS_CONFIG)
   # then: MyStrategy(broker=broker, ...)

Either way, LumiBot turns on CCXT's built-in rate limiting for you.

Testing on BTC Markets
----------------------

BTC Markets has no sandbox, and CCXT lists no test URL for it, so test with a very small amount. With environment variables, leave ``BTCMARKETS_SANDBOX`` unset. In a code config, set ``"sandbox": False``.

Algorithmic trading example: a simple BTC Markets bot
-----------------------------------------------------

This bot buys about 75 AUD of BTC on BTC Markets once and then holds it. It is a starting point to check that your keys, balances and orders work. If the exchange's minimum order is larger, raise the amount.

.. code-block:: python

   from lumibot.entities import Asset
   from lumibot.strategies import Strategy


   class BtcmarketsBuyOnce(Strategy):
       """Buy a small amount of BTC once, then hold it."""

       def initialize(self):
           self.sleeptime = "1H"
           self.set_market("24/7")  # crypto trades all day, every day

       def on_trading_iteration(self):
           coin = Asset("BTC", asset_type=Asset.AssetType.CRYPTO)
           if self.get_position(coin) is not None:
               return  # already holding BTC
           price = self.get_last_price(coin, quote=self.quote_asset)
           if price:
               quantity = round(75 / price, 6)  # about 75 AUD worth
               order = self.create_order(coin, quantity, "buy", quote=self.quote_asset)
               self.submit_order(order)


   if __name__ == "__main__":
       # LumiBot reads TRADING_BROKER and the keys from your .env file.
       strategy = BtcmarketsBuyOnce(quote_asset=Asset("AUD", asset_type=Asset.AssetType.CRYPTO))
       strategy.run_live()

Agentic trading example: an AI agent that trades on BTC Markets
---------------------------------------------------------------

Agentic trading means an AI agent reads the market and decides what to do. In this example one LumiBot agent looks at prices and your BTC Markets account, then places the orders itself. There is no Python logic in between: you set the rules in plain English in the prompt, such as what it may trade and how big each order can be. This follows the same pattern as LumiBot's AI trading team examples.

.. code-block:: python

   from lumibot.entities import Asset
   from lumibot.strategies import Strategy


   class BtcmarketsAITrader(Strategy):
       """One AI agent researches the market and places the trades itself."""

       def initialize(self):
           self.sleeptime = "4H"
           self.set_market("24/7")
           self.agents.create(
               name="trader",
               model="openai/gpt-6-luna",
               reasoning_effort="high",
               allow_trading=True,
               system_prompt=(
                   "You manage a small crypto account on BTC Markets. "
                   "You may trade BTC and ETH against AUD (asset_type 'crypto', quote_symbol 'AUD'), or hold cash. "
                   "Before every order, call account_portfolio, account_positions and "
                   "market_last_price for that exact symbol in the same run. "
                   "Keep each order under 10% of the account value. "
                   "Explain each decision in one short paragraph."
               ),
           )

       def on_trading_iteration(self):
           self.agents["trader"].run(
               task_prompt="Review recent BTC/AUD and ETH/AUD prices and your current holdings, then decide whether to buy, sell or hold.",
               context={"exchange": "BTC Markets", "quote": "AUD", "date": self.get_datetime().isoformat()},
           )


   if __name__ == "__main__":
       # LumiBot reads TRADING_BROKER and the keys from your .env file.
       strategy = BtcmarketsAITrader(quote_asset=Asset("AUD", asset_type=Asset.AssetType.CRYPTO))
       strategy.run_live()

The agent needs a model key such as ``OPENAI_API_KEY`` in your environment. See the :doc:`AI agents quickstart <agents_quickstart>` for models, tools and memory.

Fees and partner IDs on BTC Markets
-----------------------------------

You pay BTC Markets's normal trading fees. LumiBot may attach its own exchange partner ID. That costs you nothing extra. LumiBot never adds an extra builder fee unless one is turned on, and it logs a warning when one is.

BTC Markets tips
----------------

* Use ``AUD`` as your quote asset (for example ``BTC/AUD``). CCXT also lists a ``BTC/USDT`` market.
* If you lose your secret or think it leaked, click Revoke API Key on the same page and make a new key.
* BTC Markets tracks API questions and bugs on its official GitHub at https://github.com/BTCMarkets/API/issues. The current API is v3, documented at https://docs.btcmarkets.net.

Frequently asked questions
--------------------------

**Can I build a BTC Markets trading bot in Python?**

Yes. Install LumiBot (``pip install lumibot``), set your BTC Markets keys and use the ``btcmarkets`` CCXT exchange id as shown above.

**Does BTC Markets have a testnet?**

No testnet is set up for BTC Markets in LumiBot. Start with a small amount, and in a code config set ``"sandbox": False``.

**Which API permissions does a BTC Markets bot need?**

BTC Markets sets access per function when you create the key. Give the trading functions Read & Write access so the bot can place and cancel orders, and give account functions read access so it can see balances. Leave anything that moves funds out (withdrawals or transfers) off. BTC Markets warns that Read & Write lets anyone with the secret key use every ability of that function.

**Can an AI agent trade on BTC Markets by itself?**

Yes. The agentic example above gives one agent permission to trade. You control what it may trade and how much through its prompt.

**Can I trade BTC Markets perpetual futures with LumiBot?**

CCXT does not list perpetual swaps for BTC Markets, so use spot markets.

**Is LumiBot free?**

Yes. LumiBot is open source on GitHub at https://github.com/Lumiwealth/lumibot. You pay only your exchange's trading fees and, for AI agents, your model provider.
