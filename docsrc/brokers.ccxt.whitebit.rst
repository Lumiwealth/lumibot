What is WhiteBit?
-----------------

WhiteBIT is a centralized crypto exchange with 350+ trading pairs. It offers spot trading, margin trading and futures.

Sign up for WhiteBit
--------------------

#. Create a WhiteBIT account on https://whitebit.com.
#. Pass identity verification (KYC). WhiteBIT needs it before you can make deposits or withdrawals.
#. Turn on two-factor authentication (2FA). WhiteBIT requires 2FA before you can create API keys.

`Open a WhiteBit account <https://whitebit.com/>`_

Create a WhiteBit API key
-------------------------

#. Log in on the WhiteBIT website, open Settings and go to the API block, then API keys.
#. Click Generate API key and enter your 2FA code.
#. Name the key and, under endpoint access restrictions, turn on only the categories the bot needs (see below).
#. Click Confirm and enter your 2FA code again.
#. Save the Secret Key right away. WhiteBIT cannot show it again after you close the page. You can then add your bot's IP addresses to the trusted list.

**Which permissions to turn on:** Turn on Trading Balance and History and Order Management. Leave Withdrawal, Deposit and Transfer between balances off. A bot never needs to move money out of your account.

.. warning::

   Never turn on withdrawals for a WhiteBit trading bot key. Bind the key to your server's IP address when WhiteBit lets you, keep the secret out of your code and out of Git, and delete the key if it ever leaks.

Connect WhiteBit to LumiBot
---------------------------

The simplest way: put these lines in a ``.env`` file next to your strategy. LumiBot loads the file, sees ``TRADING_BROKER=whitebit`` and connects to WhiteBit for you, so your strategy needs no broker code.

.. code-block:: bash

   TRADING_BROKER=whitebit
   WHITEBIT_API_KEY=your_apiKey
   WHITEBIT_API_SECRET=your_secret

LumiBot reads exactly the fields CCXT needs for WhiteBit (``apiKey``, ``secret``). If one is missing, LumiBot stops at start-up and names the variable you still need.

You can also build the broker in code. This is handy when one script talks to more than one exchange, or when you need extra CCXT options. The keys in the config are CCXT's own credential names for WhiteBit:

.. code-block:: python

   import os

   WHITEBIT_CONFIG = {
       "exchange_id": "whitebit",
       "apiKey": os.environ.get("WHITEBIT_API_KEY"),
       "secret": os.environ.get("WHITEBIT_API_SECRET"),
       "sandbox": False,  # live connection
   }

   from lumibot.brokers import Ccxt

   broker = Ccxt(WHITEBIT_CONFIG)
   # then: MyStrategy(broker=broker, ...)

Either way, LumiBot turns on CCXT's built-in rate limiting for you.

Testing on WhiteBit
-------------------

WhiteBIT has no sandbox, and CCXT lists no test URL for it, so test with a very small amount. With environment variables, leave ``WHITEBIT_SANDBOX`` unset. In a code config, set ``"sandbox": False``.

Algorithmic trading example: a simple WhiteBit bot
--------------------------------------------------

This bot buys about 50 USDT of BTC on WhiteBit once and then holds it. It is a starting point to check that your keys, balances and orders work. If the exchange's minimum order is larger, raise the amount. WhiteBit accepts only limit orders through CCXT, so the example places a limit order just above the last price.

.. code-block:: python

   from lumibot.entities import Asset
   from lumibot.strategies import Strategy


   class WhitebitBuyOnce(Strategy):
       """Buy a small amount of BTC once, then hold it."""

       def initialize(self):
           self.sleeptime = "1H"
           self.set_market("24/7")  # crypto trades all day, every day

       def on_trading_iteration(self):
           coin = Asset("BTC", asset_type=Asset.AssetType.CRYPTO)
           if self.get_position(coin) is not None:
               return  # already holding BTC
           price = self.get_last_price(coin, quote=self.quote_asset)
           if price:
               quantity = round(50 / price, 6)  # about 50 USDT worth
               # This exchange takes only limit orders through CCXT.
               order = self.create_order(coin, quantity, "buy", limit_price=price * 1.002, quote=self.quote_asset)
               self.submit_order(order)


   if __name__ == "__main__":
       # LumiBot reads TRADING_BROKER and the keys from your .env file.
       strategy = WhitebitBuyOnce(quote_asset=Asset("USDT", asset_type=Asset.AssetType.CRYPTO))
       strategy.run_live()

Agentic trading example: an AI agent that trades on WhiteBit
------------------------------------------------------------

Agentic trading means an AI agent reads the market and decides what to do. In this example one LumiBot agent looks at prices and your WhiteBit account, then places the orders itself. There is no Python logic in between: you set the rules in plain English in the prompt, such as what it may trade and how big each order can be. This follows the same pattern as LumiBot's AI trading team examples.

.. code-block:: python

   from lumibot.entities import Asset
   from lumibot.strategies import Strategy


   class WhitebitAITrader(Strategy):
       """One AI agent researches the market and places the trades itself."""

       def initialize(self):
           self.sleeptime = "4H"
           self.set_market("24/7")
           self.agents.create(
               name="trader",
               model="openai/gpt-6-luna",
               reasoning_effort="high",
               allow_trading=True,
               system_prompt=(
                   "You manage a small crypto account on WhiteBit. "
                   "You may trade BTC and ETH against USDT (asset_type 'crypto', quote_symbol 'USDT'), or hold cash. "
                   "Before every order, call account_portfolio, account_positions and "
                   "market_last_price for that exact symbol in the same run. "
                   "Keep each order under 10% of the account value. "
                   "Explain each decision in one short paragraph."
               ),
           )

       def on_trading_iteration(self):
           self.agents["trader"].run(
               task_prompt="Review recent BTC/USDT and ETH/USDT prices and your current holdings, then decide whether to buy, sell or hold.",
               context={"exchange": "WhiteBit", "quote": "USDT", "date": self.get_datetime().isoformat()},
           )


   if __name__ == "__main__":
       # LumiBot reads TRADING_BROKER and the keys from your .env file.
       strategy = WhitebitAITrader(quote_asset=Asset("USDT", asset_type=Asset.AssetType.CRYPTO))
       strategy.run_live()

The agent needs a model key such as ``OPENAI_API_KEY`` in your environment. See the :doc:`AI agents quickstart <agents_quickstart>` for models, tools and memory.

Perpetual futures example on WhiteBit
-------------------------------------

WhiteBit also lists perpetual swaps. This bot opens one small long position in ``BTC/USDT:USDT`` worth about 50 USDT and then holds it. LumiBot treats a perpetual as ``asset_type="crypto_future"`` and sizes it in contracts, the same model as LumiBot's Bitunix futures broker. Contract symbols can differ by exchange, so check the symbol in ``self.broker.api.markets`` before going live. In hedge mode, add ``position_side="long"`` to ``create_order``. WhiteBit accepts only limit orders through CCXT, so the example places a limit order just above the last price.

.. code-block:: python

   from lumibot.entities import Asset
   from lumibot.strategies import Strategy


   class WhitebitOpenOneLong(Strategy):
       """Open one small long BTC perpetual position, then hold it."""

       def initialize(self):
           self.sleeptime = "1H"
           self.set_market("24/7")  # crypto trades all day, every day

       def on_trading_iteration(self):
           # The full CCXT symbol keeps the settlement currency clear.
           contract = self.broker.get_asset("BTC/USDT:USDT")
           if self.get_position(contract) is not None:
               return  # already holding the position
           price = self.get_last_price(contract)
           if price:
               # Each contract covers contract.multiplier BTC; size the order to about 50 USDT.
               quantity = round(50 / (price * contract.multiplier), 6)
               # This exchange takes only limit orders through CCXT.
               order = self.create_order(contract, quantity, "buy", limit_price=price * 1.002)
               self.submit_order(order)


   if __name__ == "__main__":
       # LumiBot reads TRADING_BROKER and the keys from your .env file.
       strategy = WhitebitOpenOneLong(quote_asset=Asset("USDT", asset_type=Asset.AssetType.CRYPTO))
       strategy.run_live()

Fees and partner IDs on WhiteBit
--------------------------------

You pay WhiteBit's normal trading fees. CCXT, the library underneath, normally tags WhiteBit orders with its own partner ID. LumiBot removes that tag. LumiBot may attach its own exchange partner ID instead. That costs you nothing extra. LumiBot never adds an extra builder fee unless one is turned on, and it logs a warning when one is.

WhiteBit tips
-------------

* Deposits land in your Main balance, but spot trades use your Trade balance (margin and futures use the Collateral balance). Move funds to the Trade balance on the website before you start the bot.
* If you turn on the trusted IP list and a request comes from any other IP, WhiteBIT turns the key off and emails you. You can add up to 20 trusted IPs per key.
* WhiteBIT turns off an API key after 14 days without use. You can see each key's expiry date under API keys, and reactivate it on the API settings page.
* WhiteBIT offers free Demo Tokens, a practice asset on the live exchange, to try spot trading and test your API keys. They are not a separate test site, so LumiBot's sandbox setting does not apply.

Frequently asked questions
--------------------------

**Can I build a WhiteBit trading bot in Python?**

Yes. Install LumiBot (``pip install lumibot``), set your WhiteBit keys and use the ``whitebit`` CCXT exchange id as shown above.

**Does WhiteBit have a testnet?**

No testnet is set up for WhiteBit in LumiBot. Start with a small amount, and in a code config set ``"sandbox": False``.

**Which API permissions does a WhiteBit bot need?**

Turn on Trading Balance and History and Order Management. Leave Withdrawal, Deposit and Transfer between balances off. A bot never needs to move money out of your account.

**Can an AI agent trade on WhiteBit by itself?**

Yes. The agentic example above gives one agent permission to trade. You control what it may trade and how much through its prompt.

**Can I trade WhiteBit perpetual futures with LumiBot?**

CCXT lists perpetual swaps for this exchange. Use the full contract symbol, such as ``BTC/USDT:USDT``.

**Is LumiBot free?**

Yes. LumiBot is open source on GitHub at https://github.com/Lumiwealth/lumibot. You pay only your exchange's trading fees and, for AI agents, your model provider.
