What is Binance USDⓈ-M?
-----------------------

Binance USDⓈ-M Futures are the Binance futures contracts that are quoted and settled in USDT or USDC. They come as perpetual and quarterly contracts.

Sign up for Binance USDⓈ-M
--------------------------

#. Create a Binance account, finish identity verification and turn on two-factor authentication (2FA).
#. Make a deposit of any amount to your Spot Wallet. Binance asks for this to activate the account before you can create API keys.
#. Open a USDⓈ-M Futures account before you make the API key. A key made before your Futures account was turned on cannot get the Futures permission later.

`Open a Binance USDⓈ-M account <https://www.binance.com/>`_

Create a Binance USDⓈ-M API key
-------------------------------

#. Log in, click your profile icon and choose Account, then open API Management.
#. Click Create API.
#. Choose System-generated (you get an API key and a Secret Key). Self-generated keys (Ed25519 or RSA) also work if you make your own key pair.
#. Enter a label for the key and confirm with your 2FA device or passkey.
#. Click Edit restrictions, add the IP address of the machine that runs your bot, then turn on the permissions below and save.
#. Copy the API key and Secret Key and keep them somewhere safe.

**Which permissions to turn on:** Turn on Enable Reading and Enable Futures. Leave Enable Withdrawals off, a trading bot never needs it. Binance only lets a system-generated key do more than read when you add an IP access restriction, so add your bot's IP address first.

.. warning::

   Never turn on withdrawals for a Binance USDⓈ-M trading bot key. Bind the key to your server's IP address when Binance USDⓈ-M lets you, keep the secret out of your code and out of Git, and delete the key if it ever leaks.

Connect Binance USDⓈ-M to LumiBot
---------------------------------

The simplest way: put these lines in a ``.env`` file next to your strategy. LumiBot loads the file, sees ``TRADING_BROKER=binanceusdm`` and connects to Binance USDⓈ-M for you, so your strategy needs no broker code.

.. code-block:: bash

   TRADING_BROKER=binanceusdm
   BINANCEUSDM_API_KEY=your_apiKey
   BINANCEUSDM_API_SECRET=your_secret
   BINANCEUSDM_SANDBOX=true   # testnet; remove this line for your live account

LumiBot reads exactly the fields CCXT needs for Binance USDⓈ-M (``apiKey``, ``secret``). If one is missing, LumiBot stops at start-up and names the variable you still need.

You can also build the broker in code. This is handy when one script talks to more than one exchange, or when you need extra CCXT options. The keys in the config are CCXT's own credential names for Binance USDⓈ-M:

.. code-block:: python

   import os

   BINANCEUSDM_CONFIG = {
       "exchange_id": "binanceusdm",
       "apiKey": os.environ.get("BINANCEUSDM_API_KEY"),
       "secret": os.environ.get("BINANCEUSDM_API_SECRET"),
       "sandbox": True,  # testnet first; set False for your live account
   }

   from lumibot.brokers import Ccxt

   broker = Ccxt(BINANCEUSDM_CONFIG)
   # then: MyStrategy(broker=broker, ...)

Either way, LumiBot turns on CCXT's built-in rate limiting for you.

Practice on the Binance USDⓈ-M testnet
--------------------------------------

Binance has a free test area for futures. Binance's help page now points to Futures Demo Trading at https://demo.binance.com/en/futures, where you make separate test API keys under API Management. CCXT's sandbox mode for binanceusdm uses Binance's futures testnet address (https://testnet.binancefuture.com). Make sure your test keys come from the test site that LumiBot connects to. Set ``BINANCEUSDM_SANDBOX=true`` (or ``"sandbox": True`` in a code config) to use it.

CCXT sends sandbox requests to: https://testnet.binancefuture.com/dapi/v1, https://testnet.binancefuture.com/dapi/v2. Testnet and live accounts use different keys.

Algorithmic trading example: a simple Binance USDⓈ-M bot
--------------------------------------------------------

CCXT lists no spot market for Binance USDⓈ-M, so this example trades a perpetual contract. It opens one small long BTC position worth about 50 USDT and then holds it. It is a starting point to check that your keys, balances and orders work. If the exchange's minimum order is larger, raise the amount. If your account uses hedge mode, add ``position_side="long"`` to ``create_order``. Binance USDⓈ-M accepts only limit orders through CCXT, so the example places a limit order just above the last price.

.. code-block:: python

   from lumibot.entities import Asset
   from lumibot.strategies import Strategy


   class BinanceusdmOpenOneLong(Strategy):
       """Open one small long BTC perpetual position, then hold it."""

       def initialize(self):
           self.sleeptime = "1H"
           self.set_market("24/7")  # crypto trades all day, every day

       def on_trading_iteration(self):
           # The full CCXT symbol keeps the settlement currency clear.
           contract = self.broker.get_asset("BTC/USDT:USDT")
           if self.get_position(contract) is not None:
               return  # already holding the position
           price = self.get_last_price(contract)
           if price:
               # Each contract covers contract.multiplier BTC; size the order to about 50 USDT.
               quantity = round(50 / (price * contract.multiplier), 6)
               # This exchange takes only limit orders through CCXT.
               order = self.create_order(contract, quantity, "buy", limit_price=price * 1.002)
               self.submit_order(order)


   if __name__ == "__main__":
       # LumiBot reads TRADING_BROKER and the keys from your .env file.
       strategy = BinanceusdmOpenOneLong(quote_asset=Asset("USDT", asset_type=Asset.AssetType.CRYPTO))
       strategy.run_live()

Agentic trading example: an AI agent that trades on Binance USDⓈ-M
------------------------------------------------------------------

Agentic trading means an AI agent reads the market and decides what to do. In this example one LumiBot agent looks at prices and your Binance USDⓈ-M account, then places the orders itself. There is no Python logic in between: you set the rules in plain English in the prompt, such as what it may trade and how big each order can be. This follows the same pattern as LumiBot's AI trading team examples.

.. code-block:: python

   from lumibot.entities import Asset
   from lumibot.strategies import Strategy


   class BinanceusdmAITrader(Strategy):
       """One AI agent researches the market and places the trades itself."""

       def initialize(self):
           self.sleeptime = "4H"
           self.set_market("24/7")
           self.agents.create(
               name="trader",
               model="openai/gpt-6-luna",
               reasoning_effort="high",
               allow_trading=True,
               system_prompt=(
                   "You manage a small crypto account on Binance USD\u24c8-M. "
                   "You may trade the BTC/USDT:USDT perpetual contract (asset_type 'crypto_future'), long or short, or stay flat. "
                   "Before every order, call account_portfolio, account_positions and "
                   "market_last_price for that exact symbol in the same run. "
                   "Keep each order under 10% of the account value. "
                   "Explain each decision in one short paragraph."
               ),
           )

       def on_trading_iteration(self):
           self.agents["trader"].run(
               task_prompt="Review recent BTC/USDT:USDT prices and your current position, then decide whether to buy, sell or hold.",
               context={"exchange": "Binance USD\u24c8-M", "quote": "USDT", "date": self.get_datetime().isoformat()},
           )


   if __name__ == "__main__":
       # LumiBot reads TRADING_BROKER and the keys from your .env file.
       strategy = BinanceusdmAITrader(quote_asset=Asset("USDT", asset_type=Asset.AssetType.CRYPTO))
       strategy.run_live()

Fees and partner IDs on Binance USDⓈ-M
--------------------------------------

You pay Binance USDⓈ-M's normal trading fees. LumiBot may attach its own exchange partner ID. That costs you nothing extra. LumiBot never adds an extra builder fee unless one is turned on, and it logs a warning when one is.

Binance USDⓈ-M tips
-------------------

* ``binanceusdm`` covers only USDⓈ-M futures. Use the CCXT id ``binance`` for spot trading and ``binancecoinm`` for COIN-M futures (settled in the coin itself).
* Symbols use the full CCXT form: ``BTC/USDT:USDT`` for the USDT perpetual and ``BTC/USDC:USDC`` for the USDC perpetual.
* If the Futures box is missing or greyed out on your key, your Futures account was probably opened after the key was made, or Portfolio Margin is on. Binance says such keys cannot get the Futures permission, so make a new key.

Frequently asked questions
--------------------------

**Can I build a Binance USDⓈ-M trading bot in Python?**

Yes. Install LumiBot (``pip install lumibot``), set your Binance USDⓈ-M keys and use the ``binanceusdm`` CCXT exchange id as shown above.

**Does Binance USDⓈ-M have a testnet?**

Yes. Set ``BINANCEUSDM_SANDBOX=true`` and use keys from the Binance USDⓈ-M testnet.

**Which API permissions does a Binance USDⓈ-M bot need?**

Turn on Enable Reading and Enable Futures. Leave Enable Withdrawals off, a trading bot never needs it. Binance only lets a system-generated key do more than read when you add an IP access restriction, so add your bot's IP address first.

**Can an AI agent trade on Binance USDⓈ-M by itself?**

Yes. The agentic example above gives one agent permission to trade. You control what it may trade and how much through its prompt.

**Can I trade Binance USDⓈ-M perpetual futures with LumiBot?**

CCXT lists perpetual swaps for this exchange. Use the full contract symbol, such as ``BTC/USDT:USDT``.

**Is LumiBot free?**

Yes. LumiBot is open source on GitHub at https://github.com/Lumiwealth/lumibot. You pay only your exchange's trading fees and, for AI agents, your model provider.
