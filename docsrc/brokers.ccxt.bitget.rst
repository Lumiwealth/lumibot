What is Bitget?
---------------

Bitget is a large crypto exchange with spot trading, margin, USDT and coin margined futures, and copy trading. Its newer Unified Trading Account keeps spot and futures in one account.

Sign up for Bitget
------------------

#. Create a Bitget account on the website.
#. Open Identity Verification from the profile icon and finish identity verification (KYC).
#. Turn on two-factor authentication. Bitget asks for email, SMS and Google verification codes when you create an API key.

`Open a Bitget account <https://www.bitget.com/register>`_

Create a Bitget API key
-----------------------

#. Log in on the Bitget website and open API Key Management (https://www.bitget.com/account/newapi). You can also reach it from your profile icon, then API.
#. Click Create API.
#. Add a note (a name) and type a passphrase. Write the passphrase down: Bitget cannot show it again, and you cannot change it later.
#. Set the permissions (see below) and bind the IP address of the machine that runs your bot.
#. Enter your email, SMS and Google verification codes.
#. Copy the API key and secret key and store them with the passphrase.

**Which permissions to turn on:** Give the key read and write access for trading (Bitget calls this trade, read and write) so the bot can place and cancel orders. Read-only access to account information is enough for balances. Leave withdrawals off. A bot never needs to move money out of your account.

.. warning::

   Never turn on withdrawals for a Bitget trading bot key. Bind the key to your server's IP address when Bitget lets you, keep the secret out of your code and out of Git, and delete the key if it ever leaks.

Connect Bitget to LumiBot
-------------------------

The simplest way: put these lines in a ``.env`` file next to your strategy. LumiBot loads the file, sees ``TRADING_BROKER=bitget`` and connects to Bitget for you, so your strategy needs no broker code.

.. code-block:: bash

   TRADING_BROKER=bitget
   BITGET_API_KEY=your_apiKey
   BITGET_API_PASSPHRASE=your_password
   BITGET_API_SECRET=your_secret

LumiBot reads exactly the fields CCXT needs for Bitget (``apiKey``, ``password``, ``secret``). If one is missing, LumiBot stops at start-up and names the variable you still need.

You can also build the broker in code. This is handy when one script talks to more than one exchange, or when you need extra CCXT options. The keys in the config are CCXT's own credential names for Bitget:

.. code-block:: python

   import os

   BITGET_CONFIG = {
       "exchange_id": "bitget",
       "apiKey": os.environ.get("BITGET_API_KEY"),
       "password": os.environ.get("BITGET_API_PASSPHRASE"),
       "secret": os.environ.get("BITGET_API_SECRET"),
       "sandbox": False,  # live connection
   }

   from lumibot.brokers import Ccxt

   broker = Ccxt(BITGET_CONFIG)
   # then: MyStrategy(broker=broker, ...)

Either way, LumiBot turns on CCXT's built-in rate limiting for you.

Testing on Bitget
-----------------

Bitget has no testnet in CCXT, so leave ``BITGET_SANDBOX`` unset, and in a code config set ``"sandbox": False``. Bitget does have a demo trading mode with its own Demo API Keys (switch to Demo mode, then API Key Management), but LumiBot's sandbox setting does not point there. Test with a very small amount instead.

Algorithmic trading example: a simple Bitget bot
------------------------------------------------

This bot buys about 50 USDT of BTC on Bitget once and then holds it. It is a starting point to check that your keys, balances and orders work. If the exchange's minimum order is larger, raise the amount. Bitget accepts only limit orders through CCXT, so the example places a limit order just above the last price.

.. code-block:: python

   from lumibot.entities import Asset
   from lumibot.strategies import Strategy


   class BitgetBuyOnce(Strategy):
       """Buy a small amount of BTC once, then hold it."""

       def initialize(self):
           self.sleeptime = "1H"
           self.set_market("24/7")  # crypto trades all day, every day

       def on_trading_iteration(self):
           coin = Asset("BTC", asset_type=Asset.AssetType.CRYPTO)
           if self.get_position(coin) is not None:
               return  # already holding BTC
           price = self.get_last_price(coin, quote=self.quote_asset)
           if price:
               quantity = round(50 / price, 6)  # about 50 USDT worth
               # This exchange takes only limit orders through CCXT.
               order = self.create_order(coin, quantity, "buy", limit_price=price * 1.002, quote=self.quote_asset)
               self.submit_order(order)


   if __name__ == "__main__":
       # LumiBot reads TRADING_BROKER and the keys from your .env file.
       strategy = BitgetBuyOnce(quote_asset=Asset("USDT", asset_type=Asset.AssetType.CRYPTO))
       strategy.run_live()

Agentic trading example: an AI agent that trades on Bitget
----------------------------------------------------------

Agentic trading means an AI agent reads the market and decides what to do. In this example one LumiBot agent looks at prices and your Bitget account, then places the orders itself. There is no Python logic in between: you set the rules in plain English in the prompt, such as what it may trade and how big each order can be. This follows the same pattern as LumiBot's AI trading team examples.

.. code-block:: python

   from lumibot.entities import Asset
   from lumibot.strategies import Strategy


   class BitgetAITrader(Strategy):
       """One AI agent researches the market and places the trades itself."""

       def initialize(self):
           self.sleeptime = "4H"
           self.set_market("24/7")
           self.agents.create(
               name="trader",
               model="openai/gpt-6-luna",
               reasoning_effort="high",
               allow_trading=True,
               system_prompt=(
                   "You manage a small crypto account on Bitget. "
                   "You may trade BTC and ETH against USDT (asset_type 'crypto', quote_symbol 'USDT'), or hold cash. "
                   "Before every order, call account_portfolio, account_positions and "
                   "market_last_price for that exact symbol in the same run. "
                   "Keep each order under 10% of the account value. "
                   "Explain each decision in one short paragraph."
               ),
           )

       def on_trading_iteration(self):
           self.agents["trader"].run(
               task_prompt="Review recent BTC/USDT and ETH/USDT prices and your current holdings, then decide whether to buy, sell or hold.",
               context={"exchange": "Bitget", "quote": "USDT", "date": self.get_datetime().isoformat()},
           )


   if __name__ == "__main__":
       # LumiBot reads TRADING_BROKER and the keys from your .env file.
       strategy = BitgetAITrader(quote_asset=Asset("USDT", asset_type=Asset.AssetType.CRYPTO))
       strategy.run_live()

The agent needs a model key such as ``OPENAI_API_KEY`` in your environment. See the :doc:`AI agents quickstart <agents_quickstart>` for models, tools and memory.

Perpetual futures example on Bitget
-----------------------------------

Bitget also lists perpetual swaps. This bot opens one small long position in ``BTC/USDT:USDT`` worth about 50 USDT and then holds it. LumiBot treats a perpetual as ``asset_type="crypto_future"`` and sizes it in contracts, the same model as LumiBot's Bitunix futures broker. Contract symbols can differ by exchange, so check the symbol in ``self.broker.api.markets`` before going live. In hedge mode, add ``position_side="long"`` to ``create_order``. Bitget accepts only limit orders through CCXT, so the example places a limit order just above the last price.

.. code-block:: python

   from lumibot.entities import Asset
   from lumibot.strategies import Strategy


   class BitgetOpenOneLong(Strategy):
       """Open one small long BTC perpetual position, then hold it."""

       def initialize(self):
           self.sleeptime = "1H"
           self.set_market("24/7")  # crypto trades all day, every day

       def on_trading_iteration(self):
           # The full CCXT symbol keeps the settlement currency clear.
           contract = self.broker.get_asset("BTC/USDT:USDT")
           if self.get_position(contract) is not None:
               return  # already holding the position
           price = self.get_last_price(contract)
           if price:
               # Each contract covers contract.multiplier BTC; size the order to about 50 USDT.
               quantity = round(50 / (price * contract.multiplier), 6)
               # This exchange takes only limit orders through CCXT.
               order = self.create_order(contract, quantity, "buy", limit_price=price * 1.002)
               self.submit_order(order)


   if __name__ == "__main__":
       # LumiBot reads TRADING_BROKER and the keys from your .env file.
       strategy = BitgetOpenOneLong(quote_asset=Asset("USDT", asset_type=Asset.AssetType.CRYPTO))
       strategy.run_live()

Fees and partner IDs on Bitget
------------------------------

You pay Bitget's normal trading fees. CCXT, the library underneath, normally tags Bitget orders with its own partner ID. LumiBot removes that tag. LumiBot may attach its own exchange partner ID instead. That costs you nothing extra. LumiBot never adds an extra builder fee unless one is turned on, and it logs a warning when one is.

Bitget tips
-----------

* Bitget needs three credentials: the API key, the secret key and your passphrase. Put the passphrase in ``BITGET_API_PASSPHRASE`` (``"password"`` in a code config). If you lose the passphrase you must delete the key and make a new one.
* Bitget strongly recommends binding an IP address to every API key. Each account can create up to 50 API keys.
* Sub-accounts can create their own API keys once the main account turns on API Key Management for that sub-account. A separate sub-account per bot keeps bot trades apart from manual trades.
* Spot symbols look like ``BTC/USDT``. USDT perpetuals use the full CCXT form ``BTC/USDT:USDT``.

Frequently asked questions
--------------------------

**Can I build a Bitget trading bot in Python?**

Yes. Install LumiBot (``pip install lumibot``), set your Bitget keys and use the ``bitget`` CCXT exchange id as shown above.

**Does Bitget have a testnet?**

No testnet is set up for Bitget in LumiBot. Start with a small amount, and in a code config set ``"sandbox": False``.

**Which API permissions does a Bitget bot need?**

Give the key read and write access for trading (Bitget calls this trade, read and write) so the bot can place and cancel orders. Read-only access to account information is enough for balances. Leave withdrawals off. A bot never needs to move money out of your account.

**Can an AI agent trade on Bitget by itself?**

Yes. The agentic example above gives one agent permission to trade. You control what it may trade and how much through its prompt.

**Can I trade Bitget perpetual futures with LumiBot?**

CCXT lists perpetual swaps for this exchange. Use the full contract symbol, such as ``BTC/USDT:USDT``.

**Is LumiBot free?**

Yes. LumiBot is open source on GitHub at https://github.com/Lumiwealth/lumibot. You pay only your exchange's trading fees and, for AI agents, your model provider.
