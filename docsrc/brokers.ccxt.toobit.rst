What is Toobit?
---------------

Toobit is a crypto exchange that offers spot trading, USDT-M and USDC-M perpetual contracts, copy trading and P2P trading.

Sign up for Toobit
------------------

#. Sign up on the Toobit register page with your email or phone number, set a password, and enter the verification code Toobit sends you.
#. Turn on Google Authenticator: open Profile, then Security Settings, and click Settings next to Google Verification. Toobit asks for this code when you create an API key.
#. Optional: create a sub-account for your bot (profile icon, then Sub-account, then Create sub-account) and move funds to it with Transfer.

`Open a Toobit account <https://www.toobit.com/en-US/register>`_

Create a Toobit API key
-----------------------

#. On the Toobit website (keys cannot be made in the app), click the user icon at the top right and choose API Management (https://www.toobit.com/en-US/user/sub-api).
#. Click New API.
#. Name the key, set its permissions (see below) and add the IP address of your bot to the IP whitelist, then press Confirm.
#. Enter your Google Authenticator code and click OK.
#. Copy the Secret Key right away. Toobit shows it only once.

**Which permissions to turn on:** A new Toobit key can only read at first (Enable Reading). Turn on the trade permission so the bot can place and cancel orders. Leave any withdrawal permission off. A bot never needs to move money out of your account.

.. warning::

   Never turn on withdrawals for a Toobit trading bot key. Bind the key to your server's IP address when Toobit lets you, keep the secret out of your code and out of Git, and delete the key if it ever leaks.

Connect Toobit to LumiBot
-------------------------

The simplest way: put these lines in a ``.env`` file next to your strategy. LumiBot loads the file, sees ``TRADING_BROKER=toobit`` and connects to Toobit for you, so your strategy needs no broker code.

.. code-block:: bash

   TRADING_BROKER=toobit
   TOOBIT_API_KEY=your_apiKey
   TOOBIT_API_SECRET=your_secret

LumiBot reads exactly the fields CCXT needs for Toobit (``apiKey``, ``secret``). If one is missing, LumiBot stops at start-up and names the variable you still need.

You can also build the broker in code. This is handy when one script talks to more than one exchange, or when you need extra CCXT options. The keys in the config are CCXT's own credential names for Toobit:

.. code-block:: python

   import os

   TOOBIT_CONFIG = {
       "exchange_id": "toobit",
       "apiKey": os.environ.get("TOOBIT_API_KEY"),
       "secret": os.environ.get("TOOBIT_API_SECRET"),
       "sandbox": False,  # no sandbox for this exchange
   }

   from lumibot.brokers import Ccxt

   broker = Ccxt(TOOBIT_CONFIG)
   # then: MyStrategy(broker=broker, ...)

Either way, LumiBot turns on CCXT's built-in rate limiting for you.

Toobit has a Demo Trading page on its website, but CCXT lists no test URL for Toobit, so LumiBot cannot point at it. Test with a very small amount, leave ``TOOBIT_SANDBOX`` unset, and in a code config set ``"sandbox": False``.

Algorithmic trading example: a simple Toobit bot
------------------------------------------------

This bot buys about 50 USDT of BTC on Toobit once and then holds it. It is a starting point to check that your keys, balances and orders work. If the exchange's minimum order is larger, raise the amount.

.. code-block:: python

   from lumibot.entities import Asset
   from lumibot.strategies import Strategy


   class ToobitBuyOnce(Strategy):
       """Buy a small amount of BTC once, then hold it."""

       def initialize(self):
           self.sleeptime = "1H"
           self.set_market("24/7")  # crypto trades all day, every day

       def on_trading_iteration(self):
           coin = Asset("BTC", asset_type=Asset.AssetType.CRYPTO)
           if self.get_position(coin) is not None:
               return  # already holding BTC
           price = self.get_last_price(coin, quote=self.quote_asset)
           if price:
               quantity = round(50 / price, 6)  # about 50 USDT worth
               order = self.create_order(coin, quantity, "buy", quote=self.quote_asset)
               self.submit_order(order)


   if __name__ == "__main__":
       # LumiBot reads TRADING_BROKER and the keys from your .env file.
       strategy = ToobitBuyOnce(quote_asset=Asset("USDT", asset_type=Asset.AssetType.CRYPTO))
       strategy.run_live()

Agentic trading example: an AI agent that trades on Toobit
----------------------------------------------------------

Agentic trading means an AI agent reads the market and decides what to do. In this example one LumiBot agent looks at prices and your Toobit account, then places the orders itself. There is no Python logic in between: you set the rules in plain English in the prompt, such as what it may trade and how big each order can be. This follows the same pattern as LumiBot's AI trading team examples.

.. code-block:: python

   from lumibot.entities import Asset
   from lumibot.strategies import Strategy


   class ToobitAITrader(Strategy):
       """One AI agent researches the market and places the trades itself."""

       def initialize(self):
           self.sleeptime = "4H"
           self.set_market("24/7")
           self.agents.create(
               name="trader",
               model="openai/gpt-6-luna",
               reasoning_effort="high",
               allow_trading=True,
               system_prompt=(
                   "You manage a small crypto account on Toobit. "
                   "You may trade BTC and ETH against USDT (asset_type 'crypto', quote_symbol 'USDT'), or hold cash. "
                   "Before every order, call account_portfolio, account_positions and "
                   "market_last_price for that exact symbol in the same run. "
                   "Keep each order under 10% of the account value. "
                   "Explain each decision in one short paragraph."
               ),
           )

       def on_trading_iteration(self):
           self.agents["trader"].run(
               task_prompt="Review recent BTC/USDT and ETH/USDT prices and your current holdings, then decide whether to buy, sell or hold.",
               context={"exchange": "Toobit", "quote": "USDT", "date": self.get_datetime().isoformat()},
           )


   if __name__ == "__main__":
       # LumiBot reads TRADING_BROKER and the keys from your .env file.
       strategy = ToobitAITrader(quote_asset=Asset("USDT", asset_type=Asset.AssetType.CRYPTO))
       strategy.run_live()

The agent needs a model key such as ``OPENAI_API_KEY`` in your environment. See the :doc:`AI agents quickstart <agents_quickstart>` for models, tools and memory.

Toobit tips
-----------

* Toobit API keys expire 90 days after they are created. Put a reminder in your calendar to make a new key before then, or your bot will stop trading.
* Each Toobit account can have at most 10 API keys. You can freeze, delete or change the permissions of a key from the API list.
* Toobit's own symbols look like ``BTCUSDT``. In LumiBot use the CCXT form: spot is ``BTC/USDT`` and the USDT perpetual is ``BTC/USDT:USDT``.
* Sub-accounts keep their own funds and trading apart from the main account, which makes them a good home for a bot.

Frequently asked questions
--------------------------

**Can I build a Toobit trading bot in Python?**

Yes. Install LumiBot (``pip install lumibot``), set your Toobit keys and use the ``toobit`` CCXT exchange id as shown above.

**Does Toobit have a testnet?**

No testnet is set up for Toobit in LumiBot. Start with a small amount, and in a code config set ``"sandbox": False``.

**Which API permissions does a Toobit bot need?**

A new Toobit key can only read at first (Enable Reading). Turn on the trade permission so the bot can place and cancel orders. Leave any withdrawal permission off. A bot never needs to move money out of your account.

**Can an AI agent trade on Toobit by itself?**

Yes. The agentic example above gives one agent permission to trade. You control what it may trade and how much through its prompt.

**Can I trade Toobit perpetual futures with LumiBot?**

CCXT lists perpetual swaps for this exchange. Use the full contract symbol, such as ``BTC/USDT:USDT``.

**Is LumiBot free?**

Yes. LumiBot is open source on GitHub at https://github.com/Lumiwealth/lumibot. You pay only your exchange's trading fees and, for AI agents, your model provider.
